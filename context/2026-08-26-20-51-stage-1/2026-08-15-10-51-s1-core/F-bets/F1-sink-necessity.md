"# F1 — 赌注一:sink 是 softmax 缺弃权项的必然,位置由 $\Phi$-平坦决定

## 1. 推导

attention 是 $\tau(x) = \mathrm{sel}(\arg\max_a c(x, \mathrm{anc}(a)))$ 的 softmax 版,锚点 = 各 key。softmax 强制:

$$\sum_a p(a) = 1$$

锚点集只由**内容位置**供给。于是「没有任何 key 该赢」这个状态**在签名里无处表达**——它需要 $\Omega^+$ 里那个 $*$(A2 §6),而 attention 的锚点集里没有 $*$。

概率必须落在某处。落哪最便宜?落在**纤维 $\Phi$-平**的地址上——按 A5 §3,$\Phi$ 平意味着往那儿倒不改变下游读取的量,代价近零。

$$\boxed{\text{sink 必在「恒可用且 } \Phi \text{ 最平」的地址上形成}}$$

两个条件都是必要的:恒可用(每次都得有地方倒)、$\Phi$ 平(倒了不出事)。

## 2. 三个架构,三个位置预言

同一条推导,位置随架构的「哪个地址恒可用且 $\Phi$ 最平」而变:

| 架构 | 恒可用的地址 | 预言位置 | 已观测 |
|---|---|---|---|
| causal LM | 位置 0(causal mask 下人人可见) | **P0** | 吻合;Why-First-Token 的 no-op 正是「$\Phi$ 平」的独立测量 |
| ViT(双向) | **无结构特权位置** | 落在 $\Phi$ 最平的 patch = 低信息背景 | 吻合(ICLR 2025 报告 sink 位于背景等低信息区) |
| diffusion transformer | 无固定 P0;text-conditioning key 每层每步恒在 | 落在少量 conditioning key,且**随层 / timestep 漂移**——轨迹推进使「哪个最平」本身在变 | 吻合(非固定 P0、少量 text key、随层与 timestep 变) |

**三个位置不是三条经验规律,是一条推导代入三种「恒可用」结构。** ViT 那一格尤其关键:双向注意力没有结构特权位,推导于是预言 sink 必须去找**内容上**最平的地方,这与 causal LM 的位置预言方向不同却同源。

## 3. 杀死条件

推导说 sink 存在是因为**没有弃权项**。故:

$$\textbf{给 attention 一个显式弃权项,内容地址上的 sink 应消失或显著减弱}$$

实现是把 softmax 分母加一个常数项(等价于加一个无 value 的 null key),让「谁都不该赢」有合法归宿。

- **弃权项存在时 sink 显著减弱 / 迁移到弃权项上** → F1 成立,且顺带解释了 register 类方案为何有效(它们提供了归宿)。
- **弃权项存在而内容地址上的 sink 照旧** → **F1 死。** 说明 sink 不是缺弃权项造成的,我的推导错。

**这一条可能已经被文献判决。** softmax-off-by-one / quiet attention 与 register 两条线都有工作,我记忆中有后续报告称 sink 未完全消失——若确实如此,F1 现在就死,或退化成「弃权项是必要不充分」。这是 S2 三个靶问的第一问,**优先于任何铺开式扫读**。

我不为它辩护:一个可能已经被现成文献杀死的赌注,正是评价要的那种赌注。它死掉比它含糊地活着有用。

## 4. F1 若成立,附带的可判伪预言

- 弃权项的容量应与「模型多常需要不承诺」相关,故长上下文 / 高不确定任务上收益更大。
- ViT 加入显式 register 后,原低信息 patch 上的 sink 应迁走而非消失——因为 register 就是人为造的 $\Phi$-平恒可用地址。
- diffusion 里 sink 的漂移应与「哪个 conditioning key 此刻最 $\Phi$-平」同步,可对照测。
