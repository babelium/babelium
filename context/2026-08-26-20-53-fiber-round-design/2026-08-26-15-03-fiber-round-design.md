## 3. 逐件展开

### FIB-0 · Φ 预先声明纪律

**做什么。** 一条规矩,不是实验:**下游读什么(Φ),必须在看到任何数据之前从架构里读出来写死。**

**为什么它是全轮的地基。** 代价这个量带一个参数 Φ。如果允许看了结果再挑 Φ,那任何压缩都能被说成无损——挑一把看不见损失的尺子就行。所以这条纪律是「代价」这个概念不成为空话的唯一保证。

**它同时是我们与先行工作划界的那一句。** V-information 里的函数族是分析者选的,我们的 Φ 是从架构的计算图读出来的。这个区别是我们唯一站得住的原创点,而它完全依赖这条纪律真的被执行。

**怎么落地。** 三件:(a) 按架构家族各写一份 Φ 声明,逐行对着官方 `modeling_*.py` 核;(b) 主方向只用权重矩阵的 SVD 定,**不许用任何激活统计**——用了就是看了数据;(c) 声明写完打 tag 冻结,之后的改动全部留痕。

**审计指出的一处硬伤要修:** 原来那份 Φ 声明不符合 decoder 的真实执行路径(把 attention 分支、residual 分支、整块输出混在一个族里)。这个必须按官方源码重写,否则 FIB-2 测的位点是错的。

### FIB-1 · 先行工作定位【前置,阻塞其余】

**做什么。** 读文献,回答一个问题:**我们这套东西是已有理论的哪个特例,增量到底在哪。**

**为什么它排第一。** 我们的核心量

$$\mathrm{Cost}_\Phi(p)=\sup_{\varphi\in\Phi}\big|\mathbb{E}_{\kappa\tau p}[\varphi]-\mathbb{E}_p[\varphi]\big|$$

在数学上叫 **integral probability metric**,以函数族 Φ 索引的一族概率距离,1997 年就有。取指标函数得全变差距离,取 1-Lipschitz 得 Wasserstein-1。**我们自己的结论第 58 条已经算出了它的全变差特例,但没认出这个族。**

概念上撞得最近的是 **V-information**(ICLR 2020):「能被一个受限函数族实际使用的信息量」。这跟「下游读得到的那部分损失」几乎是同一个想法,而且它有 PAC 估计保证。旁边还有 task-based quantization(为下游任务而非重建误差设计量化器,有 indirect rate-distortion 的刻画)和 task-aware quantization。

**这几支在我们的证据链里搜不到任何一处。** 顶尖会议的审稿人第一轮就会问「这与 V-information 的区别是什么」,而这个问题现在答不出来。

**怎么做。** 按项目已有的 deep-read 流程(五段式:略读 → 把握 → 深读 → 形式主张与证据 → 整合),读四支:

1. IPM 族的标准结果——**目的是知道哪些性质是白拿的,哪些是我们自己要证的**
2. V-information ——**核心是查它的函数族从哪来,有没有等价的零核刻画**
3. task-based / task-aware quantization ——**核心是查有没有人已经从架构结构导出过加权,这直接决定 FIB-4 还有没有增量**
4. 分词器理论那几篇(已有 deep-read 产物,回头复核)

**产出。** 一份定位文件,三节:我们是什么的特例;增量在哪(候选是三条:Φ 由架构导出、代价拆成商坍缩与选择坍缩两项、同一套账跨系统用);**哪些声称被文献杀掉了**。

**风险,以及为什么这个风险值得先撞。** 可能读完发现某条增量不存在。**那也是收益——早三个月知道比晚三个月知道便宜得多。** 而且真正的最坏情况不是「被杀掉一条」,是「四个月后被审稿人杀掉」。

### FIB-2 · 次序检验【主结果】

**做什么。** 这是全轮的中心。一句话:

> **同一次承诺,下游有好几个读出位点;哪个位点代价低,能在测量之前只用权重算出来。算出来的次序,和实测的次序,对不对得上。**

**为什么是这个形状。** 原设计是「九个模型 × 十个量,跨模型找相关性」。审计逐条证明这个形状不成立:跨模型比较里,想锁的变量锁不住(P6 两个模型的函数族无包含关系、P5 规模与权重绑定状态共变、P3 分词器同时变了六个东西)。**根因是同一个。**

同模型内比较把这个问题按构造消掉:同一个模型、同一批输入、同一次前向,变的只有「读哪一支」。

**而且它测的是理论本身,不是理论的下游相关物。** 零核定理说「代价恒零 ⟺ Φ 看不见纤维」。那它的可测版本就是:**Φ 越看不见纤维的变化方向,代价越低。** 位点之间的差异正好是「看见多少」的差异。P5、P6 测的都是这句话的间接后果,只有这个测这句话本身。

**在三个界面上各跑一次,不只在自回归上。** 这是「跨界面」那条增量的实验形式,也是与先行工作正面对话的位置:

| 界面 | 局部层的 $\mathcal{X}$ | 商 | $\Phi$ |
|---|---|---|---|
| AR 采样 | 残差流 | $\arg\max$ 划分 | 下一层各投影分支 |
| VQ | 编码器输出 | 最近码字划分 | 解码器首层各分支 |
| **KV cache** | 缓存键 | $\mathcal{X}/N_q$(softmax-null) | 注意力分布各分量 |

**第三行是新增的,理由是它已有先行工作**(HeadQ 2605.03562 的 Theorem 1 就是该界面的零核)。**在这一行上我们能做的不是重新发现,是证明它与前两行是同一个式子的三次代入,并检验权重级推导在三个界面上都成立。** 若同一个推导在三个界面上都对,「跨界面」这条增量就有了实证;若只在一个界面上对,那它就只是那个界面的性质。

**怎么做(每个界面同一套流程)。**

```
第一步(推导,只碰权重,不碰数据)
  对该界面的每个真实读出位点 j
  ——AR:W_q / W_k / W_v / W_gate / W_up、范数项,MLA 多一个低秩瓶颈位点
  用权重的 SVD 推出一个预测的代价次序,公式在看数之前写死

第二步(测量,三臂前向)
  提交臂:喂被选中那个 token 的嵌入(照常运行)
  不提交臂:喂按概率加权的平均嵌入(判据右侧那个反事实量)
  诊断臂:喂全词表平均嵌入(离流形参照)
  逐位点算实际代价

第三步(检验)
  推导次序 vs 实测次序,一致吗
```

**三臂那个设计的来历。** 判据右侧是「若不提交会怎样」,而下游从来不算这个量,所以必须人为造出「不提交」那一臂。做法是喂 `inputs_embeds`,不用改模型。

**它可能怎么失败,以及为什么这是优点。** 权重级推导只知道各分支的行空间与谱,**不知道纤维的变化方向在真实数据上落在哪里**。如果实测次序对不上推导次序,说明零核定理的实践内容不成立——Φ 的「大小」不足以预测代价。**这是一条能真被打死的预言。** 相比之下「代价随规模下降」即使被打死也可以归给一堆别的原因。

**四条臂,一起报。** 前两条堵「平凡通过」,第四条堵「不如既有基线」:

**推导公式已写死**(`2026-08-26-20-40-fiber-02-prereg/FIB2-ordering-derivation.md`)。转折点是一步化归:$W_j$ 不依赖样本,可移出期望,故

$$\mathrm{theory\_cost}_j=\lVert W_j\,d\rVert_2,\qquad d=\mathbb{E}_\mu\big[N(u^{\mathrm{avg}})-N(u^{\mathrm{cmt}})\big]$$

**$d$ 是一个向量,而且所有位点共用同一个 $d$。** 于是问题变成「不知道 $d$ 时能不能预测 $\lVert W_jd\rVert$ 的次序」——良设,且答案不显然。

**这步化归让四条臂各自等价于一个可陈述的假设:**

| 臂 | 预测量 | 等价于假设 |
|---|---|---|
| 形状零模型 | $\sqrt{d_j}$(输出维数) | 代价只由输出维数定 |
| 谱零模型 | $\lVert W_j\rVert_F$ | **$d$ 各向同性** |
| **权重级** | $\sqrt{\mathrm{tr}(W_jCW_j^\top)}$ | **$d$ 在坍缩子空间里典型** |
| 校准级 | $\sqrt{\mathrm{tr}(W_jC_{\mathrm{cal}}W_j^\top)}$ | $d$ 在实测二阶矩里典型 |

坍缩协方差 $C$ 只用三个权重张量构造(输入嵌入、输出投影、归一化增益 $\gamma$),四步:按 `lm_head` 行余弦取竞争集 → 取切向差 → 按余弦 softmax 加权 → 求二阶矩。

**「会不会平凡通过」这个担心可以撤了。** 平凡版本恰好**就是**谱零模型($d$ 各向同性),而权重级与它的差是 $C$ 的各向异性——两者不同构。**前两个零模型因此不只是对照手段,它们是被明确陈述的替代假设。**

**为什么必须有校准级这一臂。** 2026 年 KV cache 量化那一支已经普遍用校准统计导出「下游读什么」,且给了闭式解。**所以「用权重导出」若预测能力不如「用校准导出」,那我们不是多了一条纪律,是用了一个更弱的信息源。** 审稿人一定会问「为什么不直接用校准数据」。四臂一起报之后,即使权重级弱于校准级,结果仍是有内容的发现——**「$\Phi$ 的可见性有多少能从架构单独读出」本身值得知道**。校准集须与测量集不交,否则那不是预测是测量。

**跑之前就能算的无功效条件。** 若 $C\propto I$ 则权重级与谱零模型恒等,检验没有功效。故须先从权重算 $C$ 的各向异性(最大特征值比 / 有效秩)并报告——**无功效的话在花钱之前知道,不是事后解释。**

**这一条与先行工作正面对上:** 2608.04074 的零增益条件是「除非 $M_q\propto I$,正交变换次优」。**同一个结构在两处出现——各向同性时读出加权与朴素度量等价。** 论文里该明引这个接触点,不绕开。

**Qwen3 的 q/k 位点上化归失效,而失效处正是 FIB-0 那条新预言的定量形式。** per-head norm 作用在 $W_j\hat u$ 之后,故 $W_j$ 移不出期望;处置是在头内重复一次切向投影,得 $\mathrm{pred}^{\mathrm{Qwen3}}=\sqrt{\mathrm{tr}(P_\perp^{(h)}W_jCW_j^\top P_\perp^{(h)})}$。**投影只减小 $\mathrm{tr}$,故 Qwen3 的 q/k 低于 Qwen2 按构造成立,v 位点无投影故无差异。** 预言从「更低」变成「低多少」。

**一处结构性弱点,如实记:** $C$ 里的 token 先验只能取均匀——取语料频率就引入了数据,这一臂就不纯了。**故权重级对高频与低频 token 的竞争结构一视同仁,而实际代价由高频者主导。这是「不用数据」的代价,不是实现瑕疵。**

**冻结的八行参数**(竞争集 $k=32$、代理温度 0.05、先验均匀、用切向投影、用 $\gamma$ 加权、位点按头拆、Spearman + 三态判):见推导文件 §8。**跑出结果后不许改任何一行;要改须另起一版并同时报两版。**

**估计器与统计口径由 B02 定死**(`2026-08-26-15-03-fiber-01-foundations/B02-empirical-estimator.md`),三条要点:

- **主端点是 $\lVert\mathbb E_\mu[\cdot]\rVert_2$,期望在范数内部。** 先求期望再取范数;反过来是另一个量。理由:$\mathrm{Cost}_\Phi$ 是 IPM,问的是「$\Phi$ 里有没有函数能区分这两个分布」,故误差在期望上抵消就是不可分。抵消掉的那部分单列为 `local_shift`,不许沿用 Cost 之名。
- **范数落在零核里,不是 $\Phi$ 的成员。** 归一化第一步就把它除掉,读不到即零核。故「不提交臂的向量更短」不是需要对照的混淆项,按构造不进代价。$\Phi$ 因此是纯线性族,上确界有闭式,主分析用完整 L2 而非 16 方向截断。
- **但 $\epsilon$ 残余是真的:** 尺度不变要求 $\lVert u\rVert^2\gg\epsilon d$。**Qwen2.5-72B 的 `rms_norm_eps`=1e-05 比其余大一个数量级($\epsilon d$=8.2e-2,阈值 $\lVert u\rVert\gg0.29$),而 $u^{\mathrm{avg}}$ 是凸组合、范数天然小。** 故每个模型必测 $\lVert u^{\mathrm{avg}}\rVert^2/(\epsilon d)$ 的分布并报分位数,不许假设掉。

### FIB-3 · 配对预训练【identified 因果】

**做什么。** 自己训两组模型,除了注意力机制不同,别的全一样:同数据、同数据顺序、同预算、多个随机种子。

**为什么必须自己训。** 原设计想说「MLA 使代价降低」,做法是拿 DeepSeek-V2-Lite 比 Qwen3-30B-A3B。审计的判定是不可归因,而理由不是钱不够——**公开权重里根本不存在「同厂、同规模、只有注意力机制不同」的一对**。规格自己在审计之前就承认了这一点。同理,「代价随规模下降」在 Qwen 家族上永远测不干净,因为小模型权重绑定、大模型不绑定,绑定状态和规模一起变。

**所以这两条不是被降级的野心,是从来不在桌上。要它们上桌,唯一的路是自己训。**

**怎么做。**

```
两臂:MLA / GQA,参数量对齐
两档规模:300M、(视结果决定是否上)1B
三个随机种子
数据顺序、训练预算、超参全部固定
```

**为什么 300M 不算 toy。** 零核定理讲的是 Φ 维数与代价的关系,这是一个机制,它不该只在 32B 才出现。架构消融在这个规模上是文献惯例,**前提是框成「受控消融」而不是「前沿规模结论」**。而且两档规模能测出一件更强的事:**这个机制是不是随规模变化。** 原设计那个四个 checkpoint 的梯子答不了这个问题。

**成本粗估**(profiling 前只算量级下界):

| 规模 | 每 run | 6 run(2 臂 × 3 种子) | 8×B200 墙钟 |
|---|---|---|---|
| 300M × 30B token | ≈ 5.4e19 FLOPs | ≈ 3.2e20 | 约 1–2 天 |
| 1B × 100B token | ≈ 6.0e20 FLOPs | ≈ 3.6e21 | 约 2 周 |

**时间的大头不在跑,在搭。** 训练 pipeline、数据管线、检查点管理、多种子编排,3 周量级。跑本身很快。

**一个便宜的补充证据:TransMLA。** 已有工作能把训好的 GQA 模型转成 MLA。这条比配对预训练便宜得多,而且初始化同源。**但它不能替代配对预训练**——转换后的模型是原 GQA 模型的扰动版本,两臂不对称,这个混淆消不掉。所以它的角色是第二条证据,不是主结论。

**残留混淆要如实报:** MLA 与 GQA 在参数量对齐时 KV cache 大小仍然不同,所以两者的有效容量不完全等价。这一条消不掉,写进限制。

### FIB-4 · Φ-对齐 VQ【顶尖分水岭 + 跨域】

**做什么。** 这是唯一一件「用理论造东西」的事。

零核定理说:代价恒零 ⟺ Φ 看不见纤维。**倒过来用就是一条设计原则:如果把商设计成让纤维方向落在下游读出的零空间里,代价按构造为零。**

落到 VQ 上:标准 VQ 最小化 $\lVert z-e_k\rVert^2$,**欧氏、各向同性、跟解码器读什么完全无关**。理论说正确的目标是最小化「解码器首层看得见的那部分误差」,即按下游读出敏感度加权的量化误差。

**预言(可判伪):** 同码本大小下,Φ-对齐 VQ 的下游表现优于欧氏 VQ,**且增益幅度可由解码器首层谱的各向异性事先预测——各向同性时增益应为零。** 最后半句是它不平凡的保证:如果不管各向异性如何都有增益,那增益来自别的地方。

**为什么这一格值这么多。** 现在整套东西都在解释已知现象(KV cache 为什么合法、token healing 修的是什么、glitch token 为什么存在)。解释得再漂亮,都在「换个壳讲已知事实」的射程内。**造出一个更好的东西,才走出去。**

**它同时补掉跨域那一格。** 北极星讲全谱系,而现在只有文本。FIB-2 那个次序检验的形状在 VQ 解码器上照样能跑(读出位点换成解码器首层的各分支)。**同一条次序律在文本和图像/音频上都成立**,这是「跨系统统一记账」这个声称唯一的兑付方式。

**三个模型。** 选法不是「凑领域」,是「凑算子」——量化器的两种结构恰好对应演算里的两个组装算子:

| 量化器结构 | 怎么运作 | 对应算子 |
|---|---|---|
| **RVQ**(残差多级) | 一级的残差喂给下一级 | **串联**(塔) |
| **FSQ / LFQ**(标量或无查表量化) | 每个坐标各自独立量化 | **并联**(积) |

这个对应关系让 FIB-4 从「多领域覆盖」升级成「检验演算的两个算子」。串联上已证次可加(且否掉了自己先写的单调性),**并联上目前只有分量表、没有不等式**——结论第 64 条明写「登记为未证不许当结论用」。**并联有了实例,一个未证的空格才能变成有数据的格子。**

选定的三个,配置按 `config.json` 实测:

| 模型 | 量化器 | 实测配置 | 算子 | 域 |
|---|---|---|---|---|
| **`kyutai/mimi`** | split RVQ | 码本 2048、维 256、`num_semantic_quantizers=1` + 声学若干 | **并联套串联** | 语音 |
| **`descript/dac_44khz`** | RVQ | `n_codebooks=9`、码本 1024、维 8 | **纯串联** | 音频 |
| **`BAAI/Emu3-VisionTokenizer`** | 单级 VQ | `codebook_size=32768`、`embed_dim=4` | 单节点 | 图像 + 视频 |

三个都在 transformers 里,接入成本最低。

**Mimi 是这三个里最值钱的一个,理由是它把两个算子装在同一个模型内:** 顶层把码本分成语义支与声学支(并联),每支内部是残差多级(串联)。**于是两个算子可以在同一个模型内比较,不用跨模型——这和 FIB-2 的形状是同一个思路:同模型内比较,混淆按构造消掉。** DAC 作纯串联的独立对照,Emu3 给单节点基线并把域扩到图像。

**排除的候选,记明理由**(避免重蹈原设计选错模型那一次):

- **连续潜变量的自编码器**(如 `sd-vae-ft-mse`,类名 `AutoencoderKL`)没有离散码本,不满足 VQ 的定义。
- **NVIDIA 的 FSQ 系与 Cosmos 离散系**:权重以 `.nemo` / `.jit` 打包、许可为 `license:other`,接入成本与许可风险都不可接受。纯并联那一格因此暂缺独立模型,由 Mimi 的并联支承担。
- 备选(需要时再进):`TencentARC/Open-MAGVIT2`,LFQ 2¹⁸ 码本、逐维独立量化、Apache-2.0 不 gated,是纯并联的干净实例;代价是要接 SEED-Voken 而非 transformers,约 +1 周。

**怎么做,分两半:**

**前半(诊断,便宜)。** 三个模型上各测:码本的往返性质;以及多级结构上逐级代价与总代价的关系——这是「串联次可加」那条不等式的直接检验。Mimi 上额外测并联两支的代价与总代价的关系,填并联那个空格。

**测法有一个类型陷阱必须避开:** 不能「把码字当输入送回编码器」——码字在潜空间,编码器的输入是原始信号,这是类型错误。正确的往返是 `码字(含必需上下文) → 解码器 → 信号 → 编码器 → 量化器`。部分解码器不接受孤立的单个码字,每个模型的最小合法输入形状要逐个冻结。**而「对码字再做一次最近邻查询」只是实现层的 sanity check,不是往返证据**——码字互异时它平凡地返回自己。

**后半(干预,是分水岭那一格)。** 从头训两个小 VQ:欧氏目标 vs Φ-对齐目标,同码本大小、同数据、同预算、多种子。**从头训而不是微调现成模型**,因为两臂必须对称——微调会让 Φ-对齐那一臂继承欧氏目标训出来的表示。

### FIB-5 · 分词器级

**做什么。** 四件,都不要 GPU:

**一、自己训 matched BPE/Unigram。** 同语料、同词表规模、同 normalizer、同预处理、同特殊 token 规则,只有算法不同。

**为什么要自己训。** 理论推出一条跨算法族的预言:BPE 的商由 merge 频次定、选择由 merge 顺序定,两者分离;Unigram 的商与选择同源于一个似然。**所以 Unigram 的不可达 token 应该更少。** 但拿现成分词器比,是同时变了训练语料、词表大小、normalizer、语言覆盖六样东西,归因不到算法。**tokenizer 训练不要 GPU、小时级,这是把最原创的一条预言从描述性救回确认性的最便宜的一笔钱。**

**语料:`HuggingFaceFW/fineweb-2`(多语)为主,`HuggingFaceFW/fineweb`(纯英语)作语言轴的一端。** 两者 ODC-BY、不 gated、同厂同流水线。

分片纪律,三个职责各用不同分片:

```
分片 A(几 GB)      → 训 matched BPE/Unigram
分片 B(10B token)  → 测语料条件未出现率 + 覆盖曲线 + 频率加权
A 与 B 严格不交
```

**A 与 B 不交是硬要求,不是洁癖。** 词表是从 A 学的,拿 A 测未出现率等于自己给自己出考卷,会系统性低估。而覆盖曲线(未出现率随累计语料量怎么缩小)只有在 held-out 上画才有意义。

**语言组合取三类,因为差异只在后两类上出现:** 分析型(英)、形态丰富(俄 / 土 / 芬)、无空格分隔(中 / 日 / 泰)。英语的空格已经把大部分切分歧义消掉了,BPE 与 Unigram 的商在英语上本来就接近——**纯英语不是「小一点的实验」,是「效应被移除的实验」。**

**排除的语料,记明理由:** `CulturaX` 无独立许可标签(卡片写「许可条款严格遵循 mC4 与 OSCAR」,把问题转嫁给两个上游)且 auto-gate,许可链说不清楚,与 FIB-8 的复现性要求冲突;`RedPajama-V2` 无许可标签;`OSCAR-2301` 虽为 CC0 但需手动审批;`finewiki` 是 cc-by-sa-4.0,传染性许可会牵连产物。备选是 `HPLT 3.0`(CC0-1.0、不 gated、30T token),许可比 ODC-BY 更宽松,代价是文档与审稿人熟悉度低一档。

**二、语言作为实验轴。** `fineweb` 与 `fineweb-2` 同厂同流水线而一个纯英语一个多语,于是可以测:

> **同一套流水线下,BPE 与 Unigram 的不可达率差距,在英语上应当小于在形态丰富语言与无空格语言上。**

**这条把语言从实现参数变成一根实验轴**,并顺带回答审计一定会问的「这个差距会不会只是语言选择的产物」。杀伤条件:若差距在三类语言上无系统差异,则「商与选择分离」这个机制解释不了它,差距另有来源。

**三、字级往返三档分类。** 每个 token 解码成字符串再送回去分词,分三档:**完好**(得回自己)、**碎裂**(切成多个)、**改名**(变成另一个 token)。

有一条已证的引理让这件事干净:**改名一步终止**,所以不存在「反复重分词震荡」这种病。

**四、非规范质量。** 测「一段 token 序列解码再重新分词,还是不是原来那串」。三条违反路径各测一次:两段文本各自分词后拼接、模型自己续写、在 token 边界切断。

**这三条路径不是三个现象,是一个条件的三种违反方式**——而这是理论里最漂亮的一处:拼接边界效应、生成文本重分词、token healing 要修的东西,三个独立记录的工程病灶,恰好是一个推导出来的条件的三种破法。**而 token healing 就是把分布拉回规范集的那个投影算子本身,它不是补丁,是投影。**

**升级版的问法(审计要求)。** 原来是「非规范质量随长度单调增」,而这几乎恒真——长度越长暴露机会越多。改成检验统一性:**三条路径上,非规范质量与下游损害的关系应当是同一条曲线;且施加 token healing 的修复量应当恰好等于非规范质量预测的量,不多不少。** 如果 healing 修得比投影能解释的更多,那「healing 就是投影」这句话是修辞而不是定理。**这个版本能真死。**

**必须踩住的四个坑**(不踩会给出错答案而且不报错):

1. **byte-level 词表里一个 token 可以是多字节字符的一半**,解码返回替换符,再编码必不等于原 token。不隔离的话,CJK 词表的「碎裂率」几乎全是这个 bug。**要单列一档。** 这一条同时是理论边界的真实收窄:这类对象不是字符串,所以载体要改成字节串。
2. 编码时**必须显式关掉自动加句首标记**,否则往返永不成立,失败率是接近 100% 的假数。
3. **解码的空格清理参数要显式关掉**并记录取值。
4. **词表里有从未训练的补位行**(Qwen2.5-32B 是 152064 对 151936,差 128 行),它们会同时污染分子和分母。**所有词表级统计在两个分母下各报一次。**

**一处命名纪律(审计要求)。** 有限语料上测出来的只能叫「语料条件未出现率」,不能叫「不可达率」——枚举全部字符串不可行。而且要随累计语料量画覆盖曲线,让读者看见这个数怎么随语料缩小。**碎裂 ≠ 不可达,不许混报。**

### FIB-6 · 权重级:锚对齐机制

**做什么。** 只取两个张量(输入嵌入表、输出投影矩阵),不跑模型,做矩阵运算:对每个 token,看「拿它的嵌入去和所有输出行比,最像的是不是它自己」。

**升级版的问法。** 原来是报两个百分数(锚对齐率、嵌入范数散布),那确实是量已知的东西。但理论推出的是一个**机制**:内积的上界是两个范数的乘积,所以只在「对手范数不超过自己」时才保证 argmax 命中自己——**范数长的向量会抢范数短的向量的 argmax。**

所以可测的机制预言是:**失去 argmax 的 token 应当集中在范数短的一端,抢走它们的 token 应当集中在长的一端,而且这个关系的强度可由那个不等式定量预测。** 同样的计算量,从「报两个数」变成「检验一条机制」,而机制可以不成立。

**这条机制还接上另一件事:** 词表里有一批「只写不读」的 token——能被模型输出,但没有任何文本输入能产出它们,于是训练中只受负类梯度。理论说这批 token 的存在是必然而不是实现瑕疵。而这正是已被独立观测的 glitch / undertrained token 现象。**要查那支文献用什么指标检测——如果它本身就用嵌入范数,那它和我们的范数测量不独立,重合度会虚高。这个可能的循环必须读完文献后如实报。**

**两个会静默出错的地方:**

1. **必须用 fp32 算。** 权重是 bf16,尾数只有 8 位,而 argmax 的前两名常常差得比累加误差还小。用 bf16 会让对齐率偏低,而且不报错。
2. **分块时要维护全局最大值和全局索引。** 完整的输出矩阵是 92 GB 装不下,而「每块各取局部 argmax 再拼起来」是个很自然的错法,得到的不是全局 argmax。

### FIB-7 · 结构核查

**做什么。** 两条判断,是核查不是测量——「杀伤」是找到一个反例,不是算一个数。

**一、成对界面的方向必然相反。** 标准语言模型输入侧是「内容 → 编号 → 向量」,输出侧是「向量 → 编号 → 内容」,相反;VQ 自编码器编码侧与解码侧,相反。**最可能出反例的是字节级无固定词表的模型和动态分块模型**,因为它们的「词表」是动态的。要逐个查。

**二、双向模型即使做离散提交也不能增量缓存。** 理论说可缓存需要两个条件,不是一个:提交不可逆,**加上**追加内容不改已有部分的提交。自回归的因果掩码保证第二条,双向模型不保证。**判法**:同一个双向模型前向两次(长度 n 和 n+1),比较前 n 位的 key/value 是否逐元素不变。要同种子、同 dtype、关掉 dropout,容差事先定。

**要说清一处以免被误读:** BERT 类模型当然可以缓存整段的 key/value(全量重算后缓存)。要判的是**增量**——追加之后已有前缀变不变。

**「可缓存需两个条件」这句话要改述,因为两个条件分属不同层:** 提交不可逆是局部层的条件(值域离散),保前缀是序列层的条件(关于 $T$)。并列它们是层混。

**由此对「套壳讲废话」那个质疑有了确切答复,不是回避。** 那个质疑说「因果掩码 ⇒ 前缀不变 ⇒ 可缓存」已经闭合,改名叫「保前缀」没有增量——**这是对的,而且它对的地方正是层混:在局部层上,可缓存性确实是因果掩码的直接推论,重述它没有增量。**

有增量的是另一句:**双向模型即使做离散提交也不可增量缓存**,因为它满足局部层那条而不满足序列层那条。这句话在单层记法里写不下来——只有一个 $\tau$ 时,「提交离散」与「保前缀」看起来是同一个对象的两个性质,于是「缺哪一条」这个问题问不出来。

**故论文里这一段以对照的形式出现,不以「解释 KV cache 为什么合法」的形式出现。** FIB-7 测的是那个对照,不是那个解释。

### FIB-8 · 复现件与开跑门

**做什么。** 两半。

**一、复现件。** 审计按 46 项复现性标准打了 6/46(F 级),判定第三方无法独立复现。缺的是:数据与处理链的说明、运行入口、版本锁、产物溯源、治理信息。**顶尖会议现在把这个当门,不是加分项。** 纯活,2 周。

**二、开跑门。** 定三道机器可执行的门,防止「文档核查」「小样本试跑」「正式测量」三种状态混用:

| 门 | 过关条件 | 允许做什么 |
|---|---|---|
| **G0** 文档 | 类型系统闭合、Φ 声明冻结、manifest 齐备 | 只核查,不跑真数据 |
| **G1** 试跑 | G0 过 | 合成/小样本,**结果不得进论文** |
| **G2** 测量 | 打 tag、环境与主端点冻结 | 正式确认性数据 |

**为什么要这个。** 「能运行」不等于「可作为证据」。如果冻结项还没关就先看真实数字,后面再改协议就分不清是修 bug 还是被结果牵着走。**试跑输出目录和正式结果目录要物理分离。**

**三、profiling。** 现在所有时间与显存估计都没有实测依据。做法:在小模型上做固定 prompt 数的 profiling,记录分阶段的算力、峰值显存、I/O、墙钟,再按工作量外推区间。**在这之前,所有工期一律写「待测」。**

## 5. 与原 F 轮的差别

### 换了什么

| | 原 F 轮 | FIBER 轮 |
|---|---|---|
| 主结果的形状 | 九模型 × 十量,**跨模型**找相关 | **同模型内**,先推导后测量的次序检验 |
| 因果结论 | 想说 MLA / 规模使代价降低,审计判不可归因 | **自己训配对模型**,identified |
| 与理论核心的距离 | 测的是核心断言的下游相关物 | 直接测零核定理的实践内容 |
| 有无设计干预 | 无 | **Φ-对齐 VQ** |
| 先行工作定位 | 无 | **排在最前** |
| 跨域 | 只有文本 | 文本 + VQ 侧同一条律 |

### 砍掉了什么,和为什么

**「代价随规模下降」不再是卖点。** 它降为副结果——在 FIB-3 自训的阶梯上仍然测,但公开 checkpoint 那个四点梯子撑不起主结论。**损失是真的:这句话接得上 scaling law 那一大摊文献,读者会记住它。** 但原设计对它没有兑付能力。

**「MLA 使代价降低」不再靠跨厂商对照。** 跨模型那一对保留为描述性外部证据,主结论靠 FIB-3。

**「凸-光滑交换子」不补,改成收窄声称。** 这是一个已经失败过一次的开放问题,不该阻塞全轮。论文里把声称收窄成「序列结构的交换子,它解释三个独立记录的现象」,并明写这一族不完整。**收窄了的真声称比撑大了的空声称强。**

| R04 | 缺机器可执行的开跑门 | **FIB-8** 的 G0/G1/G2 |

**两处改判值得单独记,它们是「实现细节反过来改理论」的第三、四例**(前两例是结论第 68、69 条):

- **范数项从「$\Phi$ 的成员」改判为「落在零核里」**(B02 §3)。原规格的方向反了:被归一化吃掉意味着下游读不到,而读不到正是零核的定义。
- **KV cache 的零核要求 $\mathcal{A}$ 不预设离散**(B01 §5),而结论第 3 条早已判定离散性不是必要条件。**当初若把离散性写进必要条件,今天这条跨界面统一就做不成。**

## 8. 欠账与风险

### 必须补的欠账

**design 的设计决策已全部定案,以下三笔不阻塞阶段二与阶段三,但阻塞阶段四。**

1. **Mimi 与 DAC 的解码器首层未核实**(Emu3 已核,见 FIB-0 §5),各自的最小合法输入形状未定。阻塞 FIB-4。
2. **`fineweb-2` 的分片切法未定**(每语言取哪些 dump、A/B 各多大)。阻塞 FIB-5。
3. **FIB-1 只做了碰撞检查,没做深读。** 已读四支的定义与定理陈述,足以判定位;但项目既有的五段式 deep-read(略读→把握→深读→形式主张→整合)一篇都没走完,rate-distortion 那一支(Berger / Zador / Linder)与欠训练 token 那一支还没碰。**这两件是成文时要引的,不是开跑的门。**

**另有一件不是欠账而是尚未动工的实现活:FIB-8 的复现件与 G0/G1/G2 门。** design 规定了它们要有什么,但 manifest、锁文件、运行入口本身还没写。**这是「design 定稿」与「能开跑」之间剩下的距离。**

### 三个真风险

**一、权重级推导可能不如校准级。** 公式已写出且不会平凡通过(见 FIB-2),故原来那个「可能写不出来」的风险不存在了。剩下的是预测能力问题:权重级的 token 先验只能取均匀,而实际代价由高频 token 主导——**这是「不用数据」的结构性代价**。四臂一起报,弱于校准级也是有内容的结果,但那时论文的主张要从「架构足以决定」退到「架构决定了多少」。**另有一个跑前可算的旁路:若坍缩协方差各向同性,该检验先天无功效,这一条在花钱之前就能知道。**

**二、FIB-1 可能杀掉某条增量。** 如果 task-based quantization 那一支已经有人从架构结构导出过加权,FIB-4 的增量就得另想;如果 V-information 已经有等价的零核刻画,FIB-2 的定位要重写。**这是先做它的全部理由。**

**三、Φ-对齐 VQ 可能就是不更好。** 理论对,不代表按它设计的目标函数在实践上赢。这一条只能做出来才知道。

### 主动不做,记明理由

- **凸-光滑交换子公式**:已失败过一次,不阻塞全轮,改为收窄声称。
- **F6 微调**:原为 F1 那个未排除的替代解释而设,不值 8×80GB。
- **32B 档跨分词器**:公开权重里做不到(Llama 无 32B 档),而 FIB-3 自训后这个需求本身消失。
