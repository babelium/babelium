# F1 判决:支持,附三处修正

**判决 A**(F1 存活)。证据由 codex 检索,2026-08-15。**这是本项目第一个得到实测判决的下注。**

---

## 一、核心证据

Gu et al., ICLR 2025 Spotlight, arXiv:2410.10781, **Table 4**。60M 参数 LLaMA2 式架构,Pile 上 5B tokens;64-token 序列;判定口径为「某 layer-head 对指定位置的平均注意力 > 0.3 即计为 sink」。

| 改法 | 新槽位 sink 率 | 首内容位置 sink 率 |
|---|---|---|
| 标准 softmax | — | **18.18%** |
| 可学习 K-bias,**V 固定为零** | 73.34% | **0.00%** |
| 可学习 sink token | 74.12% | 0.00% |
| 可学习 KV-bias | 72.76% | 0.04% |

验证损失 3.73 → 3.72(K-bias 行)。

第二行是纯弃权项(不携带 value),正是 F1 指定的那个改法。**内容地址上的 sink 归零。**

---

## 二、修正一:sink 不消失,它迁移。质量守恒

F1 原文把杀死条件写成「内容地址上的 sink 应当消失或显著减弱」。这句在方向上对,在措辞上错——它暗示注意力集中现象本身会消失。实测是 0.00% 换来 73.34%:集中照旧,只是换了落点。

所以「sink」这个词一直在指两件事,必须拆开:

- **集中**(注意力质量堆在极少数位置上):不因弃权项而消失,是稳健现象。
- **落在内容地址上**:因弃权项而归零,是可消除的**症状**。

F1 解释且只解释第二件。第一件在弃权项存在时依然成立,这说明「需要一个 no-op」是真需求,而非实现缺陷。

## 三、修正二:缺的是候选项,不是归一化约束

F1 的推导把病因写成两条:候选项只由内容位置供给 + softmax 强制和为一。同一篇的 **Table 6** 把第二条单独拆开测了:

| 60M | sink 率 | | 1B | sink 率 | 验证损失 |
|---|---|---|---|---|---|
| softmax | 18.18% | | softmax | 45.11% | 3.07 |
| 无归一化 sigmoid | 0.44% | | 无归一化 | 2.46% | 3.10 |
| 无归一化 ELU+1 | 0.80% | | | | |
| sigmoid **再归一化** | 30.24% | | | | |

第四行是关键:同一个激活函数,重新加上和为一,sink 回来。这是**消融加回加**的对照,因果方向不含糊。

但把两张表并读,推翻了 F1 对病因的归属:

- 加弃权项(Table 4):sink 归零,损失 3.73 → 3.72,**免费**。
- 去归一化(Table 6):sink 大降,1B 上损失 3.07 → 3.10,**要付代价**。

结论:**和为一本身没病,病在没有东西可归。** 约束保留而补上候选项即可,且不花钱。F1 原文并列两条病因,应改为一条主因(缺候选项)加一条放大器(归一化把缺失变成强制)。

另记:sink 率随规模上升(18.18% @60M → 45.11% @1B)。若为趋势,则该结构缺陷在更大模型上更重,不是会被规模冲淡的小毛病。

## 四、修正三:弃权可插在三个位置,故病在复合映射

Qiu et al., 2025, arXiv:2505.06708。对每个 query/head 的 SDPA **输出**乘一个可趋零的 sigmoid gate。1.7B dense 与 15B MoE,训练至 3.5T tokens。首 token 平均注意力 46.7% → 4.8%;第 21 层 83% → 4%。

这里 softmax 权重**仍然归一化**,候选集也没变,sink 照样掉下来。

于是弃权项有三个可插入点,全部有效:

| 插入点 | 实现 | 证据 |
|---|---|---|
| 分母 | 可学习 K-bias | Gu Table 4 |
| value | null key,V=0 | Gu Table 4 |
| 输出 | sigmoid 输出门 | Qiu, 1.7B/15B |

三处不在同一层,却同效。所以要求不是「候选集里要有弃权项」,而是**注意力这个复合映射必须能产出「无贡献」这一结果**。

这一条把 F1 接回 $\Phi$ 框架,不是巧合:输出门之所以有效,正因为它让 attention 输出的 $\Phi$-像为零。**弃权 = 能产出 $\Phi$-零的输出**,三种实现一个要求。与 $\tau$ 统一 AR/VQ/attention 是同一类统一。

## 五、一条新推论(我的,非文献结论)

18.18% → 73.34%,弃权率是原内容 sink 率的约四倍。两个数同模型同口径,可比。

故:**内容 sink 率系统性低估了弃权需求,约四倍。**

我的解释(假说,未验证):拿内容位置当弃权代用品是**有代价**的——它会把该位置的 value 注入输出。所以模型只在不得不弃权时才这么做。一旦弃权免费(V=0),使用频率跳到真实需求水平。

若该假说成立,则可预测:内容 sink 应优先落在 value 范数小的位置上,因为那里代用品最便宜。这与 F1 原文「落在最 $\Phi$-平坦的地址」是同一句话的另一种说法,且给出了可测代理量(value 范数)。**待测。**

## 六、最接近 B 的一条,以及它为何不是 B

StreamingLLM, ICLR 2024, Table 3,160M:固定零 key/value 的 Zero Sink 之后,流式推理**仍需**保留其他初始 token。仅保留 Zero Sink 时 PPL 29214;再保留 1/2/4 个初始 token 为 19.90 / 18.27 / 18.01。

不算 B 的理由(codex 已指出):它测的是流式困惑度,不是内容位置上的 sink 强度。

我另加一条更要紧的理由:**Zero Sink 是在已训练模型上推理期加挂的**,而 Gu 的 K-bias 是**从头一起训**的。前者失败可由「模型已把路由学到位置 0 上」解释,与「弃权项无效」不同因。

由此得一个可测预测:带 Zero Sink 微调后,对初始内容 token 的依赖应下降。**待查是否已有人做过。** 另需核实 StreamingLLM 是否另有预训练带 sink token 的实验(我印象中有,但不引用未核实的印象)。

Kaul et al., ICLR 2025, arXiv:2410.17174,GPT-2/C4 上 softmax+1:首 key 为最大注意力位置的比例 53% → 2%,首 key 总注意力 46% → 4%。保留意见成立:只测首位置,不能排除迁移到其他内容 token。

Miller 的 "Attention Is Off By One":提出了但没测 sink。

## 七、附带问题:register 迁移已被直接观察,且给出 F1 的边界

Fesser et al., 2026 预印本, arXiv:2606.08105, §4。带 4 个 register 的 DINOv2-G:register 捕获跨层「几乎全部」sink mass;原有 patch 与 [CLS] sink 被排挤。

**register sink 分两型**:

- **NOP 型**:value 范数比 < 0.2。
- **broadcast 型**:value 范数约 1,产生 **rank-1 输出**。

第一型是 F1 预测的弃权。**第二型不是。** rank-1 输出意味着每个 query 得到同一个向量,那是全局广播/偏置,不是弃权。

故 F1 的覆盖边界在此划定:它解释 NOP 型,不解释 broadcast 型。且这提示**第二个缺陷**,我未曾推导:attention 也缺少「加一个与 query 无关的全局项」的合法位置,于是 register 被一并征用。

这一条不修补 F1,它开一个新口子。是否值得追,待判。

---

## 八、结论与状态

- F1 **存活**,判决 A。
- 不可升级为「加入任何固定弃权项必然清除全部内容 sink」:三处修正各自划了边界。
- 可升级的部分:**弃权 = 能产出 $\Phi$-零的输出**,三实现一要求。此句应进 S4 的机制群系。
- 新增待测两项:value 范数作为弃权代价的代理量;Zero Sink 微调后的依赖变化。
- 新增未决一项:broadcast 型 register 指向的第二缺陷。

## 九、连带影响

G1 格 4 曾把 `modeling_llama.py:216` 钉为「softmax 无弃权项」的事实。Gu Table 6 把这条从**事实**升级为**因果**:同一行代码去掉归一化则 sink 崩,加回则 sink 回。该行号现在是一条有实测因果支撑的引用点。
