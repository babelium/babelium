# M1 — 相似性面三行:可微 / 可插值 / 可泛化

> 产物一的第一批。先填相似性面,因为排表时发现这三行**基本是空的**,而同一性面五行各已有结论。
> 单格格式:判定 + 机制或遮挡物 + 出处。**没出处留空。**
> 列(七个安放):AR / VQ / diffusion 分箱 / AF2 层级 / RAG / GraphRAG / 文本输入

## 门:这三行可能杀掉什么(进表前先写)

- **可微行**可能杀「纤维可见性是区分量」:若可微与纤维可见性逐格同值,则两者中有一个多余。
- **可插值行**可能杀「两面是同一枚硬币」:若插值在载体上活、过商即死且无一例外,则相似性面根本过不了提交这道关,「同一枚硬币」在这条面相上恒假,判据须按面相分级(即 S2 计划里那个对 S3 的实质输入,会由此落地或落空)。
- **可泛化行**可能杀「地址集总在参数里」:若存在地址集不在参数里的安放,则「换地址要动模型」不是必然,而 S1 关于可数/可索引的结论都默认了它。

## 一、可微

| 安放 | 判定 | 机制 / 遮挡物 | 出处 |
|---|---|---|---|
| AR | **不成立**(界面处),载体侧另有通路 | $\arg\max$ 几乎处处零梯度;`multinomial` 采样亦不可微。但 $h_t$ 本身可微,且 forward 接受 `inputs_embeds` 故存在绕过界面的合法调用 | `generation/utils.py:2789-2793`;`modeling_llama.py:385-386` |
| VQ | **部分**,靠外部安装 | 式 (2) 的 $\arg\min$「has no real gradient」,故「just copy gradients from decoder input $z_q(x)$ to encoder output $z_e(x)$」,「during the backwards pass the gradient $\nabla_z L$ is passed unaltered to the encoder」。可行的理由是「the encoder and the input to the decoder share the same $D$ dimensional space」 | 1711.00937 §3.2,近式 (2) |
| diffusion 分箱 | **成立** | 式 (13) 的离散化解码器对整箱积分,目标对 $\mu_\theta$ 可微;不可微性没落在被优化的量上 | 2006.11239 式 (13) |
| AF2 层级 | **成立** | Algorithm 24 由扭转角经刚体变换复合出全原子坐标,复合可微 | AF2 SI Alg. 24 |
| RAG | **部分** | top-$k$ 里「哪些文档」不可微,但边缘化使检索器可微:「We marginalize the latent documents with a top-K approximation」(§1)。且文档编码器被冻住——「Updating the document encoder BERT$_d$ during training is costly as it requires the document index to be periodically updated」,故「keep the document encoder (and index) fixed, only fine-tuning the query encoder BERT$_q$ and the BART generator」 | 2005.11401 §1, §2.4 |
| GraphRAG | (待填) | | |
| 文本输入 | **前提不成立** | 不是「不可微」而是求导对象不存在:字符串集上无可微结构,分词器的输入不是连续变量 | — |

**读出来的东西。** 可微与纤维可见性**不同值**:VQ 在可微上是「部分」而在纤维可见性上是「分裂」,分箱两处都是成立,AR 两处都是否,但 RAG 在纤维可见性上是「内可见外不可见」而在可微上是「部分」——两列的分档方式不对齐。**故可微行没杀掉纤维可见性,两者独立。**

真正掉出来的是第四种格值:**前提不成立**。文本输入那格不是假,是这条面相在它上面无从提问。原计划只允许成立/不成立/部分三值,现补第四值。这不是格式松绑——**前提是否成立本身携带信息**:八个面相各自预设了载体上的某种结构(可微预设可微结构,可插值预设线性或凸结构),而**预设失败的位置恰好标出安放方式之间的真差别**。

## 二、可插值

| 安放 | 判定 | 机制 / 遮挡物 | 出处 |
|---|---|---|---|
| AR | **载体上成立,商上不成立** | 两嵌入的凸组合仍在 $\mathbb{R}^d$,但一般不属码本 $\{\mathrm{emb}(a)\}$。且 AR 前向**每步都在生产码本外的载体点**($h_t$ 几乎必然不在码本上)再量化掉它 | K2 §2:`modeling_llama.py:421/430/487` |
| VQ | **载体上成立,商上不成立** | 码字同在 $\mathbb{R}^D$ 故凸组合可算,但结果一般不属码本;式 (1) 会把它吸回某个 $e_k$ | 1711.00937 式 (1)(2) |
| diffusion 分箱 | **载体上成立,商上不成立** | 载体是 $[-1,1]$ 的连续像素值,插值良定义;箱指标是 $\{0..255\}$ 的整数,两箱心的中点一般不是箱心 | 2006.11239 式 (13),$\delta_\pm = \pm 1/255$ |
| AF2 层级 | **分裂:一个商上成立,另一个商上不成立** | 扭转角的商是连续的(圆环),插值后仍是合法扭转角;而残基类型的商是有限的,插值无定义。**同一个安放同时带两个商** | AF2 SI Alg. 24;「idealized bond angles and bond lengths」那句(理想几何即商的方向) |
| RAG | **前提不成立** | 载体是段落原文,两段文本的凸组合无定义。不是过商才死,是载体上就没有 | 2005.11401「we simply concatenate them」 |
| GraphRAG | **前提不成立** | 同上,载体是社区摘要文本 | 2404.16130(索引期图→文本) |
| 文本输入 | **前提不成立** | 同上 | — |

**这一行的产出是本批最重的一件。**

在载体可插值的四个安放上,判定**完全一致**:载体上活,过商就死。四比零。而 AF2 给出了例外的形状——**它的例外不是「过商没死」,是它有两个商,一个连续一个有限,面相在连续那个上活、在有限那个上死。**

于是规律收紧成:**插值过商而不死,当且仅当该商是连续的。** 有限商必杀插值(两代表的中点一般不是代表,这是有限集的算术事实,不是经验观察)。

这有两个后果,方向相反:

1. **对「两面是同一枚硬币」不利。** 可插值这条面相在有限商上恒假,而 token 这个概念的核心安放(AR/VQ/分箱)商全是有限的。**判据在这条面相上不能取真,只能取「载体上真、商上假」。** 门里那句「判据须按面相分级」由此落地——不是可能须分级,是已经必须分级,因为八条面相里至少有一条在主流安放上恒假,而其余(如可索引)恒真。给一个二值答案会把恒真与恒假的面相混成一个含混值。
2. **对签名有利,且新增一件结构事实:一个安放可以带多个商。** 签名 $\mathcal{I}$ 写的是单个 $\mathcal{A} = \Omega/\!\sim$。AF2 同时带残基类型(有限)与扭转角(连续)两个商,八条面相在两个商上可取不同值。**这与 K2 §3 修正四的单锚缺口是同一类缺口的第二例**:签名把本该多份的东西写成了一份。两例合起来说明缺口不是偶然。

## 三、可泛化

此处限定为**对新地址的泛化**(不是对新输入的泛化),因为这才是与商结构相关的那个问法。

| 安放 | 判定 | 机制 / 遮挡物 | 出处 |
|---|---|---|---|
| AR | **不成立**(须动参数) | 地址集烙在参数里:嵌入表形状为 `(vocab_size, hidden_size)`,加地址须改形状,框架为此专设 `resize_token_embeddings` / `_get_resized_embeddings` | `modeling_llama.py:361`;`modeling_utils.py:2604, 2702` |
| VQ | **不成立**(须动参数) | 码本大小固定,加码字须改形状 | 1711.00937 式 (1) 对 $j$ 遍历固定码本 |
| diffusion 分箱 | **不成立**(结构固定) | 256 个箱由 $\delta_\pm = \pm 1/255$ 定死,来自数据格式而非参数 | 2006.11239 式 (13) |
| AF2 层级 | **不成立** | 刚体组表(Table 2)与残基类型表固定 | AF2 SI Table 2 |
| RAG | **成立** | 地址集**不在参数里**:「we demonstrate that the non-parametric memory can be replaced to update the models' knowledge as the world changes」(§1),「This shows we can update RAG's world knowledge by simply replacing its non-parametric memory」(§4.5 Index hot-swapping)。对照:纯参数模型「need further training to update their behavior」 | 2005.11401 §1, §4.5 |
| GraphRAG | (待填,预期同 RAG 但索引期重建成本更高) | | |
| 文本输入 | **不成立** | 同 AR,共用同一张表 | 同上 |

**读出来的东西。** 门里那条被杀掉了:**地址集并非总在参数里**,RAG 是反例且原文明说这是它的卖点。六比一。

而这个反例的机制与它在别处的异常是同一件事:RAG 是全表唯一「纤维内不提交」者(对 top-$k$ 边缘化),也是唯一地址集可热换者。**两件事同源**:它之所以能换地址,是因为它从不把地址烙进参数;它之所以不必提交,是因为它可以把 $k$ 个地址一起边缘化掉。**「不提交」与「可换地址」不是两条独立观察,是同一个设计选择的两面。**

代价也在原文里:文档编码器必须冻住(§2.4),理由是索引重建太贵。**即热换地址这个能力,是用「编码器不受训」换来的。** 这一句给了 K1 的通道表一个新条目:RAG 的检索侧存在一个**被冻住的通道**,既非梯度亦非 EMA,而是完全不更新。

## 四、本批的判定汇总与新增未决

三条门的结果:

1. 可微 **没杀掉**纤维可见性(两列不对齐,独立)。
2. 可插值**杀成了半条**:「两面是同一枚硬币」在这条面相上于有限商恒假,判据**必须按面相分级**。杀的是判据的形状,不是判据本身。
3. 可泛化**杀成了**「地址集总在参数里」,反例 RAG,机制与它的「不提交」同源。

新增未决:

- **第四种格值「前提不成立」已启用**,并带来一个问法:八条面相各预设载体上什么结构?这个清单未列过,而它可能比面相本身更能区分安放方式。
- **一个安放可带多个商**(AF2),签名写不出;与单锚缺口同类,合为签名的第二处表达力缺口。
- GraphRAG 三格待填。
- 「插值过商不死 ⟺ 商连续」这条待撞:找一个连续商上插值仍死的安放,或证明它是算术必然而非经验规律。
