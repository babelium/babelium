## 一、测度 $\mu$:冻结,并指明它住在哪一层

B01 拆层之后这件事必须先说清:**局部层的测度与序列层的测度是两个不同的对象**,而原规格把它们混写成一个期望。

| 层 | 测度 | 是什么上的分布 | 谁用它 |
|---|---|---|---|
| 局部 | $\mu$ | $\mathcal{X}$ 上(残差流 / 编码器输出 / 缓存键) | 判据两项、零核、FIB-2 |
| 序列 | $\pi$ | $\mathcal{A}^*$ 上 | 非规范质量、FIB-5 |

**$\mu$ 的冻结定义:**

```
定长窗口 L = 512 token
每个 prompt 截断/采样到恰好 L
剔除:padding 位置、序列首位(无前文,分布不同族)
位置等权
温度不边缘化——五个温度各自是一个报告轴
```

**定长窗口使「位置等权」与「prompt 等权」在构造上恒等**,故审计指出的那个歧义不需要在两者之间取舍,它被消掉了。剔除比例须报。

**误差棒按文档聚类 bootstrap。** 同一文档内的位置强相关,不聚类则有效样本量虚高。**bootstrap 重抽的单位是文档,不是位置。**

## 二、估计器:期望在里面,不在外面

理论量(局部层,选择坍缩那一项):

$$\mathrm{Cost}^{\mathrm{sel}}_\Phi=\sup_{\varphi\in\Phi}\Big|\mathbb{E}_\mu\big[\varphi(u^{\mathrm{avg}})\big]-\mathbb{E}_\mu\big[\varphi(u^{\mathrm{cmt}})\big]\Big|$$

**期望在绝对值与上确界的内部。** 原规格 §7 没给保持这个次序的样本公式,于是两种实现都能声称合规而给出不同的数。

### 线性分支的主端点

$\Phi$ 的线性成员形如 $\varphi_{j,\xi}(u)=\langle W_j N(u),\xi\rangle$,$N$ 为 RMSNorm,$\xi$ 取单位向量。对固定分支 $j$:

$$\Delta_j\;=\;\mathbb{E}_\mu\Big[W_jN(u^{\mathrm{avg}})-W_jN(u^{\mathrm{cmt}})\Big]\in\mathbb{R}^{d_j}$$

$$\boxed{\ \mathrm{theory\_cost}_j\;=\;\sup_{\lVert\xi\rVert\le1}\big|\langle\Delta_j,\xi\rangle\big|\;=\;\lVert\Delta_j\rVert_2\ }$$

**先求期望,再取范数。** 反过来(先逐位置取范数再平均)是另一个量,两者一般不等。

**$v/-v$ 反例(纯代数,不需要数据):** 两个等权位置的分支差分别为 $v$ 与 $-v$。则 $\Delta_j=0$ 故 $\mathrm{theory\_cost}_j=0$;而逐位置范数的平均是 $\lVert v\rVert>0$。

**哪个对?** $\mathrm{Cost}_\Phi$ 是两个分布之间的 IPM(见 FIB-1 定位:$\mathcal F=\Phi$ 的 IPM)。IPM 问的是「$\Phi$ 里有没有函数能区分这两个分布」。若对每个 $\varphi$ 误差在期望上抵消,则**没有任何 $\varphi$ 能区分**,两个分布对 $\Phi$ 不可分——这正是理论要的意思。**所以期望在里面是对的,不是记号选择。**

### 异质性:单列,改名

抵消掉的那部分是真信息,但它不是 $\mathrm{Cost}_\Phi$。单列并改名:

$$\mathrm{local\_shift}_j=\mathrm{median}_\mu\frac{\lVert W_jN(u^{\mathrm{avg}})-W_jN(u^{\mathrm{cmt}})\rVert_2}{\lVert W_jN(u^{\mathrm{cmt}})\rVert_2}$$

**报中位数与分位数,不报均值。不许沿用 Cost 这个名字。** 论文的理论表只引 `theory_cost`,异质性图明标为次分析。

### 聚合

$\Phi$ 是各分支的并集,故按定义取 $\max_j\mathrm{theory\_cost}_j$。**但同时报逐分支的完整剖面**——因为 FIB-2 要的恰是分支之间的**次序**,取了 max 就把次序丢了。**跨分支归一化若要引入须另行定义,不得继续叫 Cost。**

## 三、范数项:原规格写反了

原规格 §6.2 把 $\varphi_0(u)=\lVert u\rVert_2$ 列为 $\Phi$ 的成员,理由是「RMSNorm 会把它吃掉,但吃掉本身是一次信息丢失,须登记」;§7.5 据此要求它单独报、不与其余合并取上确界。

**方向反了。** $\Phi$ 的定义是「下游真正读到的量」。RMSNorm 在第一步就把范数除掉,故下游**读不到**它。而「读不到」正是零核的定义。

$$\boxed{\ \lVert u\rVert_2\ \text{不是}\ \Phi\ \text{的成员,它落在零核里}\ }$$

**这不是措辞修正,它改了三件事:**

1. **$\Phi$ 变成纯线性族**,故 §2 那个 $\sup_\xi=\lVert\Delta_j\rVert_2$ 对整个 $\Phi$ 成立,不需要「除了范数项之外」这个例外。估计器因此干净。
2. **审计 H05 自动解决。** 「不提交臂的向量更短」这件事不再是需要对照的混淆项——它落在零核里,按构造不进代价。全局均值臂降为纯诊断参照,不作分母(它本来也不是数学上界,一维反例即可)。
3. **原规格的「混淆一」不再是混淆项,它是一条推论。** 「范数差会主导代价」这个担心只在范数项属于 $\Phi$ 时成立;它不属于,所以不会主导。

## 四、但 $\epsilon$ 残余是真的,而且可测

RMSNorm 是 $N(u)=u/\sqrt{\overline{u^2}+\epsilon}\cdot\gamma$。**尺度不变只在 $\epsilon$ 可忽略时成立。** 把 $u$ 换成 $cu$:

$$N(cu)=\frac{c}{\sqrt{c^2\overline{u^2}+\epsilon}}\,u\gamma,\qquad \frac{N(cu)}{N_\infty(u)}=\frac{1}{\sqrt{1+\epsilon/(c^2\overline{u^2})}}$$

其中 $c^2\overline{u^2}=\lVert cu\rVert^2/d$。故尺度不变要求

$$\lVert u\rVert^2\gg\epsilon\, d$$

**实测的 $\epsilon$ 与 $d$(2026-08-26 从各仓库 `config.json` 取):**

| 模型 | `rms_norm_eps` | $d$ | $\epsilon d$ | 阈值 $\lVert u\rVert\gg$ |
|---|---|---|---|---|
| Qwen2.5-7B | 1e-06 | 3584 | 3.6e-3 | 0.060 |
| **Qwen2.5-72B** | **1e-05** | 8192 | **8.2e-2** | **0.29** |
| Qwen3-32B | 1e-06 | 5120 | 5.1e-3 | 0.072 |
| DeepSeek-V2-Lite | 1e-06 | 2048 | 2.0e-3 | 0.045 |

**72B 的 $\epsilon$ 比其余大一个数量级,阈值因此高约 5 倍。** 而 $u^{\mathrm{avg}}$ 是凸组合、方向互相抵消,其范数可以远小于单个嵌入的范数——**所以「$\lVert u^{\mathrm{avg}}\rVert$ 是否远大于 0.29」在 72B 上不是自动成立的。**

**处置(审计 H10 要求的「带条件的近似」):**

```
必测:每个模型上 ||u_avg||² 与 ε·d 的比值分布
报:该比值的分位数,以及低于 10 的位置占比
若在某模型上该比值不够大 → 该模型的范数不完全落在零核里,
   ε 残余是一个真混淆项,须如实报,不许假设掉
```

**这一条是 B02 的实质产出之一:一个原规格写反的地方,改正之后掉出一个带具体数字的可测条件,而 72B 恰好是最危险的那个。**

## 五、白拿的一处简化:次序检验不需要归一化

原规格用无量纲比 $\rho$,理由是不同模型的 $d$ 与嵌入尺度不同故绝对代价不可比。审计 H05 指出分母不合法。

**改形状之后这个需求大部分消失了。** FIB-2 主结果是**同模型内跨读出位点的次序**,而次序在任何正的单调重标下不变——**故主端点不需要归一化。**

需要归一化的只剩「跨模型报代价的绝对量级」,而那是副结果。做法:用**逐分支的 pooled scale**,定义与 $\epsilon$、近零分母的失败规则在看结果之前冻结。

**这一处是「改形状」这个决定的第二次红利**(第一次是消掉 B03/H04)。

## 六、$m=16$ 的地位(H06)

原规格把 $\xi$ 定为「输出空间全部单位向量」,又改取 16 个 SVD 主方向,但没说这个截断量与完整上确界的关系。

**主分析用完整向量 L2**,即 §2 的 $\lVert\Delta_j\rVert_2$。这就是完整单位线性族的确切上确界,不是近似。

**16 方向那个降为另行命名的低成本敏感性分析** `cost_16`,并报捕获能量 $\lVert P_{16}\Delta_j\rVert/\lVert\Delta_j\rVert$。验收:构造与前 16 方向正交的 $\Delta_j$,截断值应为 0 而完整 L2 大于 0。**主结论只引完整 L2。**

**注意:$m=16$ 原本的动机是「$\Phi$ 里有非线性成员故上确界不好算」。范数项移出之后这个动机消失了**——纯线性族的上确界有闭式。所以 `cost_16` 现在只是一个廉价对照,不是必需品。

## 七、验收清单(对审计 B02 的四条)

| 审计要求 | 状态 |
|---|---|
| 冻结目标测度 $\mu$ | §1,定长窗口 + 位置等权;并区分了 $\mu$(局部层)与 $\pi$(序列层) |
| 线性分支主端点 $\lVert\mathbb E[\cdot]\rVert_2$ | §2 |
| 范数项单独计算 | **改判:范数项不在 $\Phi$ 里**(§3),故无此项;代之以 $\epsilon$ 残余的可测条件(§4) |
| 异质性次端点改名 `local_shift` | §2 |

**须通过的合成测试:**

```
1. v/-v 样例 → theory_cost = 0 且 local_shift > 0
2. 交换样本顺序 → 结果不变
3. 纯尺度变化 → 在 ||u||² ≫ εd 区内 theory_cost ≈ 0(范数在零核里)
                 在 ||u||² ~ εd 区内 theory_cost > 0(ε 残余可见)
   ——第 3 条的两半是 §4 那个条件的直接检验,原规格没有这一条
4. 与前 16 主方向正交的 Δ → cost_16 = 0 而完整 L2 > 0
```

## 八、须回填到别处

1. **原规格 §6.2 / §7.5 的「$\varphi_0$ 单列」与「混淆一」整段作废**,代之以 §3 的改判 + §4 的 $\epsilon$ 残余条件。
2. **结论表新增一条:** 范数落在零核里而非 $\Phi$ 里;$\epsilon$ 残余给出一个带数字的可测边界,72B 是最危险的一档。这是「实现细节反过来改理论」的第三例(前两例是第 68、69 条)。
3. **FIB-2 规格:** 主端点不需归一化(§5);`cost_16` 降为对照。
