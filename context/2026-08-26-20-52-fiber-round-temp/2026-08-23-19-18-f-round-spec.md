### 1.2 理论符号

| 符号 | 读法 | 含义 |
|---|---|---|
| $\Omega$ | 载体(carrier) | 原始内容所在的集合。文本上是字符串集;图像 VQ 上是编码器输出的连续向量空间 |
| $\mathcal{A}$ | 地址集(address set) | 词表 / 码本。形式上是 $\Omega$ 的一个商集 $\Omega/\!\sim$——即「把 $\Omega$ 里彼此等价的元素合并成一个」的结果 |
| $\sim$ | 等价关系 | 「这两份内容算同一个 token」这条规则。**设计一个 tokenizer = 在 $\Omega$ 上定一个 $\sim$** |
| $\tau$ | 提交映射(commit) | $\tau:\Omega\to\mathcal{A}^*$,把内容切成 token 序列。**注意值域是序列 $\mathcal{A}^*$ 而非单个 $\mathcal{A}$**,这一点在 §2.2 是关键 |
| $\kappa$ / $\mathrm{anc}$ | 锚点映射(anchor) | $\kappa:\mathcal{A}\to\Omega$,把一个 token 交还成内容。文本上是「token 的表面字符串」,VQ 上是「码字向量」,自回归语言模型上是「嵌入向量 $\mathrm{emb}(a)$」 |
| $\kappa^*$ | 锚点的拼接延拓 | $\kappa^*:\mathcal{A}^*\to\Omega$,逐 token 取表面形再拼起来 |
| $\mathrm{sel}$ | 选择函数(selection) | 在多个合法答案里取定一个。BPE 的 merge 优先序、自回归的 argmax 或采样、VQ 的最近邻,都是 $\mathrm{sel}$ 的实例 |
| $\Phi$ | 下游读出族 | 提交完成之后、下游实际读到的那些标量函数的集合。**它由架构决定,不由实验者挑选**,见 §6 |
| $\varphi$ | $\Phi$ 的一个成员 | 一个具体的读出函数 |
| $p$ / $\pi$ | 分布 | $p$ 是 $\Omega$ 上的分布,$\pi$ 是 $\mathcal{A}^*$ 上实际出现的 token 序列分布 |
| $h_t$ | 隐状态 | 自回归模型在位置 $t$ 的残差流向量。**提交前的载体就是它** |
| $\mathrm{emb}(a)$ | 嵌入向量 | token $a$ 在输入嵌入表里的那一行 |
| $w_a$ | 输出行向量 | token $a$ 在输出投影矩阵(`lm_head`)里的那一行 |
| $\mathcal{A}^*_{\mathrm{can}}$ | 规范切分集 | 该 tokenizer 真正能产出的 token 序列的集合,即 $\tau(\Omega)$ |
| $r$ | 字级往返 | $r(a)=\tau(\kappa(a))$:把一个 token 解码成字符串,再送回去分词。**结果可能不是原来那一个 token** |
| $R$ | 序列级往返 | $R(w)=\tau(\kappa^*(w))$:把整条序列解码再重新分词 |

### 1.3 项目内的概念术语

| 术语 | 含义 |
|---|---|
| **承诺(commitment)** | 在一个欠定的选择上取定一个代表这一事件。同一个字符串有多种合法切分而必须选一种,一整个连续区域映到同一个码字而回来时只能给出码字本身——两者是同一件事 |
| **安放方式(placement)** | 「连续↔离散的换算被放在架构的哪个位置」。五个已研究的安放:自回归采样、向量量化、扩散步进、层级粒度、检索 |
| **纤维(fiber)** | $\tau^{-1}(a)$,即所有被映到同一个地址 $a$ 的内容。**纤维内的差异是被 $\sim$ 抹掉的那部分** |
| **商坍缩 / 选择坍缩** | 一次提交里的两种独立信息损失:商坍缩 = 纤维内的位置被抹掉;选择坍缩 = 地址上的整个概率分布被压成被选中的那一个 |
| **截面(section)** | 若 $\tau(\kappa(a))=a$ 对所有 $a$ 成立,则称锚点是商的截面。直觉:「每个 token 的表面形送回去分词能得回它自己」 |
| **零核(zero kernel)** | 代价恒为零的那些情形。定理:代价恒零 ⟺ $\Phi$ 里每个函数都只依赖地址而看不见纤维内位置 |
| **绑定 / 不绑定(tied / untied)** | 输入嵌入表与输出投影矩阵是否是同一张表(`tie_word_embeddings`)。绑定时 $w_a=\mathrm{emb}(a)$,不绑定时两者是不同的矩阵 |
| **MLA(多头潜在注意力)** | DeepSeek-V2 系用的注意力:在算 query/key/value 之前先把隐状态压到一个低秩瓶颈。**它等于在提交之外多插了一次商** |
| **GQA(分组查询注意力)** | 多个 query 头共享一组 key/value 头。Llama 3、Qwen2/3 用它 |
| **RMSNorm** | 一种归一化:$\hat u = u/\sqrt{\overline{u^2}+\epsilon}\cdot\gamma$。**它会把输入向量的长度信息除掉,只留方向**,这一点在 §7.5 是关键 |
| **token healing** | 一个工程上已知的修补手段:当提示词在 token 边界处被截断时,回退若干字符再重新分词,避免切分错位 |
| **attention sink** | 注意力汇点:模型把大量注意力权重堆到某个语义上无意义的位置(常是第一个 token) |
| **glitch token / undertrained token** | 词表里一批行为异常的 token,给模型输入它们会导致乱答。已有独立研究用嵌入指标检测它们 |

## 2. 理论背景

**只读本节即可理解十条预言从哪来。不需要理论全文。**

### 2.1 核心主张

一个 token 有两面:一面是**离散可寻址的同一性**(可数、可索引、可缓存、可复用、可组合),一面是**连续可比较的相似性**(可微、可插值、可泛化)。流行的说法是「这是同一枚硬币的两面」。

**本理论的结论是这个比喻错了。** 两面不在同一枚硬币上,它们在**商映射的两侧**:同一性面活在商集 $\mathcal{A}$ 上,相似性面活在载体 $\Omega$ 上,而商映射 $\tau$ 就是那个把前者造出来、把后者杀掉的操作。所以「两面何时是同一枚硬币」这个问法预设了两面可比,而它们不可比。

**正确的问法是:商映射抹掉的东西,下游还需不需要。**

### 2.2 判据(要被检验的那个量)

「需不需要」被做成一个可测的量。一次提交有**两种独立的信息损失**,故判据有两项:

$$\text{第一项(商坍缩)}\quad \mathrm{Cost}_\Phi(p)=\sup_{\varphi\in\Phi}\big|\mathbb{E}_{\kappa\tau p}[\varphi]-\mathbb{E}_p[\varphi]\big|$$

读法:把内容换成它所属地址的锚点之后,下游读到的量变了多少。

$$\text{第二项(选择坍缩)}\quad \mathrm{Cost}^{\mathrm{sel}}_\Phi=\sup_{\varphi\in\Phi}\Big|\mathbb{E}\big[\varphi(\textstyle\sum_a p_t(a)\,\mathrm{anc}(a))\big]-\mathbb{E}\big[\varphi(\mathrm{anc}(a_t))\big]\Big|$$

读法:「按概率加权的平均锚点」与「实际被选中的那一个锚点」,下游读到的量差多少。

**三件必须理解的性质:**

1. **判据是相对量,不是绝对度量。** 它带一个参数 $\Phi$,而这不是缺陷:绝对版本必然自相矛盾,因为同一次承诺在一个下游指标下很便宜、在另一个下游指标下很贵。
2. **右侧是反事实量。** 「若不提交会怎样」下游从来不计算,所以判据不能靠观察一次前向来测,**必须人为造出「不提交」那一臂**。这是实验 F2 存在的理由。
3. **零核定理:代价恒零 ⟺ $\Phi$ 里每个函数都只依赖地址 ⟺ 纤维对下游不可见。** 这条与数据无关,只取决于架构读什么。故 $\Phi$ 必须在测量前从架构读出并写死——这是纪律 F0。

### 2.3 一次地基修复(为什么实验设计和一年前想的不一样)

判据的两处推导都依赖「锚点是商的截面」,即 $\tau(\kappa(a))=a$。而这条在文本上**假**:token `" hello"` 的表面形是字符串 `" hello"`,该串单独送去分词,贪心最长匹配可能给出另一种切分。token healing 修的就是这件事。

**修复的结论是:失效在层级上,不在普遍性上。**

$\tau$ 的值域是序列 $\mathcal{A}^*$ 而不是单个 $\mathcal{A}$,所以往返有两个:字级的 $r(a)=\tau(\kappa(a))$ 与序列级的 $R(w)=\tau(\kappa^*(w))$。

- **字级截面确实假**(这是实验 F3 要测的)。
- **序列级截面由无损性自动成立。** 若分词无损($\kappa^*\tau=\mathrm{id}$),则 $R(R(w))=R(w)$,即 $R$ 幂等,且它的像等于它的不动点集,等于规范切分集 $\mathcal{A}^*_{\mathrm{can}}$。所以在规范切分上,锚点是真截面。

**两个后果直接决定实验设计:**

**后果一:定理的假设换了性质。** 从「分词器的性质」(查词表可判)变成「输入分布的性质」($\pi$ 是否支撑在规范切分集内)。而该假设的违反只能来自**不经分词器而直接造出 token 序列**的三条路径:

1. 两段文本各自分词后拼接 → 已知现象:提示词边界效应、few-shot 模板不稳
2. 模型自回归续写(逐位从词表采样,从不过分词器) → 已知现象:生成文本重新分词后切法不同
3. 在 token 边界处切割/截断/缓存复用 → 已知现象:token healing 要修的正是这个

**三条独立记录的工程病灶,恰好是一个推导出来的条件的三种违反方式。而 token healing 就是把分布拉回规范集的投影算子 $R$ 本身**——它不是补丁,是投影。

**后果二:截面代价的上界给了实验一个明确的测量目标。**

$$\mathrm{Cost}^{\mathrm{sec}}\le 2\lVert\bar\Phi\rVert_\infty\cdot\underbrace{\pi\big(\mathcal{A}^*\setminus\mathcal{A}^*_{\mathrm{can}}\big)}_{\text{非规范质量}}$$

**要测的是「非规范质量」——按实际出现频率加权,不是按词表条目均匀计数。** 词表上均匀平均对应不到任何代价。

### 2.4 不可达 token 的推导

记 $\mathcal{A}_{\mathrm{reach}}$ = 出现在某个规范切分里的 token 集合。不在其中的 token **可以被模型输出,但没有任何文本输入能产出它**。于是它在训练中既不作为输入出现、也不作为目标出现,其嵌入与输出行向量只受负类梯度。

**理论由此推出:词表里存在一批「只写不读」的 token,行为异常。** 这正是已被独立观测的 glitch / undertrained token 现象。

**更进一步:这类 token 的存在是必然,不是实现瑕疵。** 因为商由等价关系 $\sim$ 决定,而可达性由选择函数 $\mathrm{sel}$ 决定——两者是不同的东西,没有理由一致。BPE 的商由 merge 频次定、选择由 merge 顺序定,二者分离;Unigram 的商与选择同源于一个似然。**故预言:Unigram 族的不可达率应低于 BPE 族。这是跨算法族的对照。**

### 2.5 签名:把一个安放方式写下来的记法

$$\mathcal{I}=\big(\Omega^+,\ \mathbf{Q},\ \mathcal{X},\ c,\ \mathrm{anc}_{\mathrm{scr}},\ \mathrm{anc}_{\mathrm{ret}},\ \mathrm{sel},\ \omega\big)$$

| 件 | 含义 |
|---|---|
| $\Omega^+=\Omega\sqcup\{*\}$ | 载体,外加一个「缺席」元素。**这个 $*$ 是 attention sink 现象的来源,见 §2.6** |
| $\mathbf{Q}$ | **商图**:节点是商,边是商之间的映射。允许两种复合——并联(载体分解为积,各分量各取商)与串联(商的商) |
| $\mathcal{X}$ | 相似性所居的承载(通常是某个向量空间) |
| $c$ | 比较函数(内积、负距离、或「是否匹配」) |
| $\mathrm{anc}_{\mathrm{scr}}$ | **打分用的锚**:进 $c$,决定选谁 |
| $\mathrm{anc}_{\mathrm{ret}}$ | **交还的锚**:决定交出什么 |
| $\mathrm{sel}$ | 选择函数。**签名里唯一有实质自由度的件**——其余七件说「界面长什么样」,它说「界面做什么」 |
| $\omega$ | 哪一面是给定的:内容优先(id-prim)还是表示优先(sim-prim) |

提交写成:$\tau(x)=\mathrm{sel}\big(\arg\max_a c(x,\mathrm{anc}_{\mathrm{scr}}(a))\big)$,交还写成 $\kappa=\mathrm{anc}_{\mathrm{ret}}$。

**锚点裂成一对这件事有实验后果。** 绑定权重时两个锚是同一张表;不绑定时打分用 $w_a$、交出的是 $\mathrm{emb}(a)$,是两张表。于是截面条件展开成

$$\arg\max_b\ c\big(\mathrm{anc}_{\mathrm{ret}}(a),\ \mathrm{anc}_{\mathrm{scr}}(b)\big)=a\qquad\forall a$$

**两个锚系统都在里面**,所以截面性有第二条失效来源:两张表不对齐。这条是裂开之后才写得下来的,它直接给出实验 F7 要测的锚对齐率。

**商图的两种复合各有实例:** 并联——AlphaFold2(同时带有限的残基类型商与连续的扭转角商)、product quantization、多码本 VQ。串联——规范切分、residual VQ、层级粒度(字节→片段→词)、**MLA**。

**已证的一条不等式(串联次可加):** $\mathrm{Cost}_\Phi(\tau_2\tau_1)\le\mathrm{Cost}_\Phi(\tau_1)+\mathrm{Cost}_\Phi(\tau_2)$。方向与直觉相反:**多插一层商可以降低总代价。** 这是 P6 的来源。

**一条被否掉的猜想,记明以防重犯:** 「代价沿串联单调不减」**假**。反例是退化商——把一切压成一点,则复合平凡地保任何结构,而单独一层可以不保。

### 2.6 弃权与 sink

弃权 = 能产出「$\Phi$ 读作零」的输出。若 $\mathrm{sel}$ 的值域里没有「空」这个值,则每次调用必须交出某个真 token,**弃权不可表达**。三种已知实现(视觉模型的 register 位、注意力 bias、VQ 的 null 码字)都是同一件事:在地址集里外加一个 $*$。

**故 attention sink 的必然性是签名的一条推论:病在 $\mathcal{A}$ 只是 $\Omega$ 的商而不是 $\Omega^+$ 的商——注意力权重必须和为一,但没有东西可归。**

### 2.7 可缓存的两个条件

序列结构上有强弱两级:

- **弱级(保前缀)**:$[\tau(x\cdot y)]_{1:|x|}=\tau(x)$——追加内容不改已有部分的提交。
- **强级(保拼接)**:$\tau(x\cdot y)=\tau(x)\cdot\tau(y)$。强蕴含弱,反之不然。

自回归精确落在两级之间:因果掩码保证弱级成立(**这正是 KV cache 合法的充要条件**),强级失败即提示词边界效应。

**故可缓存需要两个条件,不是一个:** $\mathrm{sel}$ 值域离散(提交不可逆)**加上** $\tau$ 保前缀(因果掩码)。**这解释了为什么双向模型即使做离散提交也不能增量缓存——它缺第二条,不缺第一条。**

## 3. 十条预言与杀伤条件

**所有阈值在看到任何数据之前写死。「事先任选」是合法的,「事后调整」不是。**

| # | 预言 | 杀伤条件 | 需要 GPU |
|---|---|---|---|
| **P1** | 绑定模型的锚对齐率 ≈ 1;不绑定模型的低于绑定组 | 任一绑定模型的对齐率 < 0.95 → 「绑定 ⇒ 锚对齐」错;或不绑定组中位数 ≥ 绑定组最小值 → 绑定这一列不预测对齐。**须同时报完整分布,不只报是否过阈** | 否 |
| **P2** | 语料未出现的 token 集与文献中的欠训练 token 集高度重合 | 按频段分层后的 lift ≤ 2.0(即未出现 token 落入欠训练集的概率不到同频段基线的两倍)→ 不可达不是欠训练的原因 | 否 |
| **P3** | Unigram 族的不可达率 < BPE 族 | 两族中位数之差 ≤ 0,或 Mann–Whitney 单尾 $p>0.05$。每族样本 ≥ 4 个分词器 | 否 |
| **P4** | 自生成续写的非规范质量随长度单调增 | 在 {64,128,256,512,1024} token 五点上 Spearman 相关 ≤ 0 或 $p>0.05$ | 是 |
| **P5** | 选择坍缩代价随模型规模下降 | 主梯五点上 Spearman(规模, 代价)≥ 0。**且须在锚对齐率与绑定状态作协变量后仍成立**——若控制绑定后趋势消失,记为「趋势由绑定解释」而非 P5 成立 | 是 |
| **P6** | MLA 架构的商坍缩代价低于非 MLA 对照 | **等维版本**下 MLA 不低于对照 → P6 由 $\Phi$ 维数差解释,不成立。自然版与等维版都须报 | 是 |
| **P7** | 嵌入行范数散布使 argmax ≠ 最近邻 | 行范数变异系数 $\sigma/\mu\le0.01$(近似齐一)→ 内积量化与欧氏量化实质等价,该区分无实测意义 | 否 |
| **P8** | 自回归的 $\lVert h_t-\mathrm{emb}(a_t)\rVert$ 不受压制;VQ 的受压制 | 自回归上该量随生成步不增(Spearman ≤ 0)→ 「自回归无提交约束项」不产生可观测后果 | 是 |
| **P9** | 成对界面的 $\omega$ 必然相反 | 存在一个实例两侧 $\omega$ 相同 → 签名错。**判法:$\omega$ 由「锚点的值域是 $\Omega$ 还是 $\mathcal{X}$」判定** | 否 |
| **P10** | 双向模型即使离散提交也不可增量缓存 | 存在一个双向模型有合法增量缓存(追加输入后已算前缀的 key/value 逐元素不变)→ 「可缓存需两条件」错 | 否 |

**P5 的推导来源**(它是唯一必须要大模型的一条):大模型每步的输出分布更尖锐,故按概率加权的平均锚点离被选中的锚点更近,选择坍缩付的代价更小。**这句话单个模型测不出来,必须要规模阶梯。所以 32B 那张卡的价值全押在 P5 与 P6 上。**

**P6 的推导来源:** MLA 在 query/key/value 之前多插一次低秩压缩,故下游读到的量维数更低;按零核定理,$\Phi$ 越小则零核越大、代价越低。**这个来源是从两个 config 数值读出来的**(`kv_lora_rank=512` 对 `hidden_size=2048`),不是直觉。

**三条须单独说明:**

- **P2 的文献我还没读。** 「用嵌入指标检测欠训练 token」那一支需先读、先确认其判定方法,再定重合度算法。**若其方法本身用嵌入范数,而 P7 也测范数,则两者不独立、重合度会虚高。** 这个可能的循环须在读完之后判定并如实报。
- **P1 与 P7 不独立,P7 是 P1 的机制。** 绑定时 $\arg\max_b\langle e_a,e_b\rangle=a$ 要求 $\lVert e_a\rVert^2\ge\langle e_a,e_b\rangle$ 对所有 $b$;而 Cauchy–Schwarz 只给 $\langle e_a,e_b\rangle\le\lVert e_a\rVert\lVert e_b\rVert$,**故只在 $\lVert e_b\rVert\le\lVert e_a\rVert$ 时才有保证——范数长的向量会抢范数短的向量的 argmax**。所以范数散布不是几何图像的装饰,它是锚对齐在权重级失效的原因。
- **P9 与 P10 是结构核查不是测量**,它们的「杀伤」是找到一个反例,不是算一个数。

## 4. 模型网格

### 4.1 为什么不是「挑九个大模型」

跨厂商的模型同时换了分词器、训练数据、架构,所以跨厂商的差异归因不到任何单一原因——这是评审一定会问的。网格必须能**分别**锁住变量:

| 对照类型 | 锁住 | 变动 | 用来测 |
|---|---|---|---|
| 同厂跨规模 | 分词器 + 架构 | 规模 | P5 |
| 同规模跨厂 | 规模 | 分词器 + 架构 | 判据是否跨厂可比 |
| 同规模同类跨注意力 | 规模 + 稀疏性 | GQA vs MLA | P6 |
| 同分词器跨训练 | 分词器 + 架构 + 规模 | 训练过程 | 分离分词器效应与训练效应 |

第四行的理由:P1 与 P2 测的是**权重的性质**,而权重同时受词表和训练影响。缺这一行,则「对齐率低是因为不绑定」与「对齐率低是因为这家训得不同」分不开。

### 4.2 主梯:Qwen2.5 五点(同厂跨规模)

|---|---|---|---|---|---|---|
| 0.5B | `Qwen/Qwen2.5-0.5B` | 151936 | 896 | 24 | **true** | ✅ |
| 1.5B | `Qwen/Qwen2.5-1.5B` | 151936 | 1536 | 28 | **true** | ✅ |

✅ 项来源:各仓库 `raw/main/config.json`,2026-08-23 实测。

**梯子上有两个断点,必须当协变量处理,不能忽略:**

**断点一:绑定状态与规模共变。** 0.5B 与 1.5B 绑定,32B 不绑定。**这不是可以绕开的**——Qwen 全家都是小模型绑定、大模型不绑定。两条处置都要做:(a) 先核实 3B/7B 的绑定值以确定断点位置,把梯子切成两段各自看趋势;(b) 用 P1 的锚对齐率作协变量——若代价随规模下降而对齐率不随规模系统变化,则下降不归因于绑定状态。

**断点二:32B 的词表是 152064 而其余是 151936,差 128 行。** 这 128 行大概率是对齐补位、从未被训练。**它们会把锚对齐率的分母污染约 8.4e-4,并把「未训练行」混进「不可达 token」。** 处置:所有词表级统计一律在两个分母下各报一次——名义 `vocab_size`,以及分词器实际长度 `len(tokenizer)`,差集单列。

## 6. $\Phi$ 声明

### 6.1 $\Phi$ 是什么,为什么必须按架构分写

$\Phi$ = 提交完成之后、下游真正读到的那些标量函数。**它不是实验者挑的,是架构决定的**:提交交出 $\mathrm{emb}(a_t)$ 之后,下一层拿它做什么,那些「做什么」就是 $\Phi$。

**纪律 F0 要求 $\Phi$ 在测量之前从架构读出并写死。** 理由:选 $\Phi$ 就是选度量,而若能看了结果再选,任何安放方式都能被说成代价小。**这条纪律是判据非空的唯一保证。**

原计划两个同族模型,一份声明够用。跨三厂之后不够:Qwen 的归一化位置与 Llama 不同,DeepSeek 某些版本用 MLA——MLA 把 key/value 压过一道,「下一层读到什么」这句话的含义就变了。**故三份声明。**

**下面每份都须在执行前用该厂的 `modeling_*.py` 源码逐行核对。⬜**

### 6.2 $\Phi_{\mathrm{GQA}}$ — Llama / Qwen2 / Qwen3(dense 与 MoE,非 MLA)

提交后的量 $u=\mathrm{emb}(a_t)\in\mathbb{R}^d$ 依次经过:

1. **RMSNorm**:$\hat u=u/\sqrt{\overline{u^2}+\epsilon}\cdot\gamma$。故 $\Phi$ 含 $\varphi_0(u)=\lVert u\rVert_2$——归一化会把它吃掉,但**吃掉本身是一次信息丢失,须登记**。
2. **五个线性投影**:$W_q\hat u$、$W_k\hat u$、$W_v\hat u$,以及前馈网络的 $W_{\mathrm{gate}}\hat u$、$W_{\mathrm{up}}\hat u$。

$$\Phi_{\mathrm{GQA}}=\big\{u\mapsto\langle W\hat u,\xi\rangle\ :\ W\in\{W_q,W_k,W_v,W_{\mathrm{gate}},W_{\mathrm{up}}\},\ \xi\ \text{为该矩阵输出空间的单位向量}\big\}\cup\{\lVert u\rVert_2\}$$

**实践上取有限子族**:$\xi$ 取该 $W$ 输出的前 $m$ 个主方向,由 $W$ 的奇异值分解确定。**$m$ 在执行前写死为 $m=16$。**

**为什么只取第一层而不是全部层:** $\Phi$ 的定义是「提交后紧接着读到的」。往深处走会把后续层的非线性混进来,那时测的不再是提交的代价。**这是范围限定而不是省事**——更深的量可以另立一族,但两者不能混报。

### 6.3 $\Phi_{\mathrm{MLA}}$ — DeepSeek-V2 系

MLA 在 query/key/value 之前多插一次低秩压缩(`kv_lora_rank=512`,而 `hidden_size=2048`)。故下一层实际读到的不是 $W_k\hat u$,是 $W_k^{\uparrow}(W^{\downarrow}\hat u)$,中间过了 512 维瓶颈。

$$\Phi_{\mathrm{MLA}}=\big\{u\mapsto\langle W^{\downarrow}\hat u,\xi\rangle:\xi\in\mathbb{R}^{512}\ \text{单位向量}\big\}\cup\{\text{rope 分支的}\ W^{\mathrm{rope}}\hat u\}\cup\{\lVert u\rVert_2\}$$

**$\Phi_{\mathrm{MLA}}$ 的维数(512 + 64 rope)低于 $\Phi_{\mathrm{GQA}}$ 的(每头 128 × 头数)。按零核定理,$\Phi$ 越小零核越大、代价越低——这就是 P6 的来源,而它是从 config 的两个数读出来的。**

**但立刻出一个混淆项,必须报:$\Phi$ 维数不同则上确界的取值范围不同,故 P6 的比较本身不公平。** 处置:**P6 一律报两个版本**——(a) 各厂自然 $\Phi$;(b) 两厂都截到同一维数 $m=16$ 主方向。**若只有 (a) 出正结果而 (b) 不出,则 P6 的正结果全部来自维数差,不是 MLA 的性质。** 这条须事先写死。

### 6.4 $\Phi_{\mathrm{VQ}}$ — 向量量化模型(F5)

提交交出码字 $e_k$,下游是解码器第一层(通常是卷积)。$\Phi_{\mathrm{VQ}}=\{e\mapsto\langle\mathrm{Conv}_1(e),\xi\rangle\}$,$\xi$ 同样取前 16 个主方向。**⬜ 须按所选模型的解码器首层核对,不同 VQ 实现首层不同。**

### 6.5 三条纪律(执行前冻结)

1. **$m=16$ 主方向、只取第一层、$\xi$ 由权重矩阵的奇异值分解确定——这三条在见到任何数据之前写死**,不因结果调整。
2. **主方向的分解只用权重矩阵,不用任何激活统计。** 用了激活就是看了数据,违反纪律 F0。
3. **三份 $\Phi$ 的差异(维数、瓶颈)须随结果一起报告**,因为跨厂比较的公平性完全取决于它。

## 7. 实验 F0–F7 逐项规格

**八项不是同一种东西:F0 是一条纪律,F1 是一个已判的文献赌局,F2–F7 是实验。这个混用是编号不齐的历史遗留,此处讲清。**

### 7.1 F0 · $\Phi$ 预先声明规则(纪律,非实验)

- **类型**:纪律。无模型、无 GPU、无运行、不测任何东西。
- **内容**:$\Phi$ 必须在测量之前从架构读出并写死,不许看了结果再挑。
- **地位**:它约束其余所有实验,且是判据非空的唯一保证。见 §6。

### 7.2 F1 · attention sink 是弃权缺失的必然(文献赌局,已判决)

- **类型**:文献赌局——先写下赌注与杀伤条件,再取证据,再写判决。无模型、无 GPU。
- **读的是别人跑的结果**,例如:加入 key-bias 后 content sink 从 18.18% 降到 0.00%,验证损失从 3.73 变为 3.72。
- **判决:存活,但我自己错了三处并已改**——sink 是迁移不是消失;病不在「注意力权重和为一」而在「没有东西可归」;缺陷在注意力这个复合映射而非 softmax 一件。
- **未排除的替代解释**:文献里 Zero Sink 失败是在推理期事后改的,而成功的那次是从头训的。**这个替代解释是 F6 存在的唯一理由。**

### 7.3 F7 · 权重级:锚对齐率、行范数、不可达交叉(P1 / P7,零 GPU)

- **真东西上的实验**(真实开源模型权重,不是玩具)。
- **输入**:每个模型只取两个张量——`model.embed_tokens.weight`($E\in\mathbb{R}^{V\times d}$)与 `lm_head.weight`($W\in\mathbb{R}^{V\times d}$)。绑定时二者同一张。
- **不运行模型**,只做矩阵运算。
- **算什么**:对每个 token $a$ 求 $\arg\max_b\langle E_a,W_b\rangle$,看是否等于 $a$;命中比例即锚对齐率。同时取 $E$ 的行范数分布。

```python
import torch
from safetensors.torch import load_file
from transformers import AutoTokenizer

def anchor_stats(emb_path, head_path, emb_key, head_key, model_id, block=4096):
    E = load_file(emb_path)[emb_key].float()          # fp32,理由见 §8 坑一
    W = E if head_path is None else load_file(head_path)[head_key].float()
    V, d = E.shape
    tok = AutoTokenizer.from_pretrained(model_id)
    n_real = len(tok)                                  # 含 added token 的真实上界

    row_norm = E.norm(dim=1)                           # P7
    best_val = torch.full((V,), -float("inf"))
    best_idx = torch.zeros(V, dtype=torch.long)
    for s in range(0, V, block):                       # 按 b 分块,理由见 §8 坑二
        logits = E @ W[s:s+block].T                    # (V, block) fp32
        v, i = logits.max(dim=1)
        upd = v > best_val                             # 维护全局 argmax,不是局部
        best_idx[upd] = i[upd] + s
        best_val[upd] = v[upd]
        del logits
    hit = (best_idx == torch.arange(V))
    return {
        "AAR_full":  hit.float().mean().item(),                 # 分母 = vocab_size
        "AAR_real":  hit[:n_real].float().mean().item(),        # 分母 = len(tokenizer)
        "n_pad":     V - n_real,
        "norm_cv":   (row_norm.std() / row_norm.mean()).item(), # P7 的杀伤量
        "norm_q":    torch.quantile(row_norm,
                                    torch.tensor([0.,.01,.5,.99,1.])).tolist(),
        "miss_ids":  torch.nonzero(~hit).flatten().tolist(),    # 交给 P2 求交集
    }
```

**`block=4096` 的理由**:每块 152064×4096 的 fp32 约 2.5 GB,峰值可控。

### 7.4 F3 · 分词器级:三档分类、不可达、非规范质量(P2 / P3 / P4 的一部分)

- **真东西上的实验**(真实分词器,不是玩具)。**不需要模型权重,零 GPU,分钟到小时级。**
- **但不是零成本**:HuggingFace 上下载大量分词器需要存储与良好网络,这一点此前被漏算过。

**测量一:字级往返三档分类**

```python
def roundtrip_class(tok):
    out = {"intact": [], "fragment": [], "rename": [], "undecodable": []}
    for a in range(len(tok)):
        if a in tok.all_special_ids: continue          # 特殊 token 无表面形,单列
        s = tok.decode([a], skip_special_tokens=False)
        if "�" in s:                              # 见 §8 坑三
            out["undecodable"].append(a); continue
        back = tok.encode(s, add_special_tokens=False)  # 见 §8 坑四
        if back == [a]:            out["intact"].append(a)
        elif len(back) > 1:        out["fragment"].append(a)
        else:                      out["rename"].append(a)
    return out
```

三档的含义:**完好** = 该 token 是自身表面形的规范切分;**碎裂** = 单独出现时该 token 不会被产出,只在更长上下文里被产出;**改名** = 另一个 token 编码同一串且优先。

**一条已证的引理(改名一步终止):** 若 $r(a)=(b)$ 且 $b\neq a$,则由无损性 $\kappa(b)=\kappa(a)$,故 $r(b)=(b)$,即 $b$ 完好。**所以字级往返没有长于 1 的环,不存在「反复重分词震荡」这种病。**

**测量二:不可达 token(P2)**

$\mathcal{A}_{\mathrm{reach}}$ 的定义是「出现在某个规范切分里」。**枚举全部字符串不可能,故只能给下界**:在语料上跑分词器,收集出现过的 id 集合。

**报的是「在该语料下未出现」,不是「不可达」。** 两者的差别必须写明:前者可测,后者是前者在语料趋于无穷时的极限。**故 P2 的正确陈述是「语料未出现集 ∩ 欠训练集」,而语料规模是协变量。** 语料定为多语混合、10B token 量级(具体来源 ⬜)。

**碎裂 ≠ 不可达,不许混报。** 碎裂只说明该 token 单独出现时不被产出,它仍可能在更长上下文里被产出。真不可达的判据是语料未出现,碎裂只是嫌疑。

**测量三:非规范质量(P4 的核心量)**

```python
def noncanonical_mass(tok, seqs):     # seqs: List[List[int]],真实出现的 token 序列
    bad = tot = 0
    for w in seqs:
        s = tok.decode(w, skip_special_tokens=True)
        R_w = tok.encode(s, add_special_tokens=False)   # 这就是 R = τ∘κ*
        tot += 1; bad += (R_w != w)                     # 不动点判定
    return bad / tot
```

三条违反路径各测一次(对应 §2.3 的三条):**(a) 拼接** — 两段文本各自 encode 后 concat;**(b) 自生成** — 模型续写的 token 序列(需要模型,与 F2 同跑);**(c) 边界切割** — 在随机 token 边界处截断再拼。**(a) 与 (c) 零 GPU,(b) 不是。**

**须报两个口径:** 上面的函数报「有多少条序列非规范」;而 §2.3 的上界要的是**按频率加权的质量**,故还须报「不动点失败的 token 位置数 / 总 token 数」。**两个数会差很多**(一条长序列只错一处也算整条失败),混用会把上界算错。

**注意:用同一分词器切出来的语料,非规范质量恒为零。** 所以真正的测量必须在生成文本或拼接文本上做——这正是三条路径存在的理由。

### 7.5 F2 / F4 · 三臂前向:选择坍缩代价与范数预言(P4 / P5 / P6 / P8,需要 GPU)

- **真东西上的实验。纯推理,不训练不微调。**
- **模型**:§4 的全部九个。
- **取什么**:每个位置的 logits(算出地址上的分布)、嵌入矩阵、以及下游第一层实际读到的量。

**三臂的确切构造。** 位置 $t$ 上,由隐状态 $h_t$ 得地址分布 $p_t=\mathrm{softmax}(Wh_t/T)$:

| 臂 | 喂给下一位置的输入 | 作用 |
|---|---|---|
| **提交臂** | $u^{\mathrm{cmt}}_t=\mathrm{emb}(a_t)$,$a_t=\arg\max p_t$ | 照常运行 |
| **不提交臂** | $u^{\mathrm{avg}}_t=\sum_a p_t(a)\,\mathrm{emb}(a)$ | 判据右侧那个反事实量 |
| **上界臂** | $u^{\mathrm{glb}}=\frac1V\sum_a\mathrm{emb}(a)$,与 $t$ 无关 | 归一化参照,理由见下 |

**为什么可以这样喂**:自回归模型的前向接受 `inputs_embeds` 参数,所以「不提交」那一臂是合法调用,不用改模型,三臂共用同一个前向。

**三个混淆项,各配对照(不缩水,给对照):**

**混淆一:范数。** $u^{\mathrm{avg}}$ 是凸组合,方向互相抵消,所以它的长度必然远小于 $u^{\mathrm{cmt}}$。**若不处理,测出来的代价几乎全部是范数差,与「承诺」无关。**
处置:RMSNorm 在第一步就把长度除掉了,故 $\Phi$ 里除 $\varphi_0=\lVert u\rVert$ 之外的成员**天然只看方向、不受长度影响**。因此 $\varphi_0$ 那一项**单独报,不与其余合并取上确界**。这是 §6.2 把长度单列的实质理由。

**混淆二:离流形程度。** $u^{\mathrm{avg}}$ 是模型没见过的输入。**正确做法是把它当协变量测掉,不是拿它当缩小实验范围的理由。** 定义离流形量 $\delta_t=1-\max_a\cos(u^{\mathrm{avg}}_t,\mathrm{emb}(a))$,与代价一同记录;报代价对 $\delta$ 分箱后的曲线,而非单一均值。**上界臂给出 $\delta$ 的极端参照**:若代价接近上界臂,则测到的是「离流形」而非「承诺」。

**混淆三:温度。** $T\to0$ 时 $u^{\mathrm{avg}}\to u^{\mathrm{cmt}}$,代价平凡趋零。故扫 $T\in\{0.5,0.7,1.0,1.3,2.0\}$(**事先写死**),报代价-温度曲线。**同时以 $p_t$ 的熵作第二协变量分箱**——理论主张代价是「熵 × $\Phi$-敏感度」的二维量,**故若代价是熵的单值函数,则该主张的一半错**。这是顺带的一次检验。

**跨规模可比性(P5 的前提)。** 不同模型的维数与嵌入尺度不同,**绝对代价不可比**。故 P5 一律用无量纲比

$$\rho=\frac{\mathrm{Cost}^{\mathrm{sel}}(\text{不提交 vs 提交})}{\mathrm{Cost}^{\mathrm{sel}}(\text{上界 vs 提交})}$$

**这是上界臂存在的主要理由,离流形参照是副产品。**

```python
@torch.no_grad()                       # 纯推理:无梯度,不存在 detach 的选择
def three_arms(model, ids, T, phi):    # phi 由 §6 从权重 SVD 预先算好并冻结
    E   = model.get_input_embeddings().weight          # (V, d)
    out = model(input_ids=ids, output_hidden_states=False)
    logits = out.logits.float()                        # fp32:softmax 前升精度
    p   = torch.softmax(logits / T, dim=-1)            # (B, L, V)
    u_cmt = E[p.argmax(-1)]                            # 提交臂
    u_avg = p @ E                                      # 不提交臂:加权平均锚
    u_glb = E.mean(0).expand_as(u_cmt)                 # 上界臂
    ent   = -(p * p.clamp_min(1e-12).log()).sum(-1)    # 熵,协变量
    cos   = torch.nn.functional.normalize(u_avg, dim=-1) @ \
            torch.nn.functional.normalize(E, dim=-1).T
    delta = 1 - cos.max(-1).values                     # 离流形量,协变量
    return {k: phi(v) for k, v in
            [("cmt", u_cmt), ("avg", u_avg), ("glb", u_glb)]} | \
           {"ent": ent, "delta": delta}
```

**四处 dtype 与统计口径,执行前写死:**

1. `logits.float()` 再 softmax:bf16 的 softmax 在长尾上下溢,会同时改变熵与加权平均锚。
2. `p @ E` 在 fp32 下做(词表 152064 的加权和,bf16 累加误差不可接受)。
3. **padding 位置一律不进统计**(按 attention mask 剔除),且**须报被剔除的比例**。
4. **序列首位不进统计**:首位无前文,其分布由句首标记决定,与其余位置不同族。

**显存瓶颈不在权重上,在 $p$ 上:** $p$ 的形状是 (批量, 长度, 词表),fp32 下长度 1024、词表 152064 时单条序列就是 623 MB。**故批量取 1,且 $p$ 须分块乘或及时释放。**

**P4 与 P8 与本实验同跑。** P4 需要模型自己续写的序列:五个长度点 {64,128,256,512,1024},每点至少 500 条,交给 §7.4 的非规范质量函数。P8 记录逐步的 $\lVert h_t-\mathrm{emb}(a_t)\rVert$,**须同时记 $\lVert h_t\rVert$ 以区分「距离增大」与「整体尺度增大」**——不分则 P8 测到的可能只是残差流范数随深度增长这件已知事实。

**P8 的理论来源**:VQ 的损失里有一项专门压 $\lVert z_e-e_k\rVert$(原文说法是「确保编码器承诺于一个嵌入且其输出不发散」),而自回归**没有任何项约束 $h_t$ 待在码本附近**——RMSNorm 只管 $h_t$ 自身的尺度,不管它与嵌入表的相对尺度。

### 7.6 F5 · 向量量化侧(需要 GPU,规模小)

- **真东西上的实验**:公开的已训好 VQ 模型,**跨多个领域,不局限单卡小模型**。
- **候选**(⬜ 待核实仓库与解码器首层):图像 `CompVis/vqgan-*` 或 `stabilityai/sd-vae-*` 一类;音频 `facebook/encodec_24khz`;语音离散化模型。**至少覆盖三个领域。**
- **纯推理,不训练。取码本,以及编码器对码字自身的响应。**

**测两件:**

1. **码字往返**:把每个码字当输入送回编码-量化,看它是否量化回自己。这是 VQ 侧的锚对齐率,**且因为 VQ 是单锚(同一个码字既进距离计算又交给解码器),它与 P1 的绑定情形同型**。答「不是」的码字就是 VQ 侧地基的洞。
2. **residual VQ 是串联的实例**:EnCodec 的多级量化正好检验 §2.5 的次可加不等式——逐级代价与总代价的关系。

### 7.7 F6 · 微调后的依赖变化(唯一需要训练的一项)

- **真东西上的实验。微调,不是纯推理——这是它与其余全部实验的区别。**
- **测什么**:验证损失与注意力质量的分布。
- **为什么做**:文献里 Zero Sink 失败是在推理期事后改的,而成功的那次是从头训的。**这一项测的是「微调之后还失败吗」,它是 F1 判决里唯一没能排除的替代解释。**

**成本报实数。** 32B 全参微调 + Adam:参数 64 GB(bf16)+ 梯度 64 GB + Adam 两个状态 fp32 256 GB + fp32 主权重 128 GB ≈ **512 GB**,须 8×80GB 加 ZeRO-3,或用 offload 换时间。

| 路 | 显存 | 代价 |
|---|---|---|
| 全参 32B | 8×80GB | 贵;但唯一能对上「从头训 vs 事后改」这个对照 |
| LoRA 32B | 1–2×80GB | 便宜;**但结论弱化**:LoRA 不改注意力的 key-bias 结构,而 F1 那件事正是结构改动 |
| 全参 8B + LoRA 32B | 1×80GB + 2×80GB | 折中:8B 给机制、32B 给规模,**两者结论不可合并陈述** |

**建议:F6 排最后,且若预算只够一条,选第三条并明确写两者结论不合并。这是预算决定,不伪装成设计决定。**

**梯度流须写死的一处:** Zero Sink 那类改动若引入可训练的 key-bias,则该 bias 与 $W_k$ 同时受训、二者共变。**要分离,须做「冻结 $W_k$、只训 bias」的第三臂。** 不做则「bias 起作用」与「$W_k$ 适应了 bias」分不开。

### 7.8 P9 / P10 · 结构核查(零 GPU,不是测量)

**P9($\omega$ 必然相反)**:逐实例查锚点映射的值域是 $\Omega$ 还是 $\mathcal{X}$。标准语言模型输入侧是字符串(内容优先)、输出侧是向量(表示优先),相反 ✓;VQ 自编码器编码侧表示优先、解码侧内容优先,相反 ✓。**待查的两个:字节级无固定词表的模型(BLT 一类)、动态分块模型(H-Net 一类)——这两个最可能出反例,因为它们的「词表」是动态的。**

**P10(双向不可增量缓存)**:判据是「追加一个 token 后,已有前缀的 key/value 是否逐元素不变」。取一个双向模型(如 `FacebookAI/xlm-roberta-base`),前向两次(长度 $n$ 与 $n+1$),比较前 $n$ 位的 key/value。**须用同一随机种子、同一 dtype、且 `model.eval()` 关掉 dropout**,否则差异来自随机性而非结构。**允许的数值容差:bf16 下 1e-2、fp32 下 1e-5;超出即判为不相等。阈值事先定。**

**须明确**:BERT 类模型在推理时当然可以缓存整段的 key/value(全量重算后缓存),要判的是**增量**——追加 token 后已有前缀的 key/value 是否不变。

## 8. 会静默出错的地方

**这一节列的是不会报错、只会给出错答案的地方。每一条都足以单独毁掉一个数。**

### 坑一:bf16 下算 argmax 会给出与 fp32 不同的答案

权重是 bf16,尾数只有 8 位。$d=5120$ 维内积的累加误差量级约 $\sqrt{d}\cdot2^{-8}\approx0.28$ 的相对量,**而 argmax 的前两名常常差得比这还小**。

**后果**:锚对齐率会偏低,而且不报错。而锚对齐率的全部内容就是 argmax 的身份。

**处置**:matmul 与 argmax 一律在 fp32 下做,输入用 `.float()` 升精度。**这不是保险,是必须。**

### 坑二:152064² 装不下,而分块的错法很自然

输出是 $152064^2\approx2.31\times10^{10}$ 个 fp32 元素 = 92 GB。

**错法**:按块取局部 argmax,再把各块的局部 argmax 拼起来。这样得到的不是全局 argmax。

**处置**:分块时维护**全局最大值与全局索引**(见 §7.3 的代码:`best_val`、`best_idx` 与 `upd` 掩码)。

### 坑三:byte-level BPE 的 token 未必是合法 UTF-8

GPT-2 系与 Llama / Qwen 的 byte-level BPE 里,**一个 token 可以是多字节字符的一半**。`decode()` 对这种 token 返回 U+FFFD 替换符,再 encode 得到的是替换符的编码——**必然不等于原 token,于是被误记为「碎裂」**。

**后果**:中日韩词表里这类 token 数以千计,**不隔离则「碎裂率」这个数几乎全部是这个 bug**。

**处置**:单列 `undecodable` 一档,并在报告里明确它既不是完好也不是失效,而是**该 token 本身不构成一个字符串**。

**这不只是工程细节,它是理论边界的一次真实收窄**:这类对象不在 §1.2 设定的 $\Omega$(字符串集)里,故无损性前提 $\kappa^*\tau=\mathrm{id}_\Omega$ 对这类词表须在**字节串**载体上重述。

### 坑四:`add_special_tokens=False` 必须显式给

默认为真时,每次 encode 都会加句首标记,于是往返结果永不等于原 token。**得到的失败率会是接近 100% 的假数。**

### 坑五:`clean_up_tokenization_spaces`

部分分词器的 `decode` 默认会改动空格。须显式关掉并在报告里记录该参数取值。

### 坑六:pad 行未经训练

`vocab_size` 常大于分词器实际长度(Qwen2.5-32B 是 152064 对约 151936,差 128 行)。**这些行从未被训练,行为随机,会同时污染锚对齐率的分子与分母,并把「未训练行」混进「不可达 token」。**

**处置**:所有词表级统计在两个分母下各报一次(`vocab_size` 与 `len(tokenizer)`),差集单列。

### 坑七:归一化会吃掉范数,故长度那一项必须单列

$\Phi$ 里若把 $\lVert u\rVert$ 与其余成员合并取上确界,则「不提交臂的向量更短」这一件事会主导整个代价,而它与承诺无关。**见 §7.5 混淆一。**

### 坑八:padding 与序列首位进了统计

padding 位置的 logits 无意义;序列首位无前文,其分布与其余位置不同族。**两者都须剔除,且剔除比例须报。**

## 10. 已知上限与未决事项

### 10.1 三处硬上限(不掩饰,写进论文)

1. **P6 的归因只到「这一对上成立」**,不到「MLA 使代价降低」。因为 DeepSeek-V2-Lite 与 Qwen3-30B-A3B 在专家配置、词表、总参数上都有差异,而公开权重里不存在「同厂、同规模、仅注意力机制不同」的一对。
2. **32B 档做不到跨分词器**。三个 32B 模型全部共用 Qwen 分词器族,因为 Llama 没有 32B 检查点。
3. **P2 只能测「语料未出现」,不能测「不可达」**。枚举全部字符串不可行,故语料规模是协变量而非实现参数。

### 10.2 一项主动不做,记明理由

理论要求「每个载体结构给一个交换子公式」。序列结构那个已写出(强弱两级),**凸-光滑结构那个仍未写出**。不照抄序列的两级是有理由的:可微是局部条件、保凸组合是整体条件,仿射映射可微而可微映射不必仿射,两者不构成包含关系。**所以照抄会得到一个假的战果。目前这一族只有一个成员加一个形状,不成族。这是没做出来,不是遗漏。**

### 10.3 需要决定的三件

1. **32B 档的取舍**:严格同规模但同分词器(现方案),还是 24–30B 近似同规模但跨分词器(如换成 Gemma-2-27B、Mistral-Small-24B)。**两者不能同时要。**
2. **Llama 是否解 gate**。不配令牌则 Llama 全部退出,网格少一厂,P3 的 BPE 族少一个样本。
3. **F6 选哪条路**(§7.7 三条),这取决于预算。

## 附录:本规格与「小实验」的分界

**记录一个已被纠正的倾向,以便评审判断本规格的可信度。**

本规格的第一版把 F2 配成「1B + 8B、单张 24GB」、把 F5 写成「小、单卡」、把 F6 写成「1B 级别」——**每一个都默认取了「能出数的最小那个」,不是「能说明问题的那个」**。并且把 F3 称为「零成本」,那是因为只算了 GPU,存储与网络根本没进账。

最典型的一处:「平均嵌入是模型没见过的输入,所以只测单步、不做整段续写」——**这是把一个真实的困难直接变成了缩小实验的理由,而不是变成一个要解决的问题**。正确的做法是给它配对照(温度调分散度、离流形程度当协变量测掉、上界臂给极端参照),不是绕开然后把范围砍小。

现行规格因此加了三条纪律:

1. **报成本要报全轴**(GPU、存储、网络、时间),不只报卡。
2. **撞到混淆项时给对照,不给缩水方案。** 要砍范围必须明说是预算决定,不许伪装成设计决定。
3. **细节要具体到会出错的那一层**:梯度是直流还是 detach、dtype 用 bf16 还是 fp32、mask 怎么造、padding 算不算进统计。§8 整节是这条纪律的产物,其中两条(坑一的 fp32 argmax、坑三的非法 UTF-8)在写代码时反过来改了理论。
