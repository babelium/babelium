# N1 — 检验一(相容性),及它逼出的判据改形

**结论:检验一**过**,但过法需要签名里的一条结构事实(锚是商的截面 ⇒ $\kappa\tau$ 幂等),没有它就过不去。而推完检验一立刻看出:判据写成**等式**时近乎空洞,它把七个安放分成一比六。判据必须改形为**泛函**,不是谓词。**

---

## 一、把对象写准(此前一直没写准)

$$\mathbb{E}_{\kappa\tau p}[\varphi] = \mathbb{E}_p[\varphi],\qquad \forall \varphi \in \Phi$$

- $p$ 是载体空间 $\Omega$ 上的分布,$\kappa\tau p$ 是它在 $\kappa\tau: \Omega \to \Omega$ 下的推前。**两侧同空间**(S-05 由此自动满足,无需外部桥)。
- $\tau: \Omega \to \mathcal{A}$ 提交,$\kappa = \mathrm{anc}: \mathcal{A} \to \Omega$ 交还。$\kappa\tau$ 是往返。
- $\Phi$ 是下游实读的量族,按 F0 规则测量前从架构声明。

**一件此前没登记的事:等式左侧是实测量,右侧是反事实量。** $\mathbb{E}_{\kappa\tau p}[\varphi]$ 是实际发生的;$\mathbb{E}_p[\varphi]$ 是「若不提交会怎样」,下游从不计算它。所以判据不能只靠观察一次前向来验,必须**造出不提交那一臂**——F2 的存在性由此不是可选实验而是判据的可测性前提。K2 之后这一臂在 AR 上很便宜(`modeling_llama.py:385-386`,forward 直接吃 `inputs_embeds`)。

**双锚不成障碍(S-06 讨清)。** 不绑定权重时 $\tau$ 用的锚是 $w_a$、$\kappa$ 交出的锚是 $\mathrm{emb}(a)$,于是 $\kappa\tau = \mathrm{emb}\circ\arg\max_a\langle h,w_a\rangle$。判据只要求 $\kappa\tau$ 是个映射,不要求它是最近邻投影,故双锚下判据**仍良定义**。代价是「$\kappa\tau$ 是最近邻投影」这个几何图像失效——而那个图像本来只在绑定且锚范数齐一时成立(S-07)。**S-07 亦自动满足:判据里根本不出现「最近」。**

## 二、检验一,推

已证那级 = 无损分词的往返,$\kappa\tau = \mathrm{id}$ **逐点**。取 $\Phi = \{\varphi \text{ 有界可测}, \lVert\varphi\rVert_\infty \le 1\}$,则

$$\sup_{\varphi\in\Phi}\left|\mathbb{E}_{\kappa\tau p}[\varphi] - \mathbb{E}_p[\varphi]\right| = 2\,\mathrm{TV}(p,\ \kappa\tau p)$$

判据成立 $\iff \kappa\tau p = p$(作为分布)。

**问题:分布相等不蕴含映射是恒等。** 反例现成:$\Omega=\{0,1\}$,$p$ 均匀,$\kappa\tau$ 交换两点,则 $\kappa\tau p = p$ 而 $\kappa\tau$ 处处不等于 $\mathrm{id}$。若判据只推出「保测」,它就收不回已证那级,检验一不过。

**缺口由签名里的一条结构事实堵上。** $\mathcal{A} = \Omega/\!\sim$ 是商,$\mathrm{anc}$ 是它的**截面**($\tau(\mathrm{anc}(a)) = a$,锚在自己的等价类里)。于是

$$\kappa\tau\kappa\tau = \kappa(\tau\kappa)\tau = \kappa\,\mathrm{id}_\mathcal{A}\,\tau = \kappa\tau$$

即 $\kappa\tau$ **幂等**。幂等映射的像就是它的不动点集:$\mathrm{im}(\kappa\tau) = \mathrm{Fix}(\kappa\tau)$。而保测给出

$$p(\mathrm{Fix}(\kappa\tau)) = p(\mathrm{im}(\kappa\tau)) = p\big((\kappa\tau)^{-1}(\mathrm{im}(\kappa\tau))\big) = p(\Omega) = 1$$

故 $p$ 全部质量落在不动点集上,即 $\kappa\tau = \mathrm{id}$ **$p$-几乎必然**。

**检验一过。** 但过法有两处必须如实记:

1. **收回的是 $p$-a.e. 恒等,不是逐点恒等。** 已证那级是逐点的,所以判据特化出的是它的**弱化版**。这个弱化是对的而非将就:下游只吃数据分布里的输入,从不出现的字节序列上 $\kappa\tau$ 干什么无关。但「判据推广了已证那级」这句话此后须写成「判据推广了已证那级的 $p$-a.e. 版本」。
2. **过关靠的是幂等,而幂等靠的是 $\mathrm{anc}$ 是截面。** 若某安放的锚不在自己的等价类里(锚是学出来的、不必落在数据流形上——VQ 的码字正是如此),则 $\tau\kappa \neq \mathrm{id}_\mathcal{A}$,幂等失效,检验一在该安放上**不成立**。**这是一条新的、可测的必要条件:$\tau(\mathrm{anc}(a)) = a$ 对所有 $a$。** 即「每个锚被自己吸引」。VQ 上这等价于码本无死码(死码的 $a$ 从不被任何载体选中,但仍须满足 $\tau(e_a)=a$),可查。**登记为待测。**

## 三、推完检验一立刻看出的事:等式近乎空洞

判据成立 $\iff \kappa\tau = \mathrm{id}$ $p$-a.e.,即**往返无损**。逐格代入:

| 安放 | 往返是否 $p$-a.e. 无损 | 判据(等式版) |
|---|---|---|
| 无损分词(已证那级) | 是 | 成立 |
| AR | 否($h_t$ 几乎必然不是锚) | 不成立 |
| VQ | 否($z_e$ 一般不等于 $e_k$,否则 $\beta$ 项恒零) | 不成立 |
| diffusion 分箱 | 否(箱内积分非箱心) | 不成立 |
| AF2 层级 | 否(理想几何偏离真几何) | 不成立 |
| RAG | 前提不清(不提交,$\kappa\tau$ 未定义) | 无定义 |
| 文本输入 | 是(BPE 无损) | 成立 |

**一比五加一个无定义。** 而那个「一」就是已证那级本身。

即:判据写成等式时,它的精确成立集 = 无损往返集 = $\{\kappa\tau = \mathrm{id}\}$。这句话的内容是「没丢信息当且仅当没丢信息」。**这与 M2 §1 里可数那一列自杀是同一种病:近乎常量,不携带区分信息。** 差别只在这次常量取的是「假」而不是「真」。

**检验二、检验三因此都问错了。** 检验二问「是否在某处精确成立」——答案是在且仅在无损处,而那是同义反复地成立,不算非空洞。检验三问「是否在某处失效」——答案是在其余所有处失效,失效得太齐,同样不区分。**两道检验的题目建立在「判据是谓词」这个假设上,而这一节说明谓词版判据不合格。**

## 四、改形:判据是泛函,不是谓词

真正承载内容的不是等式成立与否,是**差多少**:

$$\boxed{\ \mathrm{Cost}_\Phi(p) \;=\; \sup_{\varphi \in \Phi}\left|\mathbb{E}_{\kappa\tau p}[\varphi] - \mathbb{E}_p[\varphi]\right|\ }$$

这是 $p$ 与 $\kappa\tau p$ 之间由 $\Phi$ 决定的**积分概率度量**(IPM)。$\Phi$ 一变,度量就变:

- $\Phi = \{\lVert\varphi\rVert_\infty\le1\}$ → 全变差
- $\Phi = \{\text{1-Lipschitz}\}$ → Wasserstein-1
- $\Phi = $ RKHS 单位球 → MMD

**这件事须如实说清:IPM 是现成的数学对象,不是本理论的发明。** 所以判据作为数学没有新意;它的全部内容在**「$\Phi$ 从架构读出」**这一步——F0 的预先声明规则由此从「一条纪律」升为**判据的唯一实质内容**。选 $\Phi$ 就是选度量,而选度量若能看结果后再选,任何安放都能被说成代价小。F0 那条规则是判据非空的唯一保证。

**改形后三道检验的题目须重述**(检验一不受影响,零代价点就是无损往返):

- 检验二(非空洞)改问:**代价是否在某处严格为正且有限**,即 IPM 既不恒零也不恒发散。
- 检验三(区分力)改问:**代价在七个安放上是否给出不同的数,且大小次序与实测相符**。这比原题目硬得多——原题目只要一个真假,新题目要一个可验的序。

## 五、面相分级如何落地(S-11 的机制,顺带得到)

S-11 要求判据按面相分级。改形后机制是现成的:**每条面相对应一个 $\Phi$ 子族,分级 = 对每族各报一个 IPM。**

已验一例(可插值):取 $\Phi$ 含能分辨中点与两端的 $\varphi$。有限商上 $\kappa\tau$ 把中点打到某个锚,该族 $\varphi$ 上的差很大 ⇒ 代价大;连续商(AF2 扭转角)上中点仍是合法代表 ⇒ 代价小。**与 M1 §2 实测的「有限商杀插值、连续商不杀」逐格吻合。** 这不是套上去的,是两边独立算出同一结果。

其余面相的 $\Phi$ 子族**未验**,不宣布对应关系成立。尤其可复用那族(上下文不变的 $\varphi$)方向反常:$\kappa\tau$ 把上下文依赖的 $h_t$ 打成上下文无关的 $\mathrm{emb}(a_t)$,是**增加**了不变性,IPM 的符号不对应面相的好坏。**登记为待查,可能说明面相与 $\Phi$ 子族不是一一对应。**

## 六、S-13(铰链)没被满足,这是本节最尖的缺口

$\mathrm{Cost}_\Phi(p)$ 是 $p$ 与 $\kappa\tau p$ 两个**分布**之间的量。而铰链类三条面相讲的是 $\tau$ 这个**映射自身**的性质:可微(导数存不存在)、可缓存(提交可不可逆)、可组合($\tau$ 是不是同态)。

**这三条都不是 $p$ 与 $\kappa\tau p$ 的函数。** 两个 $\tau$ 可以给出同一个 $\kappa\tau p$ 而一个可微一个不可微、一个可逆一个不可逆。所以判据**结构上装不下铰链**——不是写法不巧,是泛函的自变量里没有这个位置。

而 M2 §3 已证可缓存 = 提交不可逆,并且它是至今唯一现成答出轴门的面相(解释 AR 与 diffusion 的单步成本差异)。**即:最能答出「若无此轴则某现象无法解释」的那条面相,恰好是判据装不下的那条。**

这一条交 S4,不在此处强行补。可选的出路有两条,都要付代价:判据从「$p$ 与 $\kappa\tau p$ 的泛函」扩为「$(\tau,\kappa,p)$ 的泛函」(则它不再是 IPM,失去现成数学);或承认双面体层需要**两个**判据,一个管两面之间的代价、一个管铰链的性质(则「一个判据」这个目标落空)。

## 七、状态

- 检验一**过**,过法依赖 $\kappa\tau$ 幂等,而幂等依赖 $\mathrm{anc}$ 是截面。**新增可测必要条件:$\tau(\mathrm{anc}(a))=a$ 对所有 $a$(每个锚被自己吸引);VQ 死码是候选反例,待查。**
- 收回的是已证那级的 $p$-a.e. 版本,不是逐点版本。措辞须永久改。
- **判据改形:谓词 → 泛函(IPM)。** 等式版一比五加一个无定义,近乎空洞。
- 检验二、检验三的题目随之重述(见 §4),原题目建立在谓词假设上,作废。
- S-05、S-06、S-07 **自动满足**,已讨清。S-11 得到落地机制且验了一例。**S-13 未满足,且是最尖的缺口**,交 S4。
- F0 的预先声明规则升为**判据的唯一实质内容**:IPM 是现成数学,新意全在「$\Phi$ 从架构读出」。
- F2 的地位变了:从可选实验变为**判据可测性的前提**(等式右侧是反事实量,须造出不提交那一臂才能测)。
