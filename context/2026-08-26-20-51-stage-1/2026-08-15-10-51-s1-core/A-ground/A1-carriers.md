# A1 — 两面各自的承载结构

问的不是「token 是什么」,是**两面各自最少需要什么结构才能行使 North Star 归给它的能力**。多给结构会让理论偷偷依赖离散性（D3 会查),少给则那些能力无从谈起。故逐条从能力反推。

## 1. 同一性面:从五项能力反推

同一性面被要求提供:可数、可索引、可缓存、可复用、可组合。逐项看它各自要求什么。

**可索引**要求一个集合 $\mathcal{A}$ 与一个取址操作。仅此而已——不要求 $\mathcal{A}$ 有序、有限或离散。

**可数**看似要求 $|\mathcal{A}| \le \aleph_0$,但实际被使用的是「能对 $\mathcal{A}$ 上的分布做归一化求和」。这是可数性的用途而非可数性本身。先按 $\mathcal{A}$ 上存在一个 σ-有限测度记下,不预设它是计数测度。

**可缓存**要求判等:给两次取址,能判断是否同一地址。这是同一性面唯一不可让的结构——一个**判等关系** $\sim$,且判等结果是二值的。可缓存 = 判等为真时可复用先前算出的东西。

**可复用**与可缓存要求同一件事,但多要一条:判等必须**跨上下文稳定**。地址 $a$ 在此处与在彼处是同一个地址,这个判断不依赖处境。

**可组合**要求 $\mathcal{A}$ 上有一个部分二元运算 $\cdot: \mathcal{A} \times \mathcal{A} \rightharpoonup \mathcal{A}^*$,把地址接成地址序列。它是部分的:并非任意两地址都可接（BPE 的 merge 规则、mesh 的邻接约束都是这种部分性的实例)。

$$\text{同一性面} = (\mathcal{A}, \sim, \cdot), \quad \sim \text{二值且跨上下文稳定}$$

**离散性没有出现在这个签名里。** 它是「$\sim$ 二值」的一个充分实现方式,不是必要条件。这与已证结论一致:随机分词仍可 exact,只要各文本的分词支撑不相交（即判等依然二值可判）。**可判别的同一性才是必要的,离散性不是。**

## 2. 相似性面:从三项能力反推

相似性面被要求提供:可微、可插值、可泛化。

**可插值**要求路径结构:给两点,存在连接它们的路径,且路径上的点也在承载集内。要求的是**凸性或路径连通**,不是度量。

**可微**要求光滑结构:承载集是流形（或至少局部可微结构),且被使用的量在其上可微。

**可泛化**要求邻域结构:「附近的点行为相近」这句话可陈述。要求**拓扑**,加一条把「相近」变成可比的东西。

第三项是关键。「可比较」不必是度量——不必对称,不必满足三角不等式（内积、KL 散度、余弦相似度都不是度量,却都在实际充当比较)。最少要求是一个**比较函数** $c: \mathcal{X} \times \mathcal{X} \to \mathbb{R}$ 与它诱导的邻域族。

$$\text{相似性面} = (\mathcal{X}, \tau_{\text{top}}, c), \quad \mathcal{X} \text{ 路径连通且局部可微}, \; c \text{ 分级}$$

## 3. 两面的结构性落差

把两个签名并排,落差只有一处,但是全部要点所在:

| | 同一性面 | 相似性面 |
|---|---|---|
| 比较的值域 | $\{0,1\}$ | $\mathbb{R}$ |
| 比较的名字 | 判等 $\sim$ | 比较 $c$ |
| 稳定性要求 | 跨上下文稳定 | 局部连续 |

**换算界面要跨的就是这道落差:把分级的 $c$ 变成二值的 $\sim$,或反过来。** 分级→二值必须有一个选择(阈值、argmax、最近邻、采样,形式各异但都是选择);二值→分级不需要选择,它是嵌入,把地址派给点。

**承诺就落在这个不对称上**（详见 A5)。这也给了承诺一个不依赖架构的定位:承诺 = 分级比较被压成二值判等的那一次事件。

## 4. 复用性属于地址而非内容

从 §1「判等须跨上下文稳定」直接得到一条推论,值得单列,因为它拆掉一个常见混淆。

跨上下文稳定的是**地址**,不是地址所指的内容。地址 5 在任何上下文里都是地址 5;而地址 5 在此处激发的表示与在彼处激发的表示可以完全不同。KV-cache 之所以可行,靠的正是前者;「同一个 token 在不同上下文里意思不同」说的是后者。二者不冲突,是两层。

这把一个看似的悖论降级为分层现象:同一性面的稳定性是**寻址层**的性质,相似性面的可变性是**内容层**的性质。North Star 说的「双面体」于是不是同一层上的两个矛盾属性,而是**两层各自的性质**——这一点会在 A4 决定签名怎么写。

## 5. 界面成对出现（欠 A4)

写签名时发现的结构事实,先登记。

标准 LM 里不是一个换算界面,是**两个**:

- 输入侧:signal $\to$ address（分词,分级压成二值,**是承诺**)$\to$ similarity（嵌入查表,二值派成分级,**不是承诺**)
- 输出侧:similarity $\to$ address（logits 到选出的 token,**是承诺**)$\to$ signal（detokenize 查表,**不是承诺**)

两侧各有恰好一次承诺,且承诺发生在两侧的**不同环节**上:输入侧承诺在最前,输出侧承诺在最后。

由此直接得到一条已知实证:**输入词表与输出词表可以独立调规模**（12.8M 那条)。两侧的承诺是两个独立事件,各自的地址集无须相同——不需要任何额外假设。这是 D1 non-vacuity 的第一个候选:一个从签名推出而非塞进去的可对照结论。

## 6. 已证那级的落点比看上去窄（欠 C0)

必须如实登记,否则 C3 会在错误的起点上推广。

$\kappa\tau p^* = p^*$ 里,$\tau$ 是 character string $\to$ token string,$\kappa$ 是回去。**character string 也是离散地址集**,只是粒度更细。所以已证的是两个**同一性面之间**的往返一致性——是 §3 那张表左列内部的事,压根没碰到右列。

相似性面在标准 LM 里是嵌入之后才出现的。已证那级证的是「粗地址与细地址之间的往返」,不是「分级与二值之间的往返」。

**推广要跨的缝比预想的大。** 这不改变 C3 的工作猜想,但改变它的难度评估与起点:C0 必须把这条写清,C3 不得把「两个同一性面的往返」偷换成「换算界面的往返」。
