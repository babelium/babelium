# DARE 历史 Idea 总清点

> Created: 2026-09-17 20:53
> Topic: Token 理论历史研究方向、DeepSeek 攻击与训练级算力条件下的候选 paper idea
> Phase: DARE North Star 前置 — Systematic Enumeration

## Plan Context

本阶段为 DARE North Star 的 taste elicitation 建立完整候选池。目标是从既有 `context/` 研究记录中提取曾提出、修订、保留、否定或延期的研究 idea，与 DeepSeek 对话中的七个提案合并去重，并保留来源与当前状态。当前新增资源约束为 4 台 8 卡 B200 整机，共 32 张 B200，可支持 LLM 训练级实验。此阶段不选择最终方向、不生成 Research Spec、不把 AI 建议提升为已采纳主张；输出用于研究者表达偏好，随后再形成 DARE North Star。

## 原始 Idea 原料汇总 List

01. Token 双面理论 [主线]：token 是离散同一性与连续相似性之间的换算界面，而非单纯的信号切片。
02. Token 即商结构 [主线]：tokenizer 本质上是在内容空间上规定“什么算同一个”的等价关系。
03. 换算界面签名 [主线]：用载体、地址、比较器、锚、选择器、安放方向等统一描述不同 token 系统。
04. 可执行 Token 演算 [开放]：建立类似 Lean/PyTorch 的形式系统，使不同领域的 token 方案可以统一书写和比较。
05. 承诺的形式定义 [主线]：承诺是在仍有多个合法候选时选定一个代表的事件。
06. 输入与输出双界面 [主线]：语言模型包含方向相反的输入、输出换算界面，二者误差来源不同。
07. AR、VQ、Attention 同构 [主线]：三者都是“拿向量与一组锚比较，再选一个代表”。
08. 双锚系统 [开放]：打分使用的锚与提交给下游的锚可能不是同一组，需要扩展现有签名。
09. 多商系统 [开放]：一个模型可能同时包含离散商和连续商，需要研究多种承诺代价如何组合。
10. 动态地址集 / 签名族 [开放]：研究地址集可增长、替换时，token 系统如何在不同签名之间迁移。
11. 架构声明的下游读出族 Φ [主线]：损失只能在下游真实读取的坐标中度量，且 Φ 必须在看数据前冻结。
12. Φ-可见承诺代价 [主线]：纤维内被抹掉的信息，只有能被下游读出时才构成实际代价。
13. 承诺熵 × Φ 敏感度 [主线]：不确定性与后果是两个独立维度，熵不能单独表示承诺代价。
14. 商坍缩与选择坍缩双代价 [主线]：区分“压扁候选空间”与“最终只选一个代表”造成的两类损失。
15. 零核定理 [主线]：若纤维变化落入所有下游读出的零空间，承诺代价为零。
16. 锚是否为截面 [开放]：encode(decode(token)) = token 是否成立，可作为 token 系统的分类条件。
17. 文本截面失败的代价 [开放]：推导 token healing 场景下、锚不返回自身时应付出的额外代价。
18. 位移判据与交换子分离 [主线]：往返误差与结构保持误差是两类不同对象，不能硬塞进一个公式。
19. 保前缀 / 保拼接双等级 [主线]：前者解释 KV cache，后者解释 prompt boundary effect。
20. 凸结构 / 光滑结构交换子 [开放]：为插值、可微性建立第二个可计算交换子实例。
21. 训练过程感知理论 [开放]：现有判据只看最终映射，无法区分梯度、EMA、冻结或推理时选择。
22. 训练可见性分类 [开放]：区分梯度更新载体、梯度更新代表、EMA 更新代表、完全冻结。
23. 缺席地址形式化 [开放]：统一描述 register、[MASK]、padding、attention sink 和 null slot。
24. 承诺链的分步补偿 [主线]：链式承诺允许后续步骤修正早期误差，但需要反复支付比较成本。
25. 不提交反事实实验 [冻结]：比较 argmax 嵌入与概率加权平均嵌入，直接测选择坍缩代价。
26. 权重预测下游代价次序 [已预注册]：仅根据模型权重预测不同读出位点的承诺代价排序。
27. 四种预测臂对照 [已预注册]：形状零模型、谱零模型、权重级模型、校准级模型同时比较。
28. 跨界面次序定律 [已预注册]：检验同一权重推导能否同时预测 AR、VQ 与 KV-cache 界面。
29. Qwen3 per-head norm 预言 [已预注册]：Qwen3 的 q/k 承诺代价应低于同规模 Qwen2，而 v 不变。
30. MLA 对 GQA 的配对预训练 [存活]：控制数据、规模和预算，识别注意力结构对承诺代价的因果作用。
31. 承诺代价的 scaling law [降级]：在自行训练的规模阶梯上研究代价是否随模型规模变化。
32. TransMLA 转换对照 [补充]：把同源 GQA 模型转换成 MLA，作为配对预训练之外的廉价证据。
33. Φ-对齐 VQ [存活]：用解码器真实敏感的方向加权量化误差，而非各向同性欧氏距离。
34. Φ-对齐 VQ 的零增益条件 [存活]：解码器读出近各向同性时，新目标应不产生收益。
35. Residual VQ 次可加性 [存活]：检验逐级承诺代价与总体代价之间的组合规律。
36. 跨模态 VQ 统一实验 [存活]：在图像、音频、语音模型中检验同一承诺定律。
37. Matched BPE / Unigram 训练 [存活]：控制语料、词表、模型和预算，只改变 tokenizer 家族。
38. Tokenizer 往返分类 [存活]：把 token 分成完好、碎裂、改名、非法字节四类。
39. 非规范质量与 token healing [存活]：测量拼接、自生成、边界切割造成的非规范 token 质量。
40. 语料未出现 token 与欠训练 token [开放]：研究不可输入或罕见输入的 token 是否形成 glitch behavior。
41. 锚对齐与范数劫持 [存活]：检验长范数输出向量是否抢走短范数 token 的 argmax。
42. AR 隐状态—嵌入漂移 [开放]：研究 AR 没有 commitment loss 时，隐藏状态是否逐渐远离词表码本。
43. Attention sink 的结构 / 语义解耦 [主线]：区分 sink 的形成机制与其后来承载的内容。
44. Attention 弃权机制 [存活]：K-bias、零值 null key、输出 gate 都是在提供“什么也不选”的能力。
45. Sink 必然由缺少弃权导致 [已削弱]：直接必要性主张未成立，只保留复合映射层面的机制解释。
46. 微调能否修复 sink [已砍]：原为替代解释设计，当前认为不值得单独消耗训练预算。
47. 动态计算边界实验 [开放]：同预算比较 entropy、learned router、random、空格与人工语义边界。
48. 缓存的双条件理论 [主线]：离散提交不足以保证增量缓存，还必须满足已有前缀不被后文改写。
49. 双向模型不可增量缓存 [存活]：追加 token 后直接比较已有位置的 key/value 是否变化。
50. 输入 / 输出词表独立扩展 [开放]：两侧是独立商，可分别扩大输入覆盖率与输出表达能力。
51. 可替换的非参数地址集 [开放]：利用 RAG 地址可热替换这一性质研究“可更新但不重训”的 token 系统。
52. 固定→自适应→可学习边界 [旧先验]：研究 token 边界是否存在跨语言、视觉、音频和 3D 的共同演化规律。
53. 内容感知动态 tokenization [旧先验]：按局部信息密度或任务需求动态决定粒度和计算量。
54. 端到端 tokenizer 替代两阶段范式 [旧先验]：边界、表示和任务目标共同训练。
55. MeshLex / 几何感知 Mesh Tokenizer [旧方向]：结合曲率、拓扑、局部性与层级 patch 构建 3D mesh token。
56. 统一 tokenizer 的跨模态规律 [旧方向]：寻找文本、视觉、音频、3D 中边界学习和粒度经济的共同机制。
57. 动态承诺代价 [DS，重叠 24]：把单步损失改成“初始承诺代价减去后续补偿能力”的轨迹量。
58. 临时地址池 [DS]：推理时创建额外地址，保存固定 token 表示压缩掉但后续仍需要的信息。
59. 训练—推理统一的自反馈训练 [DS]：训练中逐步增加模型自身预测作为下一步输入。
60. 可逆距离 [DS]：用补偿后的重建误差与承诺分布惩罚构造跨系统统一判据。
61. 动态 VQ 码本 [DS]：按使用情况拆分、扩展或回收码字，并以可逆距离替代 commitment loss。
62. 强化学习地址分配器 [DS]：学习临时地址的创建、保留、合并与回收策略。
63. 承诺熵与安全对齐 [DS]：研究离散选择前的不确定性是否能预测或约束不安全行为。

## Stress-test 粗筛评分（2026-09-17）

### 评分口径

本轮按 **NeurIPS / ICML / ICLR / IJCAI / AAAI / KDD 主会高分论文**的标准粗筛，并将现有资源固定为 **4 台 8×B200，共 32×B200**。总分是“作为 paper 原料的价值”，不是录用概率，也不是对理论真假的裁决。

- **新颖性护城河 30 分**：能否与现有 tokenizer、task-aware quantization、memory token、scheduled sampling、KV-cache quantization 等工作划出硬边界。
- **决定性证据 25 分**：能否给出会真正推翻主张的实验，而非只报告相关性或案例。
- **影响面 20 分**：结论是否超出一个模型、一个 benchmark 或一个实现细节。
- **算力转化率 15 分**：32×B200 是否能换来受控预训练、规模律、多种子或训练期干预等别人难以轻易补齐的证据。
- **成熟度 10 分**：定义、基线、指标、实现路径是否已经足够清楚。

分层：**S（90–100）** 可直接成为强 paper 主轴；**A（80–89）** 有顶会主轴潜力；**B（70–79）** 适合与其他原料组合；**C（60–69）** 适合作为机制、消融或理论支撑；**D（45–59）** 只作背景或需大幅重写；**X（<45）** 当前不应投入主线资源。

### 63 项原料分

01. **56 / D — Token 双面理论**：叙事统摄力强，但单独缺少新算法和决定性证据；适合作为多篇论文的共同 framing。
02. **55 / D — Token 即商结构**：数学表达干净，但审稿人会质疑其是否只是 quotient-space 重述；须绑定新定理或新设计。
03. **60 / C — 换算界面签名**：可作为跨系统比较语言；独立成文容易被判为 taxonomy，必须产生不可平凡推出的预测。
04. **47 / D — 可执行 Token 演算**：工程量巨大且评价标准模糊；除非已有用户、验证器与新发现，否则难形成高分主会论文。
05. **54 / D — 承诺的形式定义**：是必要词汇，不是足够贡献；价值取决于其是否导出可测量量和有效干预。
06. **57 / D — 输入与输出双界面**：结构上合理但贡献偏解释性；最好服务于输入 / 输出词表解耦实验。
07. **61 / C — AR、VQ、Attention 同构**：统一视角有吸引力，但“都是向锚点选取”可能被认为过于抽象；需共享定律和跨域证据。
08. **66 / C — 双锚系统**：可修复现有签名并解释 tied/untied 权重差异；仍需找到只有双锚理论能预测的现象。
09. **62 / C — 多商系统**：理论空间真实，但缺少明确的合成定律与关键实例；更适合作为后续扩展。
10. **78 / B — 动态地址集 / 签名族**：可通向动态词表、外部记忆和在线适应；最大风险是与 dynamic vocabulary、memory token、RAG 重叠。
11. **76 / B — 架构声明的下游读出族 Φ**：预注册纪律和架构导出具有辨识度；先行工作碰撞严重，必须证明比校准统计多知道了什么。
12. **73 / B — Φ-可见承诺代价**：能连接理论与任务后果；风险是被归入 task-aware distortion / V-information 的已有框架。
13. **81 / A — 承诺熵 × Φ 敏感度**：二维机制可被受控干预击穿，且能统一动态计算与选择代价；需避免变成二维相关性图。
14. **70 / B — 商坍缩与选择坍缩双代价**：分解有解释力；必须证明两项能被独立操纵，并各自预测不同失败模式。
15. **72 / B — 零核定理**：是多条实证线的理论承重件；独立新颖性受 IPM、task-aware quantization 与 KV-cache 工作挤压。
16. **60 / C — 锚是否为截面**：分类条件清楚、易测；作为主贡献过窄，适合支撑 tokenizer 论文。
17. **74 / B — 文本截面失败的代价**：直接修补现理论最明显的洞；若能给出可估计公式并预测 healing 收益，可升为主轴。
18. **49 / D — 位移判据与交换子分离**：理论卫生很重要，但主要是避免错误统一，不足以单独吸引主会审稿人。
19. **58 / D — 保前缀 / 保拼接双等级**：能统一两个工程现象，但其中较多内容接近已知结构事实；需要新算法结果才可升级。
20. **42 / X — 凸结构 / 光滑结构交换子**：目前只有形式愿望，没有自然定义、非平凡定理或实验对象。
21. **77 / B — 训练过程感知理论**：准确击中静态判据盲区，并能借训练级算力验证；需避免无限扩张为“把优化全纳入理论”。
22. **59 / D — 训练可见性分类**：分类本身不够；若能产生优化行为预测，可作为 21 的组成部分。
23. **70 / B — 缺席地址形式化**：register、sink、null slot 的共同问题有价值；最大的攻击是这些对象功能不同，统一可能只停在命名层。
24. **85 / A — 承诺链的分步补偿**：动态、可干预、可训练，直接回应 DeepSeek 的最强攻击；32×B200 能建立多尺度因果证据。
25. **73 / B — 不提交反事实实验**：是很好的测量装置；平均嵌入离流形是致命混淆，必须用训练内干预或 matched manifold 对照解决。
26. **79 / B — 权重预测下游代价次序**：预注册、可判伪、数据前预测都很强；若只得到相关性或输给校准臂，主张会明显降级。
27. **63 / C — 四种预测臂对照**：实验设计扎实，但属于证据结构，不是 paper idea 本身。
28. **78 / B — 跨界面次序定律**：若同一推导跨 AR、VQ、KV cache 成立会很强；任一界面类型不齐都会暴露“套壳统一”。
29. **60 / C — Qwen3 per-head norm 预言**：干净的具体预测，适合作为一张关键图；范围过窄，不足以单独承重。
30. **87 / A — MLA 对 GQA 的配对预训练**：32×B200 可把公开模型不可归因的问题变成真正因果实验；需把贡献提升到一般机制而非架构赛马。
31. **71 / B — 承诺代价的 scaling law**：大算力使它可做，但 scaling law 很拥挤；必须有理论形状、转折点或外推成功。
32. **62 / C — TransMLA 转换对照**：便宜且有诊断力，但转换不对称，不能替代配对预训练。
33. **86 / A — Φ-对齐 VQ**：理论推出新设计，并有明确零增益条件；高分关键在于超越既有 task-aware quantization 的边界。
34. **69 / C — Φ-对齐 VQ 的零增益条件**：是防止“总能涨点”的重要反证条件；适合作为 33 的核心验证，不独立成篇。
35. **64 / C — Residual VQ 次可加性**：能检验链式承诺，但影响面偏窄；更适合并入动态承诺论文。
36. **72 / B — 跨模态 VQ 统一实验**：可增强统一性声称；若只是多数据集复现同一增益，会被视为 breadth without depth。
37. **82 / A — Matched BPE / Unigram 训练**：受控预训练能填补 tokenizer 研究长期的因果缺口；必须控制实际训练 FLOPs、序列长度与数据暴露量。
38. **55 / D — Tokenizer 往返分类**：可提供新测量表，但容易成为描述性 audit；需证明分类预测模型行为。
39. **74 / B — 非规范质量与 token healing**：有明确工程现象和可干预终点；须证明不是长度、字节编码或边界机会的替代变量。
40. **67 / C — 语料未出现 token 与欠训练 token**：glitch token 方向有价值，但文献已有拥挤；需要因果操纵 token 可达性。
41. **66 / C — 锚对齐与范数劫持**：机制具体、成本低；单独影响有限，适合作为词表训练论文的机制章节。
42. **72 / B — AR 隐状态—嵌入漂移**：可与训练目标和生成错误联系；简单距离会被 residual norm、各向异性和表示基变换击穿。
43. **65 / C — Attention sink 的结构 / 语义解耦**：问题重要但已有多篇机制工作；需要训练期因果操纵而非新的 probe。
44. **72 / B — Attention 弃权机制**：三种实现归于一个功能要求，且可做受控训练；需证明收益来自弃权能力而非额外参数或优化效应。
45. **30 / X — Sink 必然由缺少弃权导致**：既有记录已削弱必要性，继续承重会被一个反例击穿。
46. **18 / X — 微调能否修复 sink**：问题已被项目主动砍掉，且单独贡献不足；不应因算力充裕而复活。
47. **86 / A — 动态计算边界实验**：同算力、因果操纵、训练级比较都符合主会口味；须把 router 收益与边界语义彻底分离。
48. **60 / C — 缓存的双条件理论**：概念澄清有效，但主张容易被认为是因果掩码的直接推论。
49. **35 / X — 双向模型不可增量缓存**：验证过于显然，实验结果的信息增益低，只适合作为 sanity check。
50. **80 / A — 输入 / 输出词表独立扩展**：可做真正架构干预，并测覆盖率、生成质量和算力经济；需防止退化为 vocab-size sweep。
51. **67 / C — 可替换的非参数地址集**：与持续学习和知识更新相连，但当前表述接近 RAG 的已知卖点。
52. **48 / D — 固定→自适应→可学习边界**：是趋势总结，不是可判伪贡献；只作背景。
53. **83 / A — 内容感知动态 tokenization**：适合用大规模配对训练做机制与收益闭环；赛道拥挤，必须有新的边界信号或理论目标。
54. **78 / B — 端到端 tokenizer 替代两阶段范式**：影响大、可训练，但已有 BLT/H-Net 等强先行工作；需要精确的新机制而非重复趋势。
55. **50 / D — MeshLex / 几何感知 Mesh Tokenizer**：可成独立 3D 论文，但与当前 LLM 算力优势和 token 理论主线连接较弱。
56. **59 / D — 统一 tokenizer 的跨模态规律**：范围宏大但容易变 survey 或松散拼盘；需先有一个硬定律。
57. **82 / A — 动态承诺代价**：方向正确且能吸收 24；当前公式未经验证，独立使用会被批评为重新命名可恢复误差。
58. **89 / A — 临时地址池**：最有新架构与大算力优势的原料；必须正面对比 memory tokens、registers、KV cache、latent recurrence 与 external memory。
59. **54 / D — 训练—推理统一的自反馈训练**：高度接近 scheduled sampling / DAgger / professor forcing；除非与新承诺目标结合，否则新颖性不足。
60. **58 / D — 可逆距离**：当前定义的逆映射、KL 方向与“唯一通用判据”都不稳；只保留“测后续可恢复性”的动机。
61. **65 / C — 动态 VQ 码本**：已有码字重启、拆分、EMA 与 adaptive codebook 先行工作；应作为 33 的实现变量而非主张。
62. **72 / B — 强化学习地址分配器**：可利用长任务奖励学习资源分配；RL 不是必要条件，若监督或可微控制同样有效会失去贡献。
63. **45 / D — 承诺熵与安全对齐**：潜在影响大但因果链过长，容易形成事后相关性；当前缺少独有干预和安全机制。

### 组合后最强的 5 个 paper 骨架

01. **94 / S — Elastic Address LLM**（10 + 23 + 50 + 58，62 作可选控制器）：训练能按序列临时创建、合并和回收潜在地址的 LLM，在严格等 FLOPs / 等 KV 预算下检验长上下文、代码补全与边界恢复。**首要拒稿攻击**：只是 memory token、register token 或外部记忆换名；必须证明地址的动态身份、生命周期和可恢复信息三者缺一不可。优先会议：NeurIPS / ICLR。
02. **93 / S — Controlled Learned Tokenization**（13 + 17 + 37 + 39 + 47 + 50 + 53 + 54）：以相同数据顺序、训练 FLOPs、参数量和多个种子训练固定 BPE、Unigram、熵边界、learned router 与动态输入 / 输出词表，回答“边界为何有用”而非只比较 tokenizer。**首要拒稿攻击**：变量仍未锁住，收益只是序列长度或算力重分配；必须做严格 compute matching 与边界交换干预。优先会议：NeurIPS / ICLR / KDD。
03. **92 / S — Dynamic Commitment and Recovery**（13 + 14 + 24 + 25 + 35 + 42 + 57）：把承诺代价定义为随层、时间步和后续修复变化的轨迹量，并训练不同补偿深度的模型检验“早期损失能否、何时、以何成本被追回”。**首要拒稿攻击**：只是普通误差传播或深层网络去噪；必须构造同初始承诺、不同补偿路径的因果对照。优先会议：ICML / ICLR / NeurIPS。
04. **90 / S — Architecture-Causal Commitment Scaling**（11 + 12 + 15 + 26 + 27 + 28 + 30 + 31，32 作补充）：用 MLA/GQA 配对预训练、多规模、多种子验证权重级零核预测能否预言真实承诺代价，并与校准级方法正面对比。**首要拒稿攻击**：只是已有 KV-cache task-aware metric 的泛化，且 MLA/GQA 差异不只一个因素；必须报告严格参数 / FLOPs 匹配和跨 AR、VQ、cache 的同式成功或失败。优先会议：ICML / NeurIPS / ICLR。
05. **88 / A — Readout-Aligned Discrete Representation**（11 + 12 + 15 + 33 + 34 + 35 + 36，61 作消融）：从下游真实读出导出量化度量，在图像、音频及语言离散表示中训练 Φ-对齐 VQ，并预先预测何时零增益。**首要拒稿攻击**：task-aware quantization 早已存在；必须把“Φ 从架构导出”“零核条件”“跨模态同一预测”三点同时做成不可替代的增量。优先会议：ICLR / ICML。
