## Plan Context

S1 是整条研究链的第一个 STAGE,目标两件:把 North Star 里的四个中文概念(同一性 / 相似性 / 换算 / 承诺)做成带签名的形式对象;并立刻攻坚内核——试着把编码-解码往返不动点推广成任意换算界面的成立判据。S1 内含 go / conditional-go / null 三分闸门,是整个 pipeline 唯一的前置风险闸。

S1 完全自定义,不依赖 research-catalog 的任何 package,不读新论文,不需要 codex——输入全部来自已落盘的 North Star 与 `context/2026-08-14-21-52-survey/` 证据链。

排在读文献之前有两条理由。成本:若内核推不动,先读一百多篇再发现的损失不可逆,而 S1 很便宜。靶向:S1 的产出会把 S2 的源清单从「购物单」变成「靶单」——知道内核缺什么,才知道去哪些领域取什么证据。

产物目录 `context/2026-08-15-10-51-s1-core/`,执行序 A → B → C → D → E,其中 B → A 存在一条预期回边(预计走一到两次,属设计而非意外)。

- **A-ground** — 地基形式化。A1 两面各自的承载结构;A2「什么算同一个 token」;A3「什么算可比」;A4 换算签名(τ / κ 两方向 + 两条往返);A5 承诺 = 换算态射上的什么事件。
- **B-testbed** — 五个安放方式各写一份实例,B0 给出统一模板的九个必填格(相似性面承载 / 同一性面承载 / τ 形式 / κ 形式 / 换算位置 / 承诺时刻 / 硬度 / 往返偏差形状 / 该实例已观测的 token 现象)。B1 采样、B2 量化、B3 轨迹、B4 层级粒度、B5 检索,B6 汇报哪些格填不出。**B 是地基的验伪器而非应用**:先写实例后建阶梯,否则等于猜什么重要;格填不出即 A 缺东西,回 A 改。第九格是留给 S4 的欠条,现在只登记不推导。
- **C-ladder** — 判据阶梯,内核攻坚主战场。C0 已证那级的确切适用范围;C1 逐级放松 L0(逐点精确 κτ = id,已证但适用面极窄)→ L1(分布不动点 κτp\* = p\*,已证,允许随机而 exact)→ L2(保持下游实际读取的功能量,待构造)→ L3(不保持但有可组合的分级缺陷量,待构造);C2 判 B1–B5 各落哪级及为什么;C3 推广的正式陈述与推导;C4 失败日志(NULL 分支的证据)。
- **D-crosscheck** — 三道自检全部要过。D1 non-vacuity(判据必须能否掉真东西);D2 discrimination(AR sink 与 diffusion sink 是否被判成不同,仅作早期警报,推导架构差异是 S4 的活);D3 判据不得偷偷依赖离散性。
- **E-gate** — E1 裁决,E2 分支(E1 判完才写)。

C3 的**工作猜想**(要检验而非断言):存在功能量 $F$ 使 $F(\kappa\tau x) = F(x)$,理论的实质内容是每个安放方式各自保持的是哪个 $F$。若成立,L0–L3 都是它取不同 $F$ 的特例,已证那级自动落在里面;若不成立,C4 记下确切卡点。

闸门条件。**go**:C3 条件覆盖 B1–B5 且 D1–D3 全过。**conditional-go**:覆盖五个中三个以上且条件写清、D1 过;未覆盖的安放方式转为 S2 源清单的靶子。**null**:C4 出现稳定卡点,或 D1 不过(判据是空话);换种子重开 S1,按既定方法标准这是有效交付而非失败。

**已识别的最大风险不是推不动,是推得太动**——判据一般到什么都满足,于是什么都没说。故 D1 排在自检第一位且过关条件是硬的:判据必须把至少一个真实在用的 token 方案判成有缺陷,且该判定与已有经验证据对得上;对不上直接进 null 分支。

- **S2** 全谱系证据获取(codex 主导,取 knowledge-acquisition 的 snowball / citation-chaining / saturation-detection / prisma-screening / extract-data)。我出源清单与阅读指令,codex 用 `G:\.workshop\skills` 的 34 个技能产 atoms。全谱系含语言、视觉、语音、视频、动作、图、时序、代码、3D 几何、分子与蛋白的层级结构表征、检索与知识表示、世界模型。并行支线:外部学科专轮,同一套获取机器,靶子换成「该学科是否为换算的某一面提供可用的判据或运算」,符号学 / 信息论 / 通信论 / 编码论 / 抽象代数 / 语言学是起点而非清单。并行而不单列,因为共用同一套机器,单列会虚增流程。
- **S3** 轴体涌现与先验重评(取 knowledge-structuring 的 dimension-discovery / axis-extraction / axis-validation / matrix-generation)+ 自定义贝叶斯账本,逐条记录六条先验被哪些证据升降多少、最后留没留。
- **S4** 机制群系构建(全自定义,承重件)。记法 / 演算规则 / 可执行实现。硬指标:任意领域任意 token 方案可写下并对齐比较;五个安放方式的差异必须被**推导**而非列举;须含对尚未观测现象的可判伪预测。记法草图可在 S2 跑的同时用 S1 测试集先起。
- **S5** 承诺可测量化与实证(自定义设计 + experiment-execution)。实验形状已由证据链指出:同一端到端模型内同时记下一步熵、表示变化、边界决策、后续计算的边际收益,分别操纵语义变化与表面可预测性;严格同算力预算下比 entropy / learned router / random / space / 人工语义边界。
- **S6** 成文。不是缩写前面的东西,是重写。

两件不设为 STAGE 的事。**对抗验证**做成贯穿式闸门,每个 STAGE 出口跑一次(取 stress-test 的 red-teaming / counterfactual-probing),不单列——单列会让流程变成 A+B+C 的拼接,每关过一遍反而更狠。**ara-from-context** 不用,它编译的是可复现实验产物包,与「形式系统 + 一篇文章」的交付形态不符。

## Report

一句话: A 阶段把「token 有两面」这句话,做成了一张七个格子的清单——任何领域的任何 token 方案都必须填这七格,填不出来就说明清单缺东西,于是回头改清单。

得出的结论

1. token 不必是离散的。 必须的是「能判断两个东西是不是同一个」。这个判断只要给出是或否就够了,内容本身可以是连续的。整个 A 阶段五次尝试推出「必须离散」,五次都推不出来——它一直是一种实现方式,从来不是要求。

2. 词表不是前提,是你划分内容的方式。 「设计一个 tokenizer」和「规定什么算同一个东西」是一件事的两种说法。这一条让理论可以不跟着具体模型走:模型换了词表还是换了架构都无所谓,理论只谈那个划分规则。

3. 「可复用」属于地址,不属于地址指的东西。 编号 5 在任何上下文里都是编号 5,但编号 5 在这句话里激发的表示和在那句话里可以完全不同。KV-cache 靠前者,「一词多义」说的是后者。这两件事一直被当成矛盾,其实是两层。

4. 分词那些烦人的毛病是同一个毛病。 前导空格问题、prompt 边界效应、token healing 要打的补丁、同一个字符串在不同位置被切成不同 token——全部是「拼起来再切 ≠ 分别切再拼」这一件事。反方向(把 token 拼成字符串)没有这个毛病,永远成立。工程上被当成一堆细节的东西,是一个结构缺陷的不同露头。

5. 一个模型里有两个换算界面,不是一个,而且两个的方向必然相反。 输入侧是「内容 → 编号 → 向量」,输出侧是「向量 → 编号 → 内容」。由此直接得出:输入词表和输出词表可以独立设定规模(有实验做到 1280 万),两侧的误差不同源、不能合并算。这不是观察到的,是从清单推出来的。

6. 自回归采样、VQ 最近邻、attention 是同一个式子的三次代入。 都是「拿手上的向量去和一组锚点比,取最像的那个」。差别只在锚点是什么:采样的锚点是输出矩阵各行,VQ 的锚点是码本,attention 的锚点是各个 key。三个一直被当作不同机制的东西,形式上是一个。

7. 「token 是信号的切片」这个说法,来自一个特殊情况。 只有文本输入是先有内容、再切成编号、再变成向量。视觉的 VQ、自回归的输出、diffusion 全都反过来:先有连续的向量,再压成编号。在那些情况里,信号根本不是被切开的,是被吸到最近的锚点上的。十年来的 token 观念是从唯一那个例外里长出来的。

8. 一条对我们不利的结论:North Star 选的那个数学内核,在一半的情况里是空话。 已经被证明的那个条件说「往返一圈回到原处」,但当起点是连续的向量时,转一圈必然变成有限个点,连续的东西不可能等于离散的东西——不是难满足,是永远不成立。所以它不能当作普适的起点。

9. 但替代它的东西已经明确了。 不要求转一圈完全回到原处,只要求下游真正读取的那些量转一圈不变。下游读得越多,条件越严;读得少,条件就松。已被证明的那条是「下游什么都读」的极端情况,没有丢掉。理论的实质内容因此变成:每个安放方式,下游到底读什么。

10. 承诺不是「把连续压成离散」,是「在没被定死的选择里定下一个」。 分词里也有承诺——同一个字符串有好几种合法切法,选哪种不由匹配决定,是 merge 优先序定的。这个说法比原来的更宽,好处是纯离散的场合(知识图谱检索、字符拼成词)也被覆盖进来了。

11. 承诺的代价不是熵。 熵问「我有多不确定」,而承诺的代价是「放弃掉的那些选项,在下游到底有没有分量」。这两件事可以完全无关。如果把承诺定成熵,理论第一天就和我们自己的证据打架——证据明确说了熵的边界不等于语义边界。

12. 于是那些互相矛盾的 sink 证据全部对上了。 用两根轴看:一根是「有多少选项」,一根是「这些选项在下游有没有分量」。第一个位置的 token 几乎删了也没事,是因为它的选项在下游没分量;而正因为没分量,它才可以纯粹由结构(注意力掩码那些)定下来——「无害」和「可以纯由结构决定」是同一件事的两面,不是两个独立发现。diffusion 里删掉 sink 不影响语义打分但明显改变出图,是因为「语义打分」和「像素」是两套不同的下游读取。代价不是承诺自己的属性,是承诺和「下游读什么」这一对的属性。 不同论文测的是不同的下游,所以各自看到的图景不一样。

13. 承诺现在有了可以真做的测法。 定住下游读什么,找出这次承诺放弃掉的那些选项,把其中另一个换进去、别的全不动,看下游变多少。关键在这是干预,而现有文献做的全是观察(记录熵、记录表示变化、记录边界)。观察只能定第一根轴,干预才能定第二根。这是我们比现有工作多出来的那一步。

14. diffusion 分很多步走的好处可以推出来,不用当经验事实记。 一次定死就付全款且不能退;分步走每步只付一点,而且因为还没定死,后面几步能改前面的偏差。代价是每步都要重新比一遍,总算力随步数涨。这类「不同架构为什么不一样」的推导,正是 S4 要大规模做的事,这是第一个样本。
