## Plan Context

### 本阶段存在的理由

F 轮规格的审计判定为阶段零 NO-GO,五个阻断项里三个的根因相同:跨模型比较里想锁的变量锁不住。改形状(主结果从跨模型相关性改为同模型内次序检验)使那三个自动不适用,剩两个是必须动笔的纯推导。

但改形状本身带出一个更要紧的问题:**改完之后「我们的原创增量是什么」这句话答不出来。** 故本阶段把文献定位排在最前——它可能改掉后面所有东西的写法,而三周的阅读比四个月后被审稿人告知便宜一个数量级。

### 目标

四件,按依赖排序:

**一、文献定位。** 回答「我们是已有理论的哪个特例,增量在哪」。
**二、类型系统拆分(消 B01)。** 判据的两项建立在「纤维内位置被抹掉」上,而原规格把它写在了一个没有那种纤维的层上。
**三、经验估计器(消 B02)。** 理论量是总体期望差,而原规格没给保持期望次序的样本公式,不同实现者都能声称合规而给出不同的数。
**四、$\Phi$ 声明按源码重写(消 H02/H03)。** FIB-2 的主结果是各读出位点之间的次序,位点划错则整体作废。

### 门

- 凡写下的 config 数值须实测,不许拿记忆当事实。
- 撞到混淆项时给对照,不给缩水方案。
- 每条改判须指明它改的是原规格哪一句,并说明为什么原来那句错。

## Checkpoint — 2026-08-26 20:19,四件完成

### 一、定位:最坏的消息在这一格,而这正是先做它的理由

**「代价应当在下游真正读取的坐标里度量」这个想法,2026 年正在 KV cache 量化那一支被独立地、形式地做出来。** 已定位五篇,而其中两篇与我们的主设计正面碰撞:

- **HeadQ**(2605.03562,2026-05)的 Theorem 1 就是零核定理在注意力键上的实例;其 Corollary 1(存储 MSE 排不了行为损害的序)**比我们计划做的更强**;我们计划的实验(null-space 干预、同预算反例、matched-MSE 面板)它已在六个模型上做了。
- **Attention-Preserving Transforms**(2608.04074)把失真定为注意力乘积误差,给了**闭式最优变换**,连我们准备预注册的零增益条件都有($M_q\propto I$ 时正交变换次优)。

**$\mathrm{Cost}_\Phi$ 在数学上是 integral probability metric,1997 年就有的标准构造。** 故结论第 58 条「含指标函数时上确界即全变差」是 IPM 的标准特例,须改为引用而非声称。

**但有一条区别是硬的:那五篇全部用校准数据或激活统计。** 2608.04074 明写投影权重只用于定义 q/k/v、不参与构造变换。而我们的 $\Phi$ 从权重的 SVD 导出——**F0 纪律此前是「防止事后挑度量」,现在同时是唯一的原创边界。**

V-information 那边的界也清楚了:它的族是明确的建模选择(原文把这当卖点:"as a feature instead of a bug"),且其零值刻画**关于数据**($X\perp Y$);零核定理的零值刻画**关于架构**,与数据无关。

**存活的增量三条:** 跨界面的同一套账;零核作为与载体、与数据无关的一般结构(带组装算子);$\Phi$ 从权重导出。**第三条同时是最大风险——校准级现在是既有基线,若权重级预测不如它,我们不是多了一条纪律而是用了更弱的信息源。** 由此新增 FIB-2 的第四条臂(校准级对照),原设计里没有。

### 二、B01:类型错比审计描述的深一层,而拆开之后跨界面写得下来了

原规格同时写「$\mathcal{A}=\Omega/\!\sim$」与「$\tau:\Omega\to\mathcal{A}^*$」,**两句不能同真**。后果落在纤维上:$\tau^{-1}(a)$ 实际是「分词结果恰为单 token 序列的字符串」,不是「与 $a$ 等价的内容」。**故类型错的实质是:文本序列层没有判据需要的那种纤维,而判据被写在了那一层。**

拆开后判据与零核**全部住在局部选择层**。三处收益:

1. **分词器不再是判据的例外。** 局部层给了它类型正确的载体($\mathcal{X}$ = 该字符串的全部合法切分之集),故它与 VQ、AR 同型。结论第 10 条早写了「承诺 = 在没被定死的选择里定下一个」,此前没有载体。
2. **KV cache 的零核写得下来了,这是「跨界面」那条增量的形式基础。** 三个界面成为同一式子的三次代入。**这一步要求零核定理不预设 $\mathcal{A}$ 离散,而结论第 3 条早已判定离散性不是必要条件——当初若把离散性写进必要条件,今天这条统一就做不成。**
3. **「套壳讲废话」那个质疑有了确切答复。** KV cache 单独看确实是重述(局部层上可缓存性是因果掩码的直接推论);有增量的是**双向模型即使离散提交也不可增量缓存**,而这句话在单层记法里写不下来——只有一个 $\tau$ 时,「缺哪一条」这个问题问不出来。**故论文里这一段以对照的形式出现,不以解释的形式出现。**

顺带消掉审计 R02(分词器保前缀与 KV cache 被写成同层条件)。

### 三、B02:原规格有一处方向写反了

原规格把 $\lVert u\rVert_2$ 列为 $\Phi$ 的成员,理由是「归一化会吃掉它,但吃掉本身是信息丢失,须登记」。**方向反了:被吃掉意味着下游读不到,而读不到正是零核的定义。**

$$\lVert u\rVert_2\ \text{不是}\ \Phi\ \text{的成员,它落在零核里}$$

连消三件:$\Phi$ 成为纯线性族故上确界有闭式(H06 的动机消失);「不提交臂的向量更短」不再是混淆项(H05 自动解决);原规格的「混淆一」从需要对照的项变成一条推论。

**主端点定为 $\lVert\mathbb E_\mu[\cdot]\rVert_2$,期望在范数内部。** 审计给的 $v/-v$ 反例下这个量是 0 而逐位置范数平均是 $\lVert v\rVert$;**哪个对要靠定位才答得清楚**——$\mathrm{Cost}_\Phi$ 是 IPM,问的是「$\Phi$ 里有没有函数能区分这两个分布」,故误差在期望上抵消就是不可分。抵消掉的那部分单列为 `local_shift`。

**改正之后掉出一个带数字的真问题($\epsilon$ 残余,消 H10):** 尺度不变要求 $\lVert u\rVert^2\gg\epsilon d$。实测 **Qwen2.5-72B 的 `rms_norm_eps`=1e-05 比其余大一个数量级**($\epsilon d$=8.2e-2,阈值 $\lVert u\rVert\gg0.29$),而不提交臂的向量是凸组合、范数天然小。**故这个条件在 72B 上不是自动成立的,每个模型必测该比值的分布。**

**白拿一处简化:次序检验不需要归一化**(次序在正的单调重标下不变),故审计 H05 那个不合法分母的需求大部分消失。

### 四、FIB-0:一处不核对就会让主结果整体作废

`Qwen2DecoderLayer.forward` 显示 **MLP 读的是 `post_attention_layernorm(residual + attn_out)`**,而 `attn_out` 混入了所有位置的信息。故

$$W_{\mathrm{gate}},W_{\mathrm{up}}\notin\Phi$$

**原声明五个位点里两个是错的,而 FIB-2 的主结果就是这些位点之间的次序。**

去掉两个之后每层只剩 q/k/v,做次序检验太少;**改按头拆**——Qwen2.5-32B 得 56 个位点,72B 得 80 个。**而按头拆比原设想更强:各头读同一个 $W$ 的不同行空间切片,函数形式完全相同、只有行空间不同,这正是次序检验要的对照。** 原来那五个位点函数形式各异(注意力投影 vs 前馈投影),那反而是混淆项。

**三份变四份:Qwen2 与 Qwen3 必须分开。** Qwen3 在投影之后、RoPE 之前对每个头各做一次 RMSNorm,Qwen2 没有。**这是提交之后的第二次商,故按零核定理给出一条新预言:同规模下 Qwen3 的 q/k 位点代价低于 Qwen2,v 位点无差异(v 不过 per-head norm)。** 对照结构干净——网格里已有 Qwen2.5-32B 与 Qwen3-32B,hidden 5120、64 层完全相同,且 **v 位点是内部对照**。混淆项记明:两者 `rms_norm_eps` 差一个数量级。

**另两处不完整:** MLA 是三条路而非一条(只有 KV 主路过 512 瓶颈,RoPE 键路 64 维直接读、不过瓶颈也不过 norm,V2-Lite 的 `q_lora_rank=None` 故 query 路满秩),**但这个结构反而更有用——同一模型内同时有过瓶颈与不过瓶颈的位点,故「$\Phi$ 越小代价越低」可在同模型内检验**;Emu3 的码字走两条路进解码器,主路 kernel (3,1,1) 跨时间维混了邻居故只取中心片。

### 门:过

四件都有结果。改判五处,每处都指明了原规格哪一句错。**审计五个阻断项全部处置完毕**(B03/B04/B05 由改形状自动解决,B01/B02 由本阶段消掉),高优先里 H02/H03/H05/H06/H10 一并消掉,R02 顺带消掉。
