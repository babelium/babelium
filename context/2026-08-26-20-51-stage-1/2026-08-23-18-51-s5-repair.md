## Plan Context

### 本 STAGE 存在的理由

S4 把判据的欠缺具体到三件,并判定 LAYER-03 是最薄的一层而它才是最终成文的落点。本 STAGE 做其中两件纯推导(第三件——凸-光滑交换子——不做,理由见下),然后把重心移到 LAYER-03。三件都不需要设备,故在 F 轮开跑前做完是纯收益:它们决定 F 轮出的数有没有东西可对。

### 目标

**一、推 $\tau\kappa\neq\mathrm{id}$ 时的代价。** 不推则 F3 出的百分数没有对手。
**二、签名扩容(双锚 + 多商)。** 不扩则九个模型的池子里有些配置测得出但写不下来。
**三、转 LAYER-03。** 目的是在 GPU 到位前把可判伪预言写满,因为写预言不要钱而卡是唯一稀缺资源。

### 门

不许以「需进一步研究」结束任一件;每件要么给出结果,要么给出它卡在哪个具体的东西上。新增结论一律带杀伤条件或标为未证。

## Checkpoint — 2026-08-23,三件完成

**产物**:`Q1-section-cost.md`、`Q2-signature.md`、`Q3-layer03.md`;结论表新增第 57–67 条;第 51 条挂 ⚠️ 指针(诊断对、归因错)。

**一(Q1):结果超出预期,问题被改掉而非被回答。** 原问题是「截面性失效时代价多少」;推导发现失效在**层级**上——字级($r:\mathcal{A}\to\mathcal{A}^+$)确实假,序列级($R=\tau\kappa^*$)由无损性**自动**幂等。于是 N1 的幂等与 N2 的零核定理**原样恢复**,适用域不缩小;换掉的是定理假设的性质:分词器的性质 → 输入分布的性质。该假设的三种违反方式恰好是三个独立记录的病灶(拼接 / 自生成 / 边界切割),而 **token healing 就是投影算子 $R$ 本身**。代价写成非规范质量,给 F3 的桥因此改了两处设计(须按频率加权;且松弛是真的——截面失效可以完全不付代价)。副产品:不可达 token 的推导,接上 glitch token 现象,给出一条可判伪重合度预言。

**二(Q2):两处缺口合为一处,并掉出一个零 GPU 的真测量。** 缺口的共同形状是「把本该是结构的东西写成了槽位」。$\mathrm{anc}$ 裂为一对后,截面性多出一条此前写不下来的失效来源(两个锚系统不对齐),由此得**锚对齐率 AAR**——两个矩阵一次相乘,把 K2 §3 的范数散布从几何装饰变成截面性的决定因素。$\mathcal{A}$ 裂为商图后,AF2 的分裂值从例外变成并联的必然。串联上证出次可加,**并否掉了我自己先写下的「沿塔单调不减」**(退化商反例)。

**三(Q3):L3 从 4 条到「三算子 + 五规则 + 四推导 + 十预言」,其中两条推导是新结论。** 新的两条:可缓存需两个条件而非一条(故双向模型即使离散提交也不可增量缓存);不可达 token 是「商与选择由不同件决定」的必然,推出跨算法族对照 Unigram < BPE。演算的份量如实记为「能写下、能对齐、能比较」,不能自动搜索或综合——离北极星那句「如 Lean 之于数学」还远。

**一件主动不做,记明理由:凸-光滑交换子公式仍未写。** 第 50 条已禁止照抄序列的两级,而本轮没有找到不照抄的写法。它是 S4 三件里唯一没动的,故 R5 目前是「一个成员加一个形状」,「一族交换子」尚不成族。这不是遗漏,是没做出来。

**门:过。** 三件都有结果,未做的那件指名了卡点。新增十一条结论中,带杀伤条件的十条已进 Q3 §7 的预言表。
