## A 阶段已产生的、会改变后续的东西

1. **复用性属于地址而非内容**（A1 §4）。这解释了 KV-cache 为何可行,也把「同一个 token 在不同上下文里意思不同」从悖论降级为分层现象。
2. **界面成对出现**（A1 §5,欠 A4）。标准 LM 有两个换算界面而非一个:输入侧与输出侧。输入侧 signal→address 是承诺、address→similarity 是查表;输出侧 similarity→address 是承诺、address→signal 是查表。输入输出词表可独立调规模（12.8M 那条实证）由此直接得到,不需额外假设——这是 D1 的第一个候选。
3. **已证那级的落点比看上去窄**（A1 §6,欠 C0）。κτp\* = p\* 证的是两个**同一性面**之间的往返（character 也是离散地址,只是粒度更细）,不是相似性面与同一性面之间的往返。推广要跨的缝比预想的大,这一点必须在 C0 如实登记,不得含糊过去。
4. **地址集是商而非前提**（A2 §1）。$\mathcal{A} = \Omega/\sim$,「设计 tokenizer」=「在 $\Omega$ 上定一个 $\sim$」。商结构是「理论高于 architecture」这句话的形式内容——理论只谈 $\sim$,而 $\sim$ 是 $\Omega$ 上的关系,与用它的模型无关。
5. **$\kappa$ 是同态,$\tau$ 不是;而「$\tau$ 不是同态」实为强弱两级**（A2 §4;2026-08-15 按 `2026-08-15-15-37-s3-frontal-criterion/N4-sequential-instance.md` §1 重写）。$\kappa=\mathrm{anc}$ 保拼接,$\tau$ 不保——但不保有两级,原文把两级混作一件。**弱级(保前缀)** $[\tau(x\cdot y)]_{1:|x|}=\tau(x)$:AR 成立(因果掩码 `modeling_llama.py:399`),**这正是 KV cache 合法的充要条件**;**BPE 不成立**——贪心最长匹配使后文能改前文的切分,即前导空格、token healing、切分位置改变地址那一族。**强级(保拼接)** $\tau(x\cdot y)=\tau(x)\cdot\tau(y)$:AR 亦不成立,失败即 prompt 边界效应。故原文列的四件不是同一件事的四个露头——**前三件是弱级坏、第四件是强级坏,且 AR 与 BPE 在弱级上取相反值**。另:弱级坏的那三件同时是**「锚不是截面」($\tau(\mathrm{anc}(a))\neq a$)的露头**,见第 51 条;原文没看出这一点,而它后来击倒了第 38 条。术语一并订正:截面是 $\mathrm{anc}$(在 $\tau\circ\mathrm{anc}=\mathrm{id}_\mathcal{A}$ 成立时),$\tau$ 是商映射,原文「$\tau$ 只是截面」的说法作废。签名不得把两个方向写成对称的一对映射,此结论不变。
6. **I1↔I2 落差是双向可测缺陷**（A2 §5）。构造级判据与功能级判据取的商一般不同,两向各对应一族已知病(codebook collapse / 多义地址),两向都可测。形状上正合 C-ladder L3 要的东西。
7. **缺席须另外接上**（A2 §6）。$\Omega^+ = \Omega \sqcup \{*\}$。register / [MASK] / sink / null / padding 在 $\Omega$ 里没有原像,这是它们行为异常的形式原因而非实现巧合。只登记;是否为独立轴留待轴体阶段。
8. **类型论已按单一标准入场**（A2 §2）。I2 功能级判据就是观察等价 / 上下文等价(bisimulation 那一族)。这是外部学科第一个凭「提供可用判据」而非气质相投进入的实例。
9. **安放方式的二值结构参数是载体的结构,不是「哪一面原始」**（A3 §2;2026-08-15 按第 26/49 条重写）。原问法「哪一面原始」预设两面可比,而它们不可比——同一性面活在商 $\mathcal{A}$ 上、相似性面活在载体 $\Omega$ 上,商映射正是那个把前者造出来、把后者杀掉的操作。故该参数须改述为**载体本身是离散还是连续**:文本输入与层级粒度的载体已是离散可寻址的(商是有限到有限),AR 采样 / VQ / diffusion 的载体是连续的(商是连续到有限),检索是两极对照。改述后**第 11 条的「相反的复合」不再是独立观察而是推论**:载体离散则 $\kappa\tau=\mathrm{id}$ 易成立而 $\tau\kappa$ 坏(即 token healing,第 51 条),载体连续则反之。**原文最有力的那半句不变且被加强**:「token 是信号切片」这条根假设来自恰好那个载体离散的安放方式;载体连续时信号不是被切的,是被吸附到锚点上的——而按第 35 条,吸附**必然**杀掉插值,因为有限商上两代表的中点一般不是代表。这是 D1 的第二个候选。
10. **三个机制是同一个式子**（A3 §4）。$\tau(x) = \arg\max_a c(x, \text{anc}(a))$;AR argmax(锚点=unembedding 行)、VQ 最近邻(锚点=码字)、attention(锚点=key)是三次代入。$\kappa = \text{anc}$ 本身。
11. **两种安放方式坏掉的是相反的复合**（A3 §5）。同一性原始:$\kappa\tau = \text{id}$ 成立、$\tau\kappa$ 坏。相似性原始:$\tau\kappa = \text{id}$ 成立、$\kappa\tau$ 坏。同一对映射,代数身份互换。
12. **不动点在相似性原始时恒假,内核受损但替代物已明确**（A3 §6）。$\kappa\tau$ 把连续分布推成离散测度,故 $\kappa\tau p^* = p^*$ 不是难满足而是恒假,L1 不能作普适起点。替代物形状已定:$\mathbb{E}_{\kappa\tau p}[\phi] = \mathbb{E}_p[\phi], \forall \phi \in \Phi$,$\Phi$ = 下游实际读取的量。**理论的实质内容变成「每个安放方式的 $\Phi$ 是什么」**;$\Phi$ 取全体有界可测函数时退回 L1,已证那级作为特例落在里面。这是 C3 的具体起点。
    - ⚠️ **本条末句已被 G 表推翻,待改**(`G-phi-table/G0-summary.md` §3)。「理论的实质内容 = 每个安放方式的 $\Phi$」不成立:六个条目里四个的 $\Phi$ 完全相同,声明它们不产生信息。$\Phi$ 降级为**计算代价的工具**,区分安放的自变量改为**纤维可见性**。替代物公式本身($\mathbb{E}_{\kappa\tau p}[\phi] = \mathbb{E}_p[\phi]$)不受影响,受影响的只是「$\Phi$ 承载安放差异」这个归属。原文保留待你过目。
13. **签名七件**（A4 §1）。$\mathcal{I} = (\Omega^+, \mathcal{A}, \mathcal{X}, c, \mathrm{anc}, \mathrm{sel}, \omega)$。$\omega$ 不改签名的形,只改 $\mathrm{anc}$ 的值域($\Omega$ 或 $\mathcal{X}$)——这是六条要求能装进一个签名而非两个的原因。$\tau$ 两栏同式。
14. **承诺的定位收紧:不是「分级压成二值」,是「在欠定的选择上取定一个代表」**（A4 §2）。id-prim 侧 $c$ 本来就二值(串匹配),承诺落在 merge 优先序 / 最长匹配这个**定序**上;sim-prim 侧承诺落在「拿锚点代表整个纤维」上。两侧只差纤维基数(有限多切分 vs 连续纤维),不差性质。这是 A1 §3 的推广而非否定——分级→二值只是欠定的一种来源。**后果:承诺不再需要「有连续面在场」这个条件,纯离散界面(KG 检索、character→word)也进入覆盖范围。**
15. **$\mathrm{sel}$ 是签名里唯一有实质自由度的件**（A4 §3）。其余六件说界面长什么样,$\mathrm{sel}$ 说界面做什么。值域取 $\mathcal{A}$ 则承诺确定、取 $\Delta(\mathcal{A})$ 则随机——**随机性住在 $\mathrm{sel}$ 里,不住在别处**;已证那级的「随机而仍 exact」即 $\mathrm{sel}$ 取分布值且各纤维支撑不相交。A5 接手的正是 $\mathrm{sel}$ 被调用的那一次事件。
16. **界面成对且两侧 $\omega$ 必然相反**（A4 §4）。A1 §5 的成对由此得证而非观察。三条推论:两侧各恰好一次 $\mathrm{sel}$ 调用且位置相反;两侧 $\mathcal{A}$ 是两个独立的商;两侧坏掉的复合相反,故误差不同源、不可合并计。VQ 自编码器同构(编码侧 sim-prim、解码侧 id-prim)。**这是可检验的结构预言**,B 阶段五实例全查——若某实例两侧 $\omega$ 相同,签名错。D1 的第三个候选。
17. **承诺的代价是纤维在 $\Phi$ 上的落差,不是纤维上的熵**（A5 §2）。熵在纤维内部测分散,$\Phi$-落差测这份分散穿不穿透下游,两者可完全脱钩。若把承诺定成熵,理论第一天就与证据链「熵边界 ≠ 语义边界」冲突。
18. **二维分类使证据链的乱局归位**（A5 §3）。熵 × $\Phi$-敏感度四格。首 token 近 no-op = 左下格($\Phi$ 平);**P0-sink 可由纯结构形成是左下格的必然——「无害」正是「可由纯结构决定」的原因**,不是两件独立的事;diffusion sink 删除不损语义对齐但改变成像 = 同一次承诺在 $\Phi_{\text{语义}}$ 下平、$\Phi_{\text{像素}}$ 下陡。**代价不是承诺的属性,是承诺与 $\Phi$ 这一对的属性**,不同论文测不同 $\Phi$ 故图景不同——证据链「分层而非单因素」由此得到解释而非仅被记录。且熵为何不够成为推论:它只读行不读列,是二维量的一维代理,故「熵边界 = 语义边界」必假,维数不够。D1 第四个候选。
19. **「选择机制 ≠ 承载内容」是签名的两个不同槽位**（A5 §4）。选择机制 = 什么定下 $\mathrm{sel}$,承载内容 = $\Phi$ 从结果读出什么。混同即类型错误,不需另记为注意事项。
20. **承诺的操作定义:给定 $\Phi$,代价 = 纤维重采样下 $\Phi$ 的敏感度**（A5 §5）。协议五步,第 3 步「纤维内重采样、其余不动」是新东西——证据链的「最需要的实验」全是**观测**,$\Phi$-敏感度要求**干预**(不换边界,换同一次承诺内的代表)。二者互补:观测定行,干预定列。S5 设计据此增补。相对于 $\Phi$ 而非绝对是特性不是缺陷,绝对版本必然自相矛盾。
21. **链式承诺的收益可推**（A5 §6）。原子承诺一次付清 $\Phi$-落差不可退;链式每步只付一部分且纤维未收完,**后续步骤可修正前面的落差**。diffusion 沿 timestep 摊薄的好处是这条,不是「更平滑」这种气质描述;代价是每步重新比较、总算量随链长增。这是 S4 必须推导的那类架构相关差异的第一个样本。

## F/G 阶段新增(第 22 条起)

22. **纤维可见性取代 $\Phi$ 成为区分安放的量**(G0 §2–3)。六个条目六个不重复的答案:完全不可见(AR,遮挡=`nn.Embedding` 查表)/ 分裂按消费者(VQ,解码器不可见但 commitment loss 可见)/ 完全可见(diffusion 分箱,读整箱积分非箱心)/ 部分可见且方向明确(AF2,理想化键长键角不可见、其标量后果经 FAPE 可见)/ 内可见外不可见且**内不提交**(RAG 对 top-$k$ 边缘化)/ 不可见且两层遮挡(GraphRAG,摘要有损 + 图只间接塑造检索)。而 $\Phi$ 在 AR、VQ 解码侧、RAG、KG 四处**完全相同**。$\Phi$ 之间的差别全部来自纤维是否可见,故它是纤维可见性的影子而非自变量。**因果方向此前是倒的。**
23. **AR 是结构异类,而它恰好是所有人讲 token 理论时用的例子**(G0 §5)。按「换算前后是否同空间」分,VQ($z_e,z_q$ 同 $\mathbb{R}^D$,原文 3.2 节凭此使直通估计成立)、diffusion 分箱、AF2、RAG 全部同空间,提交落差架构自己就能相减(VQ 甚至已在惩罚它);**只有 AR 异空间**——换算前 $\mathbb{R}^{|A|}$、换算后 $\mathbb{R}^d$,落差必须靠外部构造的桥测量。若成立,这解释了为何 tokenization 的讨论长期停在类比与经验规则:大家在最难相减的那个界面上争论「压缩」与「边界」,而四个可直接相减的界面无人讨论。**可证伪:找出第二个异空间安放,或证明 AR 其实同空间,即倒。**
24. **提交是否被训练目标看见,是一个三档取值的新区分量**(G0 §4)。AR 的 $\mathrm{sel}$ 在训练期**从不被调用**(teacher forcing 下 `generation/utils.py:2789-2793` 不在训练图里),VQ 的式 (1) 训练期每步执行且式 (3) 第三项显式付费,RAG **不提交**,GraphRAG 的提交前置到**索引期**。同一签名的两次安放在此取相反值。该列是填格 4 时逼出来的,不在事先列的任何维度上,且与纤维可见性不重合(AR 与 KG 同为「否」但可见性一个完全不可见一个两层遮挡)。**按 S3 的门它答得出**(若无此档,曝露偏差无法解释:AR 训练期不练提交、推理期必须提交),但门在 S3 统一过,此处不放行为轴。
25. **弃权 = 能产出 $\Phi$-零的输出,三个实现一个要求**(F1-verdict §4)。分母加可学习 K-bias、加 V=0 的 null key、对输出乘可趋零 sigmoid gate——三处不在同一层却同效,故缺陷在**注意力这个复合映射**而非 softmax 这一件。这与 $\tau$ 统一 AR/VQ/attention 是同一类统一,应进 S4 机制群系。另:病因归属须改——加弃权项免费(验证损失 3.73→3.72),去归一化要付费(1B 上 3.07→3.10),故**和为一本身没病,病在没有东西可归**。

## S2 阶段新增(第 26 条起)

> 层标签:【边界】= 双面体 + 推广不动点 层的边界;【内部】= 该层内部;【界面】= 换算界面 + 承诺可测量化 层;【方法】= 研究方法本身。

26. 【内部】**两面不在同一枚硬币上,它们在商映射两侧;「同一枚硬币」这个比喻不准**(M2 §4)。可复用七格全为「商上成立、载体上不成立」,与可插值行「载体上成立、商上不成立」构成镜像。可复用之所以成立,恰因商映射抹掉了上下文依赖;可插值之所以死,恰因同一个抹除。故正确的问法不是「两面何时是同一枚硬币」,而是**「商映射抹掉的东西,下游还需不需要」**——而这句话就是 $\Phi$-弱替代判据的内容。**$\Phi$ 由此回升一格**:第 22 条(它不是区分安放的坐标)不翻,但它是这个正确问法的形式化,不止是「计算代价的工具」。
27. ⚠️ **本条已被第 49 条改为「分两类」,2026-08-15,依 `2026-08-15-15-37-s3-frontal-criterion/N4-sequential-instance.md` §4。原文保留于下。** 【内部】**八条面相分三类,第三类是铰链而非第三个面**(M2 §5 + M1 §1)。在商上:可数、可索引、可复用;在载体上:可插值、可泛化;**在映射 $\tau$ 上:可微、可缓存、可组合**。第三类讲的是两面之间的关系(商映射正是那个把同一性面造出来、把相似性面杀掉的操作),故不是又一个面。「双面体」这个名字里没有铰链的位置。
28. 【内部】**「某面相在某安放上成立」欠定**(M2 §5)。三条面相各按不同的东西分裂:可插值按载体/商、可复用按商/载体、可组合按 $\tau$/$\kappa$。故单格须标**侧**与**方向**,判据陈述同此要求。原矩阵设计(八面相 × 七安放 = 56 格)形状错了,但不扩成 224 格——多数组合退化。
29. 【边界】**第 23 条推翻:AR 其实同空间,跨空间类为空,唯一性空真**(K2)。错因是把 $c$ 的值表当成载体所居的空间:logits 是 $c(x,\mathrm{anc}(\cdot))$ 的取值表,载体是 $h_t$。VQ 算距离同样得到一个 $\mathbb{R}^{|A|}$ 的表,若 logits 使 AR 跨空间则 VQ 亦跨,而 VQ 原文明说同空间。绑定权重时 $\tau = \arg\max_a\langle h_t,\mathrm{emb}(a)\rangle$(`modeling_llama.py:421/430/438/487`),**AR 是残差流在嵌入码本上的内积量化**,与 VQ 同型。连带:「异类被当成典型」作废;F0 的桥不用架;F2 简化;S3 的一个许可答案已删(规格 S-08)。**同空间与是否绑定无关**——绑定只决定打分的表与交出的表是否同一张。
30. 【界面】**签名有两处表达力缺口,同型**(K2 §3 修正四 + M1 §2)。一,不绑定权重时 $c$ 用的锚是 $w_a$ 而 $\kappa$ 交出的锚是 $\mathrm{emb}(a)$,两个锚映射,而签名只有一个 $\mathrm{anc}$(VQ 是单锚:同一 $e_k$ 进式 (1) 与式 (2))。二,一个安放可带**多个商**:AF2 同时带残基类型(有限)与扭转角(连续),八条面相在两商上取不同值,而签名只有一个 $\mathcal{A}=\Omega/\!\sim$。两例合起来:**签名把本该多份的东西写成了一份。**
31. 【界面】**纤维可见性带方向,且「被训练」至少三档**(K1 §4)。VQ 式 (3) 里同一个纤维内位移出现两次且 $\mathrm{sg}$ 反置——中间项把代表拉向载体(原文:only used for updating the dictionary),$\beta$ 项把载体拉向代表(原文:to make sure the encoder commits)。故须指明梯度给纤维的哪一侧。三档为:梯度到载体 / 梯度到代表 / **非梯度更新代表**(附录 A.1 的 EMA 式 (6)(7)(8),$\gamma=0.99$,不入任何损失项)。RAG 另给第四档:完全不更新(文档编码器冻住)。**故「可见」须定义在更新规则上,不得定义在目标函数上**,否则 EMA 那一档在定义下隐形。

## S3 阶段新增(第 38 条起)

38. ⚠️ **本条把截面性当成了普遍成立的,错;已由第 51 条改,2026-08-15,依 `2026-08-15-15-37-s4-confluence/P2-verdict.md` §1。原文保留于下。** 【内部】**双面体层的地基是「锚是商的截面」,即 $\tau(\mathrm{anc}(a))=a$**(N1 §2、N2 §2)。这一条事实做两份工:给出 $\kappa\tau$ **幂等**(故其像 = 不动点集,保测即可推出恒等),又给出 $\sim$-不变函数在往返下**逐点**不变。两处推导各自都过不去,靠的是同一条。**它不是技术假设,是这一层唯一的承重结构。** 而它在 VQ 死码上待查:死码从不被任何载体选中,却仍须满足 $\tau(e_a)=a$;若不满足,地基在 VQ 上有洞。

44. 【内部】**F0 的预先声明规则升为判据的唯一实质内容**(N1 §4)。有限矩差异是现成的数学对象,故判据作为数学没有新意;全部内容在「$\Phi$ 从架构读出」这一步。选 $\Phi$ 就是选度量,而看了结果再选度量则任何安放都能被说成代价小。**F0 那条规则是判据非空的唯一保证。** 相应地 F2 的地位三次上升:判据可测性的前提(等式右侧是反事实量,下游从不计算)→ 第二项的唯一测量装置 → 检验三判定的必要条件。

47. 【内部】**位移与交换子是两种不同的量,合并它们只有审美理由**(N4 §3)。铰链的形式是**交换子**——同一输入走两条路径之差(先提交后运算 vs 先运算后提交);现行判据的形式是**位移**——一个点与它的像之差,而恒等映射不是「另一种运算顺序」,故不存在第二条路径。要把位移写成交换子须找一个二元运算使 $\mathrm{id}$ 是 $\tau$ 与它交换的结果,构造不出来。**故 S-13 的答案是:双面体层要一个位移判据(两项)+ 一族交换子(每结构一个,形式统一)。**「一个判据」的目标落空,但落空方式可说清。这也推翻 N3 §3 自己的猜(「现行判据是模式在可测结构上的实例」)。
48. 【内部】**序列结构上有强弱两级,AR 精确落在两级之间,两级各解释一个不同的已知现象**(N4 §1–2)。弱级保前缀 $[\tau(x\cdot y)]_{1:|x|}=\tau(x)$,强级保拼接 $\tau(x\cdot y)=\tau(x)\cdot\tau(y)$,强蕴含弱。AR 弱级成立(因果掩码:`modeling_llama.py:399` `create_causal_mask`、`:236` `is_causal=True`)——**这正是 KV cache 合法的充要条件**,`:270` 的 `past_key_values.update` 能只追加不重算靠的就是它;强级失败即 **prompt 边界效应**。此前二者在项目里分记两条,现为同一结构的两级,而**两级之差恰好解释「AR 为何能缓存却仍有边界效应」**。另:BPE 与 AR 在 $\mathrm{Cost}^{\mathrm{prefix}}$ 上取不同值(同一张词表、同一个 $\mathcal{A}$,而 BPE 贪心最长匹配使后文能改前文切分),故**序列结构上的代价是 $\tau$ 的性质而非 $\mathcal{A}$ 的性质**——与第 40 条(第一项的零核只取决于 $\Phi$)对照,两项代价的依赖对象不同。

54. 【边界】**两个新入口,两路都没碰过**(P1 §4)。一,**多商无合成规则**:判据对每个商各自良定义,一个安放带两商就得两个代价,而总代价不是两者之和;AF2 是现成实例。二,**可泛化是签名族的元性质**:存表与现算可给出同一个 $\mathrm{anc}$,故它既不是 $\tau$ 的性质也不是更新规则的性质;加一个地址就改了 $\mathcal{A}$ 即改了整个签名,所以它问的是**能不能从一个签名走到另一个而不重训**,层级比其余七条高一格。这解释了第 49 条为何把可泛化悬着没归类。**须防过度解读**:「元性质」只说它问的对象不同,不说它更深刻;被钉住的后果仅一个(存参数里的表须 `resize_token_embeddings`)。

56. 【方法】**三层的重写判断**(P2 §3)。**双面体 + 推广不动点 层须重写且名字须换**:「双面体」漏了铰链,而铰链偏偏是唯一现成答出轴门的那类面相(第 33 条)又是判据装不下的那条(第 43/45 条);「推广不动点」的落点已变两次(恒假 → 泛函 → 两项),该词已不描述现在的对象;两面在商映射两侧(第 26 条)、面相分两类(第 49 条)。**建议新名:商-截面 + 双代价 层**——截面性是这一层最脆也最承重的一条(第 51 条),「双代价」写位移两项,铰链另立不塞进名字。**换名待用户决定,未擅改。** **换算界面层局部改不须重写**($\Phi$ 地位改两次;F0 升为判据唯一实质内容;「可测量化」现有确切内容)。**机制群系层未动但入口已备三个**,皆为「多个已知机制并成一条」的形状:弃权三实现一要求(第 25 条)、缓存/冻结/不受训三视角一机制(第 32 条)、序列两级各解释一现象(第 48 条)。

## S5 阶段新增(第 57 条起)

57. 【内部】**截面性不是「在文本输入上失效」,是我把它写在了错的层级上;修好之后 N1 与 N2 原样恢复**(Q1 §1–2)。$\tau$ 的值域是 $\mathcal{A}^*$ 而非 $\mathcal{A}$,故往返有两个:字级 $r(a)=\tau(\kappa(a))\in\mathcal{A}^+$ 与序列级 $R(w)=\tau(\kappa^*(w))$。**字级截面确实假**(F3 要测的就是它),**序列级截面由无损性自动成立**:$\kappa^*\tau=\mathrm{id}_\Omega$ 直接给出 $R$ 幂等,且 $\mathrm{im}(R)=\mathrm{Fix}(R)=\tau(\Omega)=:\mathcal{A}^*_{\mathrm{can}}$(规范切分集),故 $\kappa^*$ 在 $\mathcal{A}^*_{\mathrm{can}}$ 上是 $\tau$ 的真截面。N1 的幂等与 N2 零核定理的 $\Leftarrow$ 逐行恢复,只需把载体从 $\mathcal{A}$ 换成 $\mathcal{A}^*$。**代价是定理假设换了性质**:从「分词器的性质」(查词表可判)变为「输入分布的性质」($\pi$ 支撑在 $\mathcal{A}^*_{\mathrm{can}}$ 内)。**第 51 条与原第 11 条不再冲突——两者层级不同,可同真**,故 P2 §1 那个「真冲突」的裁决升级:不是一方适用域缩小,是双方讲的不是一件事。
58. 【内部】**截面代价不是第三项,是第一项裂成两块;它给 F3 的桥是「非规范质量」而非「失败 token 比例」**(Q1 §3)。$\mathrm{Cost}^{\mathrm{sec}}_{\bar\Phi}(\pi)=\sup_{\bar\varphi}|\mathbb{E}_{R_*\pi}\bar\varphi-\mathbb{E}_\pi\bar\varphi|$,即 $\mathrm{Cost}_\Phi$ 限制到 $\sim$-不变子族;截面性成立时这一块恒零,失效时不零,**故判据项数不变**。被积函数在 $\mathrm{Fix}(R)$ 上逐点为零 ⇒ $\mathrm{Cost}^{\mathrm{sec}}\le2\lVert\bar\Phi\rVert_\infty\cdot\pi(\mathcal{A}^*\setminus\mathcal{A}^*_{\mathrm{can}})$,含指标函数时上确界即 $\lVert R_*\pi-\pi\rVert_{\mathrm{TV}}$。**两处改实验设计**:须按语料频率加权而非按 type 计数(词表上均匀平均对应不到任何代价);且松弛是真的——$R$ 若在 $\bar\varphi$ 等值的序列间搬质量则代价为零而非规范质量为正,**截面失效可以完全不付代价**,这是第 52 条(判据只吃推前对)的第三次露头。
59. 【内部】**条件的否定恰好是三个已知病灶,而 token healing 就是把 $\pi$ 拉回规范集的投影算子 $R$ 本身**(Q1 §4)。$\pi$ 由 $\tau$ 作用于文本时由构造规范,故违反只能来自不经 $\tau$ 而直接造出 token 序列的路径,共三条:两段各自分词后拼接(prompt 边界效应、few-shot 模板不稳)、模型自回归续写(逐位从 $\mathcal{A}$ 采样从不过 $\tau$)、在 token 边界处切割/截断/缓存复用(token healing 的本体)。**三条独立记录的病灶 = 一个推导出来的条件的三种违反方式**;healing 的正确形式化就是「作用一次 $R$」,它不是补丁而是投影。
60. 【内部】**字级失效分三档且改名一步终止;不可达 token 由此推出,并接上已知的 glitch token 现象**(Q1 §5)。三档:完好 $r(a)=(a)$、碎裂 $|r(a)|>1$(单独出现时该 token 不会被产出)、改名 $|r(a)|=1$ 但 $r(a)\neq a$。**引理:改名一步终止**——$r(a)=(b)$ 时无损性给 $\kappa(b)=\kappa(a)$ 故 $r(b)=(b)$,**所以字级往返没有长于 1 的环,不存在反复重分词震荡这种病**。推论:$a\notin\mathcal{A}_{\mathrm{reach}}$ 的 token 可被模型输出但**没有任何文本输入能产出它**,故其输入嵌入与输出行向量都只受负类梯度 ⇒ **理论推出「只写不读」的 token 存在且行为异常**,即 glitch/undertrained token。**预注册:$\mathcal{A}\setminus\mathcal{A}_{\mathrm{reach}}$ 与文献用嵌入指标独立找出的 undertrained token 集应高度重合**;杀伤条件是同频段对照下重合不显著。**须查证的既有工作(用嵌入范数/logit 指标检测欠训练 token 那一支)我尚未读,不预设其内容。**
61. 【界面】**双锚与多商不是两个补丁,是同一个错误的两次露头:签名把本该是结构的东西写成了槽位**(Q2 §1)。三处缺口(S-06 双锚、S-15 多商、第 57 条的设计商 vs 有效商)共形。第 30 条已并前两处为「把本该多份的东西写成了一份」,第三处的加入把结论改成**「有结构的多份」**:双锚是**一对**(两件配合完成一次往返),多商有**两种复合**(并联/串联),把槽位改成列表既表达不出配合也表达不出复合。
62. 【界面】**$\mathrm{anc}$ 裂为一对后,截面性多出一条此前写不下来的失效来源,并掉出一个零 GPU 可测量**(Q2 §2)。$\mathrm{anc}=(\mathrm{anc}_{\mathrm{scr}},\mathrm{anc}_{\mathrm{ret}})$,前者进 $c$ 后者进 $\kappa$,**绑定从默认变成可判真假的条件**($\mathcal{C}$ 同且映射同;VQ 恒绑定、id-prim 侧恒绑定、不绑权 LM 不绑定)。截面条件展开为 $\arg\max_b c(\mathrm{anc}_{\mathrm{ret}}(a),\mathrm{anc}_{\mathrm{scr}}(b))=a$,**两个锚系统都在里面**,故失效有两个独立来源:词表本身(第 60 条),以及**两个锚系统不对齐**——后者是裂开之后才写得下来的。新增**锚对齐率 AAR** $=|\{a:\arg\max_b\langle\mathrm{emb}(a),w_b\rangle=a\}|/|\mathcal{A}|$:绑定时由 Cauchy–Schwarz 在范数齐一下必成立、范数不齐则未必,**故 AAR 把 K2 §3 的范数散布从几何图像的装饰变成截面性的决定因素**。成本是两个矩阵一次相乘,零前向零训练。
63. 【界面】**$\mathcal{A}$ 裂为商图,两种复合原子;AF2 的「分裂值」不是例外而是并联的必然**(Q2 §3)。并联(积):$\Omega\cong\prod\Omega_i$ 各分量各取商——AF2、product quantization、多码本 VQ。串联(塔):$\Omega\to\mathcal{A}_1\to\mathcal{A}_2$——规范切分、residual VQ、层级粒度、**MLA(提交之外多插一次压缩,那也是一次商)**。并联分量各自独立故面相可取任意组合,**所以「面相在某安放上成立」在多商安放上根本不完整**:第 28 条的「标侧与方向」须加第三项**标商**。
64. 【内部】**串联上代价次可加(已证),而「沿塔单调不减」是我自己写下又否掉的假命题**(Q2 §4)。$\mathrm{Cost}_\Phi(\tau_2\tau_1)\le\mathrm{Cost}_\Phi(\tau_1)+\mathrm{Cost}_\Phi(\tau_2)$,证法是位移插中间项 $\kappa_1\tau_1x$ 后逐 $\varphi$ 用三角不等式。**单调性反例是退化商**:把一切压成一点则 $\tau_2\tau_1$ 平凡地保任何代数结构而 $\tau_1$ 可以不保。三条后续:**方向与直觉相反——塔不比它的部件更贵**,多插一层商可以降低总代价(落在 MLA 上可判伪);**交换子不服从这条**(插中间项不给三角不等式),故位移与交换子的分开(第 47 条)在多商上第二次出现;**并联上没有不等式只有分量表**,若 $\Phi$ 可分解为各分量函数之和则次可加,否则无界关系,**登记为未证不许当结论用**。
65. 【机制群系】**演算成形到「能写下、能对齐、能比较」:三个组装算子 + 五条推理规则,原签名是单节点特例**(Q3 §1–2)。算子:串联 $\circ$、并联 $\otimes$、对偶 $\dagger$;**一个架构 = 一个表达式**(标准 LM 是 $\mathcal{I}_{\mathrm{out}}\circ[\text{计算}]\circ\mathcal{I}_{\mathrm{in}}$ 且两侧 $\omega$ 相反,VQ-VAE 是 $\mathcal{I}^\dagger\circ\mathcal{I}$)。规则:R1 对偶必反、R2 串联次可加、R3 零核(须沿**有效**商即塔的全部层不变)、R4 双坍缩、R5 交换子按结构。**边界如实记:它不能自动搜索或综合,北极星那句「如 Lean 之于数学」离得还远**;R1 未在全部实例上验,R5 只有一个成员加一个形状。
66. 【机制群系】**四个推导,其中两条是新结论**(Q3 §3–6)。可缓存需**两个**条件而非一条:$\mathrm{sel}$ 值域离散(提交不可逆)+ $\tau$ 保前缀(因果掩码)——**这解释了双向模型即使离散提交也不能增量缓存**,此前项目里「可缓存」只挂在一条上。不可达 token 是必然而非实现瑕疵:**商由 $\sim$ 定、可达性由 $\mathrm{sel}$ 定,两者是签名里不同的件故无理由一致**;可判伪推论是「统一了商与选择的分词方案不应有不可达 token」,故 **Unigram 的不可达率应低于 BPE**——这是跨算法族的对照而非同族比大小。另两个是已有条目的推导化:sink 的必然性成为 $\mathcal{A}$ 不是 $\Omega^+$ 的商而只是 $\Omega$ 的商这一句的推论(F1 判决那句「病在没有东西可归」的形式表述);MLA 作为塔受 R2 约束,且按 R3 压缩扩大零核 ⇒ **预注册其第一项代价低于同规模 MHA/GQA**。
67. ⚠️ 十条中 P1/P7 已由第 68 条并为一条。【方法】**十条预注册预言,六条不需要 GPU**(Q3 §7)。P1 AAR、P2 不可达 ∩ undertrained、P3 Unigram < BPE、P7 嵌入范数散布、P9 $\omega$ 必反、P10 双向不可增量缓存——**这六条本来就不需要卡**,且各自独立于需要卡的四条(P4 自生成非规范质量随长度增长、P5 第二项代价随规模下降、P6 MLA 第一项更低、P8 AR 的 $\lVert h_t-\mathrm{emb}(a_t)\rVert$ 不受压制)。每条都带杀伤条件,**故设备到位前这六条可全部结清**。

## F 轮规划阶段新增(第 68 条起;来源 `2026-08-23-19-02-f-round/`)

68. 【界面】**嵌入范数散布是锚对齐失败的机制,故 P7 与 P1 不是两条独立预言**(R3 · F7)。绑定时 $\arg\max_b\langle e_a,e_b\rangle=a$ 要求 $\lVert e_a\rVert^2\ge\langle e_a,e_b\rangle\ \forall b$,而 Cauchy–Schwarz 只给 $\langle e_a,e_b\rangle\le\lVert e_a\rVert\lVert e_b\rVert$,**故仅在 $\lVert e_b\rVert\le\lVert e_a\rVert$ 时才有保证**:范数长的向量会抢范数短的向量的 argmax。于是 K2 §3 修正三(内积量化 vs 欧氏量化只差范数齐一)与第 62 条(锚对齐率)是同一件事的两头——**范数散布不是几何图像的装饰,它是截面性在权重级失效的原因**。这条是写 F7 的代码时才看清的,登记为「实现细节反过来改了理论」的第一例。
69. 【内部】**byte-level 词表的 token 未必是合法字符串,故 $\Omega$ 对这类安放须取字节串而非字符串**(R3 · F3 坑一)。byte-level BPE 里一个 token 可以是多字节字符的一半,`decode` 返回替换符,再 encode 必不等于原 token。**若不隔离,则「碎裂率」这个数几乎全部是这个假象**(CJK 词表里这类 token 数以千计)。理论后果不只是工程隔离:这类对象**不在 Q1 §1 设定的 $\Omega$(字符串集)里**,故 Q1 的无损性前提 $\kappa^*\tau=\mathrm{id}_\Omega$ 须在字节串载体上重述。**这是本轮第二次由实现反推出的理论收窄**,与第 68 条同源。
70. 【方法】**P2 只能测「语料未出现」,不能测「不可达」;且碎裂 ≠ 不可达**(R3 · P2)。$\mathcal{A}_{\mathrm{reach}}$ 的定义要枚举全部字符串,不可行,故可测的只是「在给定语料下未出现」,**语料规模因此是协变量而非实现参数**。碎裂档($|r(a)|>1$)只说明该 token 单独出现时不被产出,它仍可能在更长上下文里被产出,**故碎裂是嫌疑不是证据**。另记一处可能的循环:若文献检测 undertrained token 的方法本身用嵌入范数,而第 68 条也测范数,则两者不独立、重合度会虚高——**须读完文献后判定并如实报**。
71. 【方法】**F2 须三臂而非两臂,上界臂是跨规模可比性的前提**(R4 · F2)。绝对代价因 $d$ 与嵌入尺度不同而跨模型不可比,故 P5 须用无量纲比 $\rho=\mathrm{Cost}^{\mathrm{sel}}(\text{avg vs cmt})/\mathrm{Cost}^{\mathrm{sel}}(\text{glb vs cmt})$,分母来自第三臂(喂全局平均嵌入 $\frac1V\sum_a\mathrm{emb}(a)$)。**离流形参照是副产品而非主要理由**:若第二项代价接近上界臂,则测到的是「离流形」而非「承诺」。另两个混淆项各配对照:范数差由 RMSNorm 在第一步吃掉(故 $\Phi$ 里 $\lVert u\rVert$ 那一项须单列不合并取上确界),温度扫五点且以熵作第二协变量——**后者顺带检验第 18 条:若代价是熵的单值函数,则「熵维数不够」那半错**。
72. 【方法】**$\Phi$ 按架构家族分写时,MLA 的维数差从 config 直接读出,同时暴露 P6 最大的混淆项**(R2 §1)。DeepSeek-V2-Lite 的 `kv_lora_rank=512` 而 hidden=2048,故 $\Phi_{\mathrm{MLA}}$ 的维数(512+64 rope)低于 $\Phi_{\mathrm{GQA}}$,按第 40 条(零核)$\Phi$ 越小零核越大代价越低——**P6 的来源因此是两个 config 数值而非直觉**。但 $\Phi$ 维数不同则上确界的取值范围不同,**故 P6 的比较本身不公平**:须一律报两版,(a) 各家自然 $\Phi$、(b) 两家都截到同一维数 $m=16$ 主方向,**若只有 (a) 出正结果则 P6 全部来自维数差**。主方向由权重矩阵的 SVD 定、不用任何激活统计,否则违 F0。
