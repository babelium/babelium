# FIB-2 · 次序推导公式

> 2026-08-26 · 全轮最大单点风险 · **执行前冻结,不因结果调整**
>
> **结论:推出来了,而且化归之后是一个良设且非平凡的问题——跨位点的次序由一个所有位点共用的未知向量 $d$ 决定,而权重级能知道的是「$d$ 落在哪个子空间里」。于是「谱零模型」恰好等于「假设 $d$ 各向同性」,真实推导等于「假设 $d$ 在坍缩子空间里典型」,两者之差就是坍缩子空间的各向异性有没有预测力。这个问题可以真的答错,故检验不平凡。**

---

## 一、要产出什么,以及它怎么会失败

FIB-2 的主结果需要一个函数:输入是权重,输出是各读出位点的**预测代价次序**;不许碰任何激活统计。

**它会以两种方式失败:**

1. **平凡通过。** 若预测退化成「矩阵大的代价大」,则近乎恒真,通过了也什么都没说。
2. **预测不了。** 权重级看不到「纤维的变化方向在真实数据上落在哪」,若这一块本质上是数据决定的,则权重级推导注定弱于校准级。

**本节的任务是把问题化归到能判断这两件事的形式。**

---

## 二、化归:次序由一个共用的未知向量决定

B02 定的主端点,对线性/仿射位点 $j$:

$$\mathrm{theory\_cost}_j=\Big\lVert\mathbb{E}_\mu\big[W_j N(u^{\mathrm{avg}})-W_j N(u^{\mathrm{cmt}})\big]\Big\rVert_2$$

$W_j$ 不依赖样本,故可移出期望:

$$\boxed{\ \mathrm{theory\_cost}_j=\lVert W_j\,d\rVert_2,\qquad d:=\mathbb{E}_\mu\big[N(u^{\mathrm{avg}})-N(u^{\mathrm{cmt}})\big]\in\mathbb{R}^{d_{\mathrm{model}}}\ }$$

**$d$ 是一个向量,且所有位点共用同一个 $d$。** 这一步把问题变成:

> **在不知道 $d$ 的情况下,能不能预测 $\lVert W_j d\rVert$ 的次序?**

这是一个良设的问题,而且答案不显然——这是本节最重要的一步。**它同时说明:跨位点次序检验测的不是「$\Phi$ 有多大」,是「$W_j$ 与 $d$ 怎么对齐」。**

### 化归的直接后果:两个零模型的含义变精确了

按 SVD 写 $W_j=U_j\Sigma_jV_j^\top$,则

$$\lVert W_jd\rVert^2=\sum_k\sigma_{jk}^2\,\langle v_{jk},d\rangle^2$$

**若 $d$ 各向同性**($\mathbb{E}\langle v,d\rangle^2=\lVert d\rVert^2/d_{\mathrm{model}}$ 对任意单位 $v$),则

$$\mathbb{E}\lVert W_jd\rVert^2=\frac{\lVert d\rVert^2}{d_{\mathrm{model}}}\sum_k\sigma_{jk}^2=\frac{\lVert d\rVert^2}{d_{\mathrm{model}}}\lVert W_j\rVert_F^2$$

$$\boxed{\ \text{谱零模型}\;=\;\text{按}\ \lVert W_j\rVert_F\ \text{排序}\;=\;\textbf{假设}\ d\ \textbf{各向同性}\ }$$

**这一句把零模型从「一个对照手段」变成「一个可陈述的假设」。** 于是真实推导要做的事有了确切内容:**说出 $d$ 的各向异性是什么,并且只用权重说。**

## 三、权重级能知道 $d$ 的什么:三条结构事实

### 事实一:$d$ 落在锚点差的张成里

$$u^{\mathrm{avg}}-u^{\mathrm{cmt}}=\sum_a p(a)e(a)-e(a^*)=\sum_{a\neq a^*}p(a)\big(e(a)-e(a^*)\big)$$

**故提交前后之差是「被放弃的候选与被选中者之差」的凸加权和**——这正是理论说的「纤维内被抹掉的那部分」,而它的载体是嵌入表的行差。**嵌入表是权重。**

### 事实二:径向分量被归一化压掉,只剩切向

$N(u)=\sqrt{d_{\mathrm{model}}}\,\gamma\odot u/\lVert u\rVert$。令 $u=u^{\mathrm{cmt}}$、$\Delta=u^{\mathrm{avg}}-u^{\mathrm{cmt}}$,一阶展开:

$$\hat u^{\mathrm{avg}}-\hat u^{\mathrm{cmt}}\;\approx\;\frac{P_\perp(\hat u^{\mathrm{cmt}})\,\Delta}{\lVert u^{\mathrm{cmt}}\rVert},\qquad P_\perp(\hat u)=I-\hat u\hat u^\top$$

**故 $d$ 的方向是切向的,径向那部分被吃掉。** 这与 B02 §3 的改判是同一件事的两面:范数落在零核里,而切向投影就是那句话的形式版本。**两处独立推出、在此对上,是一个内部一致性检查。**

**适用范围要写明:** 一阶展开在 $\lVert\Delta\rVert\ll\lVert u^{\mathrm{cmt}}\rVert$ 时成立,即低温区。**它是「为什么按切向构造」的理由,不是对测量的声称**——测量端用 B02 的精确式子,不用展开。高温区展开失效,故预测能力应随温度下降,这是一条可查的一致性检验。

### 事实三:哪些候选会竞争,由输出投影的几何定

$p(a)\propto\exp(\langle w_a,h\rangle/T)$,故 $p(a)$ 与 $p(a^*)$ 同量级要求 $\langle w_a,h\rangle\approx\langle w_{a^*},h\rangle$。**对未知的 $h$ 取平均,这要求 $w_a$ 与 $w_{a^*}$ 方向相近。** 而 $w_a$ 是 `lm_head` 的行——**也是权重**。

**故「谁与谁竞争」这个问题在权重级有一个可算的代理:输出行向量的余弦相似度。** 这一步是整个推导的关键,也是它可能错的地方:若实际竞争结构主要由 $h$ 的分布决定而非由 $\{w_a\}$ 的几何决定,则这个代理失效。**那个失效本身就是结果。**

## 四、坍缩协方差:构造(执行前冻结)

三条事实合起来给出一个只用权重的构造。

**输入张量:** 输入嵌入 $E\in\mathbb{R}^{V\times d}$、输出投影 $W_{\mathrm{out}}\in\mathbb{R}^{V\times d}$、归一化增益 $\gamma\in\mathbb{R}^{d}$。绑定时 $W_{\mathrm{out}}=E$。

```
第一步 · 竞争对
  对每个 token a,按 ⟨w_a, w_b⟩/(‖w_a‖‖w_b‖) 取前 k 个 b ≠ a
  → 竞争集 N_k(a)

第二步 · 切向差
  对 (a,b),b ∈ N_k(a):
    Δ_ab = e(b) − e(a)
    t_ab = γ ⊙ [ P_⊥(ê(a)) Δ_ab ] / ‖e(a)‖        ← 事实二的切向投影 + γ
                                                     (γ 因为 N 里含 γ⊙)

第三步 · 加权
  权重 ω_ab = softmax_b( ⟨w_a,w_b⟩/(‖w_a‖‖w_b‖) / T_surr )  在 N_k(a) 内归一
  ——T_surr 是代理温度,与测量端的温度扫描无关,单独冻结

第四步 · 协方差
  C = Σ_a π_a Σ_{b∈N_k(a)} ω_ab · t_ab t_ab^⊤ ∈ R^{d×d}
  ——π_a 是 token 的先验权重。零数据版取 π_a = 1/V(均匀)
```

**$\pi_a$ 是唯一一处「本可以用数据」的地方,而零数据版必须取均匀。** 这一条不是洁癖:取语料频率就引入了数据,权重级这一臂就不纯了。**均匀 $\pi_a$ 是一个已知的弱点,须如实报——它意味着权重级推导对高频 token 的竞争结构与低频 token 一视同仁,而实际代价由高频者主导。**

### 预测公式

$$\boxed{\ \mathrm{pred}_j\;=\;\sqrt{\mathrm{tr}\big(W_j\,C\,W_j^\top\big)}\ }$$

**推导:** 若 $d$ 在坍缩子空间里「典型」,即 $d\sim\mathcal{N}(0,C)$ 至一个尺度,则 $\mathbb{E}\lVert W_jd\rVert^2=\mathrm{tr}(W_jCW_j^\top)$。

**「典型」这个假设就是本预言的全部内容,也是它可以被打死的地方。** 若真实的 $d$ 恰好集中在 $C$ 不强调的方向上,预测失败。

## 五、四条臂,以及各自对应的假设

| 臂 | 预测量 | 等价于假设 |
|---|---|---|
| 形状零模型 | $\sqrt{d_j}$($d_j$ = 该位点输出维数) | 代价只由输出维数定 |
| 谱零模型 | $\lVert W_j\rVert_F$ | **$d$ 各向同性** |
| **权重级** | $\sqrt{\mathrm{tr}(W_jCW_j^\top)}$,$C$ 由 §4 | **$d$ 在坍缩子空间里典型** |
| 校准级 | $\sqrt{\mathrm{tr}(W_jC_{\mathrm{cal}}W_j^\top)}$ | $d$ 在实测二阶矩里典型 |

**校准级的构造(与既有工作对齐,故是公平基线):** 在一个与测量集**不交**的小校准集上估 $C_{\mathrm{cal}}=\mathbb{E}[\Delta N\,\Delta N^\top]$,再在测量集上预测。**不许用测量集本身估**——那不是预测,那是测量。

**评判:** 各臂预测次序与实测次序的 Spearman 相关,按 H07 的三态判(支持 / 反驳 / 证据不足)。**权重级须显著优于两个零模型;与校准级的比较是另一个问题,两个结果分开报。**

## 六、检验何时没有功效:一个可从权重算出的条件

**若 $C\propto I$,则 $\mathrm{tr}(W_jCW_j^\top)\propto\lVert W_j\rVert_F^2$,权重级与谱零模型恒等,检验无功效。**

故须先从权重算 $C$ 的各向异性并报告:

$$\mathrm{aniso}(C)=\frac{\lambda_1(C)}{\frac1d\sum_k\lambda_k(C)}\quad\text{或}\quad\text{有效秩}\ \frac{(\sum\lambda_k)^2}{\sum\lambda_k^2}$$

**$\mathrm{aniso}$ 接近 1 ⇒ 该模型上这个检验先天无功效,须在跑之前就知道并如实报,不许事后解释。**

**这一条与先行工作对上了:** 2608.04074 的零增益条件是「除非 $M_q\propto I$,正交变换次优」。**同一个结构在两处出现——各向同性时,读出加权与朴素度量等价。** 这是我们的框架与那一支的一个具体接触点,写论文时应当明引而非绕开。

## 七、Qwen3 的 q/k 位点:化归失效,而失效处正是新预言

§2 的化归用了「$W_j$ 可移出期望」。**Qwen3 的 q/k 位点上这一步不成立**——per-head norm 作用在 $W_j\hat u$ 之后:

$$\varphi(u)=\big\langle \mathrm{RoPE}_t\big(N_h(W_j\hat u)\big),\xi\big\rangle,\qquad \mathbb{E}[N_h(W_j\hat u^{\mathrm{avg}})-N_h(W_j\hat u^{\mathrm{cmt}})]\neq W_jd$$

**处置:在头内重复一次事实二。** per-head norm 把每个头内的径向分量压掉,故该头的有效读出是切向的:

$$\mathrm{pred}_j^{\mathrm{Qwen3}}=\sqrt{\mathrm{tr}\big(P_\perp^{(h)}W_j\,C\,W_j^\top P_\perp^{(h)}\big)},\qquad P_\perp^{(h)}=I-\hat m_h\hat m_h^\top$$

$\hat m_h$ 是该头输出的主方向(由 $W_j^{(h)}$ 的第一右奇异向量与 $C$ 共同定,只用权重)。

**故 FIB-0 那条新预言在这里有了定量形式:** Qwen3 的 q/k 位点多一个投影 $P_\perp^{(h)}$,而投影只会减小 $\mathrm{tr}$,**故 $\mathrm{pred}^{\mathrm{Qwen3}}_{q,k}<\mathrm{pred}^{\mathrm{Qwen2}}_{q,k}$ 按构造成立;v 位点无投影故无差异。** 预言从「更低」变成「低多少」,可对上实测。

## 九、风险的当前状态

**原风险陈述:** 「权重级推导看不到纤维变化方向在真实数据上落在哪里,想不清楚就会退化成矩阵大的代价大。」

**化归之后风险变具体了,而且从「可能写不出来」降为「可能预测不准」:**

| 原担心 | 化归后的状态 |
|---|---|
| 会退化成平凡版本 | **不会。** 平凡版本恰好是谱零模型($d$ 各向同性),而权重级与它的差是 $C$ 的各向异性,两者不同构 |
| 可能写不出公式 | **写出来了**(§4),且只用三个权重张量 |
| 可能不如校准级 | **仍然可能,且这一条现在是明确的实验问题**——四条臂一起报,弱于校准级也是有内容的结果 |
| $C$ 可能各向同性 | **可在跑之前从权重算出**(§6),无功效的话提前知道 |

**新暴露的一处弱点(原来没看见):$\pi_a$ 只能取均匀。** 权重级这一臂对高频与低频 token 的竞争结构一视同仁,而实际代价由高频者主导。**这是权重级相对校准级的一个结构性劣势,不是实现瑕疵**——它就是「不用数据」的代价。须写进限制。
