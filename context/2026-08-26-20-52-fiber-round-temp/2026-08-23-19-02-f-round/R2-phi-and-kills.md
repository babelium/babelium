## 一、$\Phi$ 是什么,和它为什么必须按家族分写

判据的两项都对 $\varphi\in\Phi$ 取上确界。$\Phi$ = 提交之后、下游真正读到的那些标量函数。**它不是我挑的,是架构决定的**:提交交出 $\mathrm{emb}(a_t)$ 之后,下一层拿它做什么,那些「做什么」就是 $\Phi$。

三家在这一步不同,故三份声明。**下面每份都须在跑之前用该家的 `modeling_*.py` 逐行核对,标 ⬜ 者未核对。**

### $\Phi_{\mathrm{GQA}}$ — Llama / Qwen2 / Qwen3 dense 与 MoE(非 MLA)

提交后的量 $u=\mathrm{emb}(a_t)\in\mathbb{R}^d$ 依次经过:

1. **RMSNorm**:$\hat u = u/\sqrt{\overline{u^2}+\epsilon}\cdot\gamma$。故 $\Phi$ 含 $\varphi_0(u)=\lVert u\rVert_2$(归一化把它吃掉,但吃掉本身是信息丢失,须登记)。
2. **四个线性投影**:$q=W_q\hat u$、$k=W_k\hat u$、$v=W_v\hat u$;以及 MLP 的 $W_{\mathrm{gate}}\hat u$、$W_{\mathrm{up}}\hat u$。

$$\Phi_{\mathrm{GQA}}=\big\{\,u\mapsto\langle W\hat u,\ \xi\rangle\ :\ W\in\{W_q,W_k,W_v,W_g,W_{\mathrm{up}}\},\ \xi\in\text{该矩阵输出空间的单位向量}\,\big\}\cup\{\lVert u\rVert_2\}$$

**实践上取有限子族**:$\xi$ 取该 $W$ 输出的前 $m$ 个主方向(由 $W$ 的 SVD 定,**不看数据**,故不违 F0)。$m$ **在跑之前写死为 $m=16$**。

**为什么是第一层而不是全部层**:$\Phi$ 的定义是「提交后**紧接着**读到的」。往深处走会把后续层的非线性混进来,那时测的不再是提交的代价。**这是范围限定,不是省事**:更深的量可以另立一族 $\Phi^{(L)}$,但两者不能混报。

### $\Phi_{\mathrm{MLA}}$ — DeepSeek-V2 系

MLA 在 $q,k,v$ 之前多插一次低秩压缩(`kv_lora_rank=512`,而 hidden=2048)。故下一层实读的不是 $W_k\hat u$,是 $W_{k}^{\uparrow}(W^{\downarrow}\hat u)$,中间过了 512 维瓶颈。

$$\Phi_{\mathrm{MLA}}=\big\{\,u\mapsto\langle W^{\downarrow}\hat u,\ \xi\rangle\ :\ \xi\in\mathbb{R}^{512}\ \text{单位}\,\big\}\cup\{\text{rope 分支的}\ W^{\mathrm{rope}}\hat u\}\cup\{\lVert u\rVert_2\}$$

**关键:$\Phi_{\mathrm{MLA}}$ 的维数(512 + 64 rope)低于 $\Phi_{\mathrm{GQA}}$ 的(每头 128 × 头数)。** 按 R3(零核),$\Phi$ 越小零核越大、代价越低——**这正是 P6 的推导来源,而它现在是从 config 的两个数读出来的,不是从直觉**。

**但立刻出一个混淆项,必须报:$\Phi$ 维数不同则两项代价的上确界取值范围不同,故 P6 的比较是不公平的。** 处置:**P6 一律报两个版本**——(a) 各家自然 $\Phi$;(b) 两家都截到同一维数 $m=16$ 主方向。**若只有 (a) 出正结果而 (b) 不出,则 P6 的正结果全部来自维数差,不是 MLA 的性质。** 这条须事先写死。

### $\Phi_{\mathrm{VQ}}$ — VQ-VAE / VQGAN(F5)

提交交出码字 $e_k$,下游是解码器第一层(通常卷积)。$\Phi_{\mathrm{VQ}}=\{e\mapsto\langle\mathrm{Conv}_1(e),\xi\rangle\}$,$\xi$ 同样取前 16 个主方向。**⬜ 须按所选模型的解码器首层核对,不同 VQ 实现首层不同。**

## 二、杀伤条件,逐条

| # | 预言(方向已定) | 杀伤条件(看数前写死) | 阈值来源 |
|---|---|---|---|
| **P1** | 绑定模型 AAR ≈ 1;不绑定模型 AAR < 绑定组 | 若**任一**绑定模型(Qwen2.5-0.5B/1.5B)AAR < 0.95 → 「绑定 ⇒ 锚对齐」错,回到范数散布重推。若不绑定组 AAR 中位数 ≥ 绑定组最小值 → 绑定/不绑定这一列不预测对齐 | 0.95 是任选的,但**事先任选合法**;须同时报完整分布不只报是否过阈 |
| **P2** | $\mathcal{A}\setminus\mathcal{A}_{\mathrm{reach}}$ 与文献 undertrained 集重合度高 | 须先定「重合度」:$\mathrm{Jaccard}$ 与「在同频段分层后的 lift」。**杀伤:分层 lift ≤ 2.0**(即不可达 token 落入 undertrained 集的概率不到同频段基线的两倍)→ 不可达不是欠训练的原因 | lift 2.0 事先定 |
| **P3** | Unigram 族不可达率 < BPE 族 | 杀伤:两族**中位数之差 ≤ 0**,或 Mann–Whitney $p>0.05$(单尾)。样本 = 各族 ≥ 4 个分词器 | 族内样本 ≥ 4 事先定 |
| **P4** | 自生成续写的非规范质量随长度单调增 | 杀伤:在 {64,128,256,512,1024} token 五点上,**Spearman 相关 ≤ 0** 或 $p>0.05$ | 五个长度点事先定 |
| **P5** | 第二项代价随规模下降 | 杀伤:主梯五点上 Spearman(规模, 代价) **≥ 0**。**且须在 AAR 与 tie 作协变量后仍成立**——若控制 tie 后趋势消失,记为「趋势由 tie 解释」而非 P5 成立 | R1 §2 的断点决定 |
| **P6** | MLA 第一项 < 非 MLA(同 MoE 对照) | 杀伤:**(b) 等维版本**下 MLA 不低于对照 → P6 由维数差解释,不成立。(a) 与 (b) 都须报 | §1 的 (a)/(b) |
| **P7** | 嵌入行范数散布使 argmax ≠ 最近邻 | 杀伤:行范数的 $\mathrm{CV}=\sigma/\mu \le 0.01$(即近似齐一)→ 内积量化与欧氏量化实质等价,K2 §3 修正三无实测意义 | CV 0.01 事先定 |
| **P8** | AR 的 $\lVert h_t-\mathrm{emb}(a_t)\rVert$ 不受压制;VQ 的受压制 | 杀伤:AR 上该量随层深/生成步**不增**(Spearman ≤ 0)→ 「AR 无约束项」不产生可观测后果 | — |
| **P9** | 成对界面 $\omega$ 必反 | 杀伤:存在一个实例两侧 $\omega$ 同 → 签名错。**判法须先写:$\omega$ 由「$\mathrm{anc}$ 的值域是 $\Omega$ 还是 $\mathcal{X}$」判定** | A4 §1 |
| **P10** | 双向模型即使离散提交也不可增量缓存 | 杀伤:存在一个双向模型有合法增量 KV cache(即追加输入不改已算前缀的任何 K/V)→ 「可缓存需两条件」错 | Q3 §3 |

**三条须单独说明:**

- **P2 的文献集我还没读。** 「用嵌入指标检测 undertrained token」那一支须先读、先确认其判定方法,再定重合度算法。**若其方法本身用了嵌入范数,而 P7 也测范数,则两者不独立,重合度会虚高。** 这个可能的循环须在读完之后判定并如实报。
- **P5 是唯一必须要大模型的。** 其余九条在小模型上都能测。**故 32B 那张卡的价值全押在 P5(加 P6)上**,这与 CC-05 的说法一致,但现在有了具体的杀伤条件。
- **P9/P10 是结构核查不是测量**,故它们的「杀伤」是找到一个反例,不是算一个数。P10 须明确:BERT 类模型在**推理时**当然可以缓存整段的 K/V(全量重算后缓存),要判的是**增量**——追加 token 后已有前缀的 K/V 是否不变。

## 三、$\Phi$ 声明的三条纪律(跑之前冻结)

1. $m=16$ 主方向、只取第一层、$\xi$ 由 $W$ 的 SVD 定,**这三条在见到任何数据之前写死**,不因结果调整。
2. 主方向的 SVD 只用**权重矩阵**,不用任何激活统计。用了激活就是看了数据,违 F0。
3. 三份 $\Phi$ 的差异(维数、瓶颈)**须随结果一起报**,因为跨家比较的公平性完全取决于它。
