# A3 — 相似性判据:「什么算可比」

A1 给出相似性面签名 $(\mathcal{X}, \tau_{\text{top}}, c)$ 但把 $c$ 当作已给。A3 问 $c$ 由什么定。**结论比 A2 更硬,且对内核不利。**

## 1. $c$ 不在 $\Omega$ 上

A2 的 $\sim$ 是 $\Omega$ 上的关系。$c$ 不是——它活在 $\mathcal{X}$ 上,而标准文本模型里 $\mathcal{X}$ 在地址**之后**才出现:

$$\Omega \xrightarrow{\ \sim\ } \mathcal{A} \xrightarrow{\ \text{emb}\ } \mathcal{X} \xrightarrow{\ c\ } \mathbb{R}$$

**相似性面不比较内容,它比较地址的像。** 两块内容无法直接比,必须先取商成地址、再嵌入、才可比。分级比较**在二值判断的下游**。

这不是普遍事实,是文本的事实。VQ 反过来:编码器先给出连续特征,再量化成地址。

## 2. 哪一面是原始的,取决于安放方式

| 安放方式 | 次序 | 原始面 |
|---|---|---|
| 文本输入分词 | $\Omega \to \mathcal{A} \to \mathcal{X}$ | **同一性** |
| AR 输出采样 | $\mathcal{X} \to \mathcal{A}$ | 相似性 |
| VQ 量化 | $\Omega \to \mathcal{X} \to \mathcal{A}$ | 相似性 |
| diffusion / flow 轨迹 | $\mathcal{X} \to \mathcal{X} \to \cdots$ | 相似性 |
| 层级粒度(残基/原子/frame) | $\Omega \to \mathcal{A} \to \mathcal{X}$ | 同一性 |
| 检索 RAG / KG | $\mathcal{X}$ / $\mathcal{A}$ | **两极对照** |

**哪一面原始不是 token 的性质,是安放方式的性质。** North Star 要求机制群系推导架构相关差异,这是第一个符合要求的候选:不是列举各领域怎么做,是一个二值结构参数,取值决定次序。

一条诊断随之而来:**文本输入是六行里的异类**(与它同列的层级粒度也是内容先有名字),而它恰是所有 token 理论化的出发点。「token 是信号切片」这条根假设,来自恰好那个同一性面原始的安放方式。换个安放方式,信号根本不是被切的东西,而是被**吸附**到锚点上的东西。

## 3. 三级判据

**S0 规定级** — $c$ 由约定给定(余弦、点积、$L^2$)。可算,但为什么是这个不作解释。
**S1 学得级** — $c$ 被目标函数塑形。对比学习直接优化 $c$;嵌入矩阵一被训练,几何就被塑形。实际在用的那级。
**S2 功能级** — $c(x,y)$ 大当且仅当下游计算对 $x,y$ 的处置相近。语义上真想要的那级。

S2 与 A2 的 I2 是**同一个东西的分级版**:I2 问处置是否相同(二值),S2 问处置差多少(分级)。这不是巧合,是 A1 §3 那道落差在判据层的复现——同一道落差,在承载、在判据、后面在签名上各现一次。

## 4. $\tau$ = 锚点 + 比较:三个机制其实是一个

换算 $\mathcal{X} \to \mathcal{A}$ 要求把 $\mathcal{X}$ 划成胞腔,一址一腔。$c$ 单独做不到这件事,还需一组**锚点** $\text{anc}: \mathcal{A} \to \mathcal{X}$:

$$\tau(x) = \arg\max_{a \in \mathcal{A}} c\big(x, \text{anc}(a)\big)$$

代入三处:

| 机制 | 锚点 | $c$ |
|---|---|---|
| AR argmax / 采样 | unembedding 各行 | 点积 |
| VQ 最近邻 | codebook 各码字 | 负 $L^2$ |
| attention | 各 key | 缩放点积 |

**三个被当作不同机制的东西是同一个式子的三次代入。** 锚点即地址在 $\mathcal{X}$ 中的代表,$\kappa = \text{anc}$ 本身。

## 5. 两个复合的方向恰好相反

$\kappa$ 与 $\tau$ 有两个复合,哪个是恒等取决于哪一面原始:

**同一性原始(文本)** — $\kappa\tau = \text{id}$ 于 $\Sigma^*$(串往返回得来),$\tau\kappa \ne \text{id}$ 于 $\mathcal{A}^*$(非规范地址串会被重切)。
**相似性原始(VQ)** — $\tau\kappa = \text{id}$ 于 $\mathcal{A}$(码字量化回自身),$\kappa\tau \ne \text{id}$ 于 $\mathcal{X}$(量化误差)。

$$\boxed{\text{两种安放方式坏掉的是相反的那个复合}}$$

A2 §4 已得「$\kappa$ 同态、$\tau$ 截面」;此处得其对偶「$\kappa$ 是 $\tau$ 的截面」。同一对映射,在两种安放方式下代数身份互换。

## 6. 不动点在相似性原始时恒假:内核受损

已证那级是 $\kappa\tau p^* = p^*$。在相似性原始的安放方式里,$\kappa\tau$ 把 $\mathcal{X}$ 上的分布推成**支撑在有限锚点集上的离散测度**。若 $p^*$ 连续:

$$\kappa\tau p^* \text{ 离散} \ne p^* \text{ 连续} \qquad \text{恒成立}$$

**不动点条件不是难满足,是恒假。** 它不能只靠推广覆盖 B2 / B3——那里它无内容。

这比 A1 §6 说的更严重。A1 §6 说缝比预想的大,A3 §5–6 说**缝的两侧要的是相反的复合,而已证那条在其中一侧恒假**。C0 必须照此登记,C3 不得假装 L1 是普适起点。

**但同时它精确指出了替代物。** 若 $F(\kappa\tau x) = F(x)$ 要在离散化下成立,$F$ 必须**粗到看不见离散化**——即 $F$ 只读一族检验函数下的期望。这正是弱收敛 / 矩匹配的形状:

$$\mathbb{E}_{\kappa\tau p}[\phi] = \mathbb{E}_{p}[\phi], \quad \forall \phi \in \Phi$$

$\Phi$ = 下游实际读取的量。**$\Phi$ 大则条件强、$\Phi$ 小则条件弱,理论的实质内容变成「每个安放方式的 $\Phi$ 是什么」。** 这是 L2 的具体构造,C3 直接接手;$\Phi = $ 全体有界可测函数时退回 L1,$\Phi$ 为单点时退到平凡,已证那级作为特例落在里面。
