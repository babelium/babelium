# Token 理论 — North Star

> Created: 2026-08-14 23:24
> Topic: Token 理论（同一性↔相似性换算界面）
> Phase: Phase 1 — North Star Crystallization
> Status: **PINNED**

## North Star

▎揭示「token 是信号切片」这一从未被言明的根假设只描述了 token 的一个面。token 是一个双面体：一面是离散可寻址的同一性（可数、可索引、可缓存、可复用、可组合），一面是连续可比较的相似性（可微、可插值、可泛化）。二者何时确实是同一枚硬币，有其成立条件——编码-解码往返的不动点是该条件目前唯一被证明的特例，将其推广为一般判据是本理论的首要任务。

▎研究重点是建构同一性与相似性之间的换算界面，并把承诺——换算实际发生的那一事件——从解释性概念做成可测量、可操作化的量。

▎沿此建立一套形式化、可执行的机制群系：不是自然语言的分类学，而是一套记法 / 演算 / 系统（如 Lean 之于数学、PyTorch 之于 DL），使任意领域的任意 token 方案都能在其中被写下、对齐、比较与检验。其核心与词汇 architecture / method / algorithm 无关，但必须推导出架构相关的差异：换算的不同安放方式（采样 / 量化 / 轨迹 / 层级粒度 / 检索）如何生成各领域已观测的 token 现象，并给出尚未观测的可判伪预测。

▎外部学科（符号学 / 信息论 / 通信论 / 编码论 / 抽象代数 / 语言学等，不限于此）按单一标准选择性纳入：它是否为换算的某一面提供可用的判据或运算；纳入者内化为理论的组成部分并带上自身的权限边界，不适用者不取。

▎全过程以贝叶斯方式对待一切既有经验规律，让坐标轴从全谱系证据中自行涌现而非预先声明；最终为 token 建立一套自立的、可检验的形式理论。

### 一句话旗号

把 token 从「信号的切片」重新确立为「同一性与相似性之间的换算界面」，并将该换算铸成一套形式化可执行的机制群系，使全谱系领域的 token 方案首次可被统一书写、比较与检验。

## 地基词汇（贯穿全程，不得漂移）

| 术语 | 定义 | 当前状态 |
| --- | --- | --- |
| **同一性** | 离散、可寻址的那一面：可数、可索引、可缓存、可复用、可组合。判据问题属类型论本行——「什么算同一个 token」。 | 有词汇，无统一判据 |
| **相似性** | 连续、可比较的那一面：可微、可插值、可泛化。量度（度量、内积、散度）是其实现手段，不是其本身。 | 有词汇，无统一判据 |
| **换算界面** | 同一性与相似性之间的双向转换本身。理论的唯一承重件。不是「切法」，切法只是它的一个投影。 | **待建构** |
| **承诺** | 换算实际发生的那一事件。不是自回归的特权：AR 采样、VQ 最近邻、diffusion/flow 沿 timestep 的摊薄、层级粒度的选定、检索的相似度匹配，都是承诺的不同安放方式。 | **解释性构造 → 待做成可测量量（交付物）** |

承诺的证据学地位必须如实记录：**尚无任何一篇论文直接测量过模型的承诺状态。** 目前最接近的操作化代理是 BLT 的下一字节熵（低熵=局部续写已基本确定，高熵=应增加昂贵计算）。把承诺做成可测量、可操作化的量，是本理论要交付的东西之一，不是已有前提。

## 已定裁决（本轮锁定）

1. **内核选择**：往返不动点的推广列为**首要任务**，承担其风险。已证的特例只覆盖 character↔token string 的随机映射对（τ 编码、κ 解码，一致性判据 κτp\* = p\*，exactness 为 κτ = id）；「每个换算界面都有一个不动点形状的成立条件」是**待证推广**，不是已有结论。若不成立，形式内核需另寻种子——此风险已知并接受。
2. **不动点判据反读方向**：往返偏差不是 bug，是两面未对齐时必须付的价。派生误差分解 ‖κq_n − p\*‖₁ ≤ ‖q_n − q\*‖₁ + ‖κτp\* − p\*‖₁ 把「模型学得好不好」与「硬币两面对不对齐」分成两项。
3. **离散性不是 token 的必要条件**；可判别的同一性才是。该判据允许随机分词而仍 exact（各文本分词支撑不相交且确定性解码），这是形式层面的直接支持。
4. **架构无关 ≠ 不谈架构**：核心与词汇架构无关，但**必须推导出**架构相关的差异。反例不可回避：sink 在 AR 中是持久 memory / 近似 no-op anchor；在 diffusion transformer 中变为动态轨迹路由点（随 layer 与 timestep 变、几乎不在 index 0、主要落在少量 text-conditioning keys）；ViT registers 证明 register-like 功能不依赖 AR 而形态不同。
5. **机制群系的形态**：形式化、可执行的记法 / 演算 / 系统，不是自然语言分类学。产物应为可写下、可对齐、可比较、可检验的东西（记法、演算规则、可运行的实现），不是散文。
6. **外部学科单一纳入判据**：是否为换算的某一面提供可用的**判据或运算**。纳入者内化并带上自身权限边界。不按「看起来相关」纳入。
7. **贝叶斯态度**：一切既有经验规律只作先验，由后续证据升降。最终结论不必是任何既有条目列表。
8. **全谱系**：不设域限制。凡涉及 token 者皆在范围内（语言、视觉、语音、视频、动作、图、时序、代码、3D 几何、分子与蛋白的结构性层级表征、检索与知识表示、世界模型等）。叙述上始终按全谱系立论。
9. **坐标轴自涌现**：轴体由全谱系证据聚合后自行涌现，任何预先草案仅作占位，不得反过来约束提炼。

## 当前证据状态

最强的一条结构性结论，已改写框架：**选择机制 ≠ 承载内容。** 槽位可由纯结构原因形成（causal mask 使位置 0 只能注意自身、恒有 p0=1，MLP 检测并放大该不对称）而随后承载语义（value 被复制为共享低维 tag，可探针读出真假 / 情感）；也可由预测不确定性选中而仅作计算预算控制器。混为一谈会同时高估「语义边界」证据并低估结构机制。

**当前证据可支持**：下一步预测熵是有效的动态计算分配信号；端到端训练可学出跨语言跨模态的动态 chunking；causal P0 sink 的形成不要求固定 BOS 语义；register/sink-like 槽位可承载任务相关语义或全局信息；register-like 内部工作空间不依赖自回归；sink 的功能随 AR / 双向 ViT / diffusion 推理而改变。

**当前证据不支持**：所有 attention sink 都是预测不确定性或承诺边界；熵边界即语义 / 词 / 推理步骤 / 认知承诺边界；H-Net 的 router score 是校准的不确定性概率（它是相邻 causal hidden state 的投影余弦差异，论文明确不作概率）；patch boundary、attention sink、massive activation、visual register 属同一底层电路。

**权限边界须随理论携带**：Rényi 效率（α=2.5 与 BLEU 相关性 0.78）的 Compression Principle 是经验假设，**不由编码定理推出**；结果依赖调参、协方差近似与有限 MT 设置。编码论在此提供的是诊断量，不是定律。同理，一致性定理假定 token 级估计已收敛，无法据以对 tokenizer 排样本效率 / 优化难度 / 归纳偏置。

## 坐标轴草案（占位，将被涌现结果取代）

主轴候选：换算的**位置**（在哪一层发生）｜换算的**时刻**（训练固定 / 推理动态 / 生成时即时）｜换算的**硬度**（硬投影 / 软摊薄）｜换算的**可逆性**（往返偏差大小）｜换算的**习得程度**（规则给定 / 端到端学出）｜**触发信号 vs 承载内容**是否同一（证据要求的独立轴）。

辅轴候选：承载体（信号切片↔潜码坐标）｜依赖塑形（locality / 条件熵重分配）｜尺度顺序（raster / next-scale / LoD / 层级粒度）｜粒度经济（词表规模、输入输出解耦）｜同一性面与相似性面的实在程度不对称（空符号候选位）。

## 理论内部未决项

- 往返不动点能否推广为一般换算界面的成立判据。
- 承诺的可测量化路径：需在同一端到端模型中同时记录下一步熵、表示变化、边界决策与后续计算收益，并分别操纵语义变化与表面可预测性；在严格相同实际计算预算下比较 entropy / learned router / random / space / 人工语义边界，看哪种最能预测「增加一次高层计算的边际收益」。
- 同一性的判据是否可由类型论直接给出，或需自建。
