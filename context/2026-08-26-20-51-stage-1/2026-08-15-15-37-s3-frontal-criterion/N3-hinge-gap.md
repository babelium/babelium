# N3 — 铰链缺口:不是判据没写好,是判据只做了一个范畴里的那一份

**结论:S-13 不需要「扩成 $(\tau,\kappa,p)$ 的泛函」也不需要「另立第二个判据」。铰链三条面相是同一句话在三个不同结构上的实例——「$\tau$ 保不保这个结构」。而现行判据本身就是这句话在**可测结构**上的实例。判据不是一个判据,是一个**按结构编号的模式**;铰链是它的其余编号。**

信心分层写在 §5:哪些已证,哪些是猜。

---

## 一、先把缺口证硬:盲区不是疏忽,是这种形式的判据必然的

**命题(盲)。** $\mathrm{Cost}_\Phi$ 与 $\mathrm{Cost}^{\mathrm{sel}}_\Phi$ 的值只依赖 $\tau$ 的**几乎必然等价类**;而铰链三条性质**不是 a.e.-不变的**。故任何形如「$p$ 与其推前之间的泛函」的判据都测不到铰链。

**推理。** 两项都是对 $p$ 的积分,改 $\tau$ 于一个 $p$-零集上不改任何积分值。而:

- **可微**是逐点性质,在零集上改 $\tau$ 即可破坏或修复;
- **可缓存**(提交不可逆)同理——把 $\tau$ 在一个零集上改成可逆的,不动任何积分;
- **可组合**($\tau(xy)=\tau(x)\tau(y)$)同理:两个典型点的拼接可以落进零集。

所以缺口是**结构性的**,不是「这一版判据没写好」。任何测度上的泛函都盲。∎

**a.e. 那个论证会被人嫌人造**(实际的 $\tau$ 就是 $\arg\max$,没人去零集上改它),所以补一个不人造的版本:**判据把 AR 判成免费,而 AR 在工程上最大的一堆麻烦恰在铰链上。** 按 N2,$\Phi_{AR}$ 全 $\sim$-不变故第一项恒零;而直通估计、REINFORCE、Gumbel-Softmax 这一整片文献存在的理由是 $\tau$ **不可微**——那是铰链。判据对最大的那块工程困难报零。**这不是精度问题,是它没有这个量纲。**

## 二、三条铰链是同一句话

逐条改写,不加新概念:

| 面相 | 现有说法 | 改写成「$\tau$ 保不保结构」 |
|---|---|---|
| 可组合 | $\tau(xy)\neq\tau(x)\cdot\tau(y)$ | $\tau$ 不保 $\Omega$ 的**幺半群结构**(拼接) |
| 可微 | $\arg\max$ 几乎处处零梯度 | $\tau$ 不保 $\Omega$ 的**光滑结构**(连续都不保) |
| 可缓存 | 提交不可逆 + 因果掩码 ⇒ 过去的 K/V 永不变 | $\tau_t$ 只依赖前缀,即 $\tau$ **保序列结构**(对前缀过滤适应,不前视) |

三条都是「$\tau$ 与 $\Omega$ 上某个额外结构可不可交换」。**而 M2 §5 记的「可组合按 $\tau$/$\kappa$ 分裂」在这个写法下不再是异常:$\kappa$ 保结构($\kappa$ 是截面,由构造保)、$\tau$ 不保(它是商,由构造塌)。** 方向的不对称是结构性的,不是两条独立观察。

**载体 $\Omega$ 同时带若干结构**:可测结构、幺半群结构、光滑结构、序列结构。此前一直只用了第一个——因为判据要积分,只需要可测结构。**其余三个从没进过判据,这就是铰链缺口的全部内容。**

## 三、于是判据是个模式,现行判据是它的一个实例

统一写法(**这是本节的猜,不是证,见 §5**):

> 给定载体上的一个结构 $S$。问 $\tau$ 是否保 $S$。若不保,代价 = 不保的程度,以 $S$ 自己的语言度量。

- $S$ = 可测结构 → 「不保」的程度 = $p$ 与 $\kappa\tau p$ 在 $\Phi$ 上的差 = **现行判据两项**。
- $S$ = 光滑结构 → 「不保」的程度 = 导数的缺失程度 → 直通估计正是在**替一个不存在的导数造一个**(K1 引 1711.00937 §3.2:「just copy gradients from decoder input $z_q(x)$ to encoder output $z_e(x)$」,可行的理由是两侧同 $D$ 维)。
- $S$ = 幺半群结构 → 「不保」的程度 = $\tau(xy)$ 与 $\tau(x)\tau(y)$ 的差 → prompt 边界效应那一族的量级。
- $S$ = 序列结构 → 保则可缓存,不保则每步全量重算 → **M2 §3 已实测:AR 保、diffusion 不保,且这解释了单步成本差异。**

**「双面体 + 铰链」在这个写法下站得住:**

- 同一性面 = $\Omega$ 作为「带商的集合」这一层结构;
- 相似性面 = $\Omega$ 作为「光滑/度量空间」这一层结构;
- 铰链 = $\tau$ 对每层结构保不保。

**故铰链不是第三个面,也不需要第三个判据——它是「面」与「面」之间那个动词。** 第 27 条说铰链讲的是两面之间的关系,这一节给出关系的具体形式:**保结构 / 不保结构。**

## 四、一个自洽检验(独立算出同一结果)

模式若对,应能重推出 M1 §2 那条实测规律(有限商杀插值、连续商不杀),而且不能用它推出来的东西去证它。

推:相似性面 = 光滑结构。$\tau$ 保光滑结构要求 $\mathcal{A}$ 上有相容的光滑结构。$\mathcal{A}$ 有限 ⇒ 离散拓扑 ⇒ 除常映射外无非平凡光滑结构可保 ⇒ **$\tau$ 必不保** ⇒ 相似性面必死。$\mathcal{A}$ 连续(AF2 扭转角) ⇒ 可保 ⇒ 可活。

与 M1 §2 的四比零加 AF2 分裂**逐格吻合**。M1 那边是填表读出来的,这边是从模式推出来的,两条路独立。**这是本节唯一的正面证据,也是它区别于「换个说法」的地方。**

## 五、信心分层(要紧,不许含糊)

**已证:**

1. §1 的盲命题:测度上的泛函只依赖 $\tau$ 的 a.e. 类,铰链三条不是 a.e.-不变的。这是缺口的严格版本。
2. 三条铰链各自可改写成「$\tau$ 保某结构」——逐条改写在 §2,每条都能对上既有出处,不是套话。
3. §4 的自洽检验:有限商必杀相似性面,由离散拓扑推出,与 M1 实测吻合。

**猜(未证,不许当结论用):**

4. 「代价 = 不保的程度,以 $S$ 自己的语言度量」这个统一写法。四个实例里只有 $S$ = 可测结构那个写出了公式(现行判据);其余三个只指出了对应的现象,**没写出度量**。光滑那个尤其可疑:「导数缺失的程度」不是一个现成的数,直通估计是造一个替代品而非度量一个缺口。
5. 结构清单完不完备。四个结构是从八条面相反推出来的,不是从别处独立得到的——**与八条面相「没有独立来源」这个已登记风险同源,不是新的独立支撑。**

**这一节最可能的错法:** 「一切都是保不保结构」这句话足够空,几乎任何数学对象都能被这么讲一遍;若四个实例里只有一个写得出公式,那它就是个漂亮的说法而不是理论。**判定它是哪一种,只需一件事:再写出一个实例的公式。** 序列结构那个最容易——可缓存 = $\tau_t$ 只依赖前缀,这句话有现成的形式化(适应过滤),且 M2 已给出可测后果(单步成本)。**列为下一步的第一件。**

## 六、状态

- **S-13 的出路是第三条**:不扩泛函、不另立判据,而是承认现行判据是「$\tau$ 保结构吗」这个模式在可测结构上的实例。
- 缺口本身已由 §1 证硬:任何测度泛函必盲,不是写法问题。
- 铰链三条统一为「$\tau$ 保结构 / $\kappa$ 保结构」,方向不对称由构造给出(截面保、商塌),M2 §5 的分裂不再是异常。
- 模式的统一度量**未写出**,四实例中三个只有现象没有公式。**下一件:写序列结构那个实例的公式**(可缓存 = 对前缀过滤适应),写成了则模式可信一档,写不成则模式降为说法。
- 交 S4 的东西变了:不再是「铰链装不下、请裁决两条出路」,而是「模式已提出、其中三个实例欠公式、请判它是理论还是说法」。
