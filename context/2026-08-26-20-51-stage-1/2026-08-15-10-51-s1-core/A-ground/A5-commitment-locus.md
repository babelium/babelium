# A5 — 承诺:$\mathrm{sel}$ 被调用的那一次事件

A4 把承诺定成「在欠定的选择上取定一个代表」,并把它收进 $\mathrm{sel}$。A5 只剩事件学:何时调、能否观测、可否测量。**North Star 的可测量化交付物整个落在这里。**

## 1. 事件有前后

$\mathrm{sel}$ 被调用前,纤维是开的——多个代表都还活着。调用后,一个代表被取定,其余不可恢复。承诺的实质是**不可逆的收窄**,不是选择本身。

于是「承诺多大」这个问题有了形状:量的是**放弃了多少**。但放弃什么算多?这里有一个必须避开的陷阱。

## 2. 承诺不是熵:一个必须避开的等同

最自然的量是调用前纤维上分布的熵。BLT 的下一字节熵正是这个,也是证据链认定的最接近代理。

**但证据链同时把「熵边界 = 语义边界 / 承诺边界」列进了不能支持。** 若把承诺定成熵,理论第一天就与证据冲突。

熵问的是「我有多不确定」。承诺的代价不是不确定,是**不可逆**——纤维里其余代表被永久放弃,而放弃得贵不贵,取决于它们**在下游是否承重**。

这正是 A3 §6 的 $\Phi$。$\Phi$ 是下游实际读取的量族,于是:

$$\boxed{\text{承诺的代价} = \text{纤维在 } \Phi \text{ 上的落差,不是纤维上的熵}}$$

熵在纤维**内部**测分散;$\Phi$-落差测这份分散**穿不穿透到下游**。两者可以完全脱钩。

## 3. 二维分类:证据链的乱局由此归位

熵与 $\Phi$-敏感度是两根独立的轴。四格:

| | $\Phi$ 平(纤维内代表同效) | $\Phi$ 陡(代表差别穿透下游) |
|---|---|---|
| **低熵**(几无可选) | 被迫且无害 —— 名义承诺 | 被迫且要紧 —— 生僻内容的切分 |
| **高熵**(可选甚多) | 自由且无害 —— **register / sink 的形成** | 自由且要紧 —— 真正的语义决策点 |

三条证据当即归位:

**为何首 token 近乎 no-op** —— P0 的纤维 $\Phi$ 平。删掉不改变被读取的东西,故承诺代价近零,尽管其位置的熵未必低。落在左下格。

**P0-sink 可由纯结构原因形成** —— 左下格的必然:当纤维 $\Phi$ 平时,取哪个代表不受下游约束,于是选择被**结构**(causal mask、恒可见、pre-norm)而非内容定下。**「无害」正是「可由纯结构决定」的原因**,不是两件独立的事。

**diffusion sink 小规模删除不损语义对齐但明显改变成像** —— 同一次承诺在 $\Phi_{\text{语义}}$ 下平、在 $\Phi_{\text{像素}}$ 下陡。**代价不是承诺的属性,是承诺与 $\Phi$ 这一对的属性。** 不同论文测不同 $\Phi$,故各自看到的图景不同——证据链得出「分层而非单因素」的结论,由此得到解释而非仅被记录。

**并且熵为何不够,现在是推论:** 熵只读表的行,不读列。它是二维量的一维代理,所以「熵边界 = 语义边界」必假——不是经验上碰巧不成立,是维数不够。这条推出了证据链的否定结论,D1 记为第四个候选。

## 4. 「选择机制 ≠ 承载内容」是签名的两个不同槽位

证据链最强的结构性结论,在签名里不需要记住:

- **选择机制** = 什么定下 $\mathrm{sel}$(结构、熵、学出的 router、优先序)
- **承载内容** = $\Phi$ 从结果上读出什么

两者是签名的不同件,混同即类型错误。槽位不同,不是需要提醒的注意事项。

## 5. 可测量化:纤维重采样下的 $\Phi$-敏感度

$\Phi$-落差给出可执行协议。测一次承诺的代价:

1. 定住 $\Phi$ —— 明确下游读什么(任务指标、探针可读量、生成结果、后续计算收益)。须显式,因为 §3 说代价随 $\Phi$ 变。
2. 定住该次承诺的纤维 —— 找出被 $\mathrm{sel}$ 收窄掉的那些代表。
3. **纤维内重采样** —— 换取其他代表,其余一切不动。
4. 量 $\Phi$ 的变化 —— 方差或最坏落差即该次承诺在该 $\Phi$ 下的代价。
5. 同时记熵 —— 用于定位在 §3 的哪一格,不用于定义代价。

第 3 步是新东西。证据链的「最需要的实验」要求联合记录下一步熵、表示变化、边界决策、等算力下的边际收益——全是**观测**。$\Phi$-敏感度要求**干预**:不换边界,换同一次承诺内的代表。二者互补,前者定位格子的行,后者定列。S5 的设计据此增补。

这也把承诺从解释性概念变成有操作定义的量:**给定 $\Phi$,承诺的代价是纤维重采样下 $\Phi$ 的敏感度。** 相对于 $\Phi$ 而非绝对,这是特性不是缺陷——§3 的第三条证据表明绝对版本必然自相矛盾。

## 6. 何时调:原子承诺与链式承诺

$\mathrm{sel}$ 可以调一次,也可以是一串 $\mathrm{sel}_1, \mathrm{sel}_2, \ldots$ 各自只部分收窄纤维。这是 A4 九格里的「硬度」。

在 $\Phi$ 框架下二者的差别可推:原子承诺一次付清全部 $\Phi$-落差,不可退;链式承诺每步只付一部分,**且纤维尚未收完,后续步骤可修正前面的落差**。

$$\text{链式承诺的收益} = \text{纤维保持开放,使 } \Phi\text{-落差可被后续步骤纠正}$$

diffusion / flow 沿 timestep 摊薄的好处于是不是「更平滑」这种气质描述,是这条。同理可推它的代价:每步都要重新比较,总计算量随链长增。**这是 S4 必须推导的那类架构相关差异的第一个样本**,A5 只给种子,不在此展开。

## 7. A 阶段收束

签名 $\mathcal{I} = (\Omega^+, \mathcal{A}, \mathcal{X}, c, \mathrm{anc}, \mathrm{sel}, \omega)$ 齐备,承诺有了操作定义与二维定位。B 阶段的九格按此重排:

七件填值 + 三栏($\omega$ / 坏掉的复合 / 该实例的 $\Phi$)+ 一栏已观测现象(留给 S4 的欠条)+ 一栏在 §3 四格中的落点。

**交给 C 的关键一条:** $\Phi$ 从 A3 的「待定函数族」变成了「下游实际读取的量」,并在 A5 拿到了操作定义(重采样敏感度所针对的那个量)。C3 要证的东西因此是明确的:$\mathbb{E}_{\kappa\tau p}[\phi] = \mathbb{E}_p[\phi], \forall \phi \in \Phi$ 是否能作为界面成立的一般判据,以及各安放方式的 $\Phi$ 各是什么。

**交给 D3:** 承诺的定义只用到纤维与 $\Phi$,不用离散。第五次。
