# STAGE 2 — 反推路线:双面体层的毛边边界

> Created: 2026-08-15 15:37
> Topic: token 理论 — 从换算界面层与机制群系层反推双面体层的边界
> Phase: STAGE 2(与 STAGE 3 同时起跑,略先半步)

## Plan Context

### 本 STAGE 的定位与它为何不能单独完成任务

三层的标准用词后续固定为:**双面体 + 推广不动点 层**、**换算界面 + 承诺可测量化 层**、**机制群系 + 推导架构差异 层**。原 A/B/C 标签作废。

北极星原本设计的推进顺序是三层依次条件化(有了第一层再推第二层,有了第二层再推第三层)。S1 的实测数据要求下调这个先验:第一层内部的三项进展(不动点在相似性原始时恒假、$\Phi$-弱替代判据、已证那级其实是两个同一性面之间的往返)全部来自正面推导,而第一层边界的两项进展(两面共不共处一室、纤维对训练目标可见 ⟺ 提交代价被训练)全部来自第二、三层的反推。3–0 与 2–0,无交叉。

反推路线到不了判据,这是路径性质而非进度问题。反推的操作方式是填行与比行,即从样本读出规律,属归纳;而判据是一句全称句(对任意安放方式,两面何时确实是同一枚硬币)。归纳不能覆盖尚未被造出的第 $n+1$ 个安放方式,那需要从两面的最小结构演绎。因此把表填到六十行与填到六行,在「是否得到判据」上没有差别。

反推路线真正的产出物是**判据必须满足的规格清单**。已有一例可作样板:AR 是唯一跨空间的安放,这条不是一句边界观察,它把判据的形状框住了——判据必须能处理「两面根本不在同一个空间」的情形,而 $\Phi$-弱替代判据的现行写法默认两面可比。反推 → 正面,方向单向,S3 持续接收本 STAGE 的规格。

### 目标

产出规格清单,不是产出更多行。行是手段。

### 产物形式(三样,职责不同,2026-08-15 与用户确认)

#### 产物一:原子面相 × 安放方式 矩阵(扩容主力,新建)

北极星已把两面拆成八个原子面相:同一性面五条(可数、可索引、可缓存、可复用、可组合),相似性面三条(可微、可插值、可泛化)。此前的推导一直笼统处理「两面」,未按面相排表。排表后发现一个空洞:同一性面五条各有结论(可复用属于地址、可组合因 $\tau$ 非同态而坏、可索引即商结构、可缓存有但薄、可数则部分被推翻——离散性从未进入必要条件),而**相似性面三条基本是空的**:可微几乎没碰,可插值与可泛化各零条结论。此空洞由排表暴露,笼统讲「两面」不可能看出。

矩阵的用处不止补漏。若两面各是一捆面相,则「是不是同一枚硬币」未必是全有全无:可能可缓存过得去而可组合过不去。判据因此可能须按面相分级而非给一个二值答案。这是对 S3 的实质输入。

行为八个面相,列为七个安放方式(AR、VQ、diffusion 分箱、AF2 层级、RAG、GraphRAG,加文本输入这个最典型的),共五十六格。

单格格式:**成立 / 不成立 / 部分 + 机制或遮挡物 + 出处**。与 G 表同一规矩:没出处就留空,不许填印象。空格有信息——它标出未被查过的地方。

两个样例格,示明所需精度。可组合 × 文本输入:不成立,机制是 $\tau(xy) \neq \tau(x)\cdot\tau(y)$,即 prompt 边界效应那一族。可插值 × VQ:部分,码字同在 $\mathbb{R}^D$ 故插值可算,但结果一般不属码本——**面相在载体上活着,过了商就死了**;载体上成立与商上成立的区分是格子必须记录的内容。

**已知风险与对冲**:八个面相取自北极星,而北极星由本项目自己写成,该清单**没有独立来源**,若拆错或拆漏则整表继承此错。对冲用与 S3 轴门同形的一道门:每个面相必须能在至少一个安放方式上被实际检验(说出成立或不成立及其机制),检验不了的面相砍掉。

#### 产物二:杀伤判决(一条杀伤一个文件)

格式沿用 `2026-08-15-10-51-s1-core/F-bets/F1-verdict.md`:判决 + 逐条修正 + 覆盖边界 + 新增待测项。该文件的价值在于它三处修正了自己的原推导,而非只宣布赌赢;两次杀伤的判决须同此标准。

#### 产物三:规格清单(交给 S3 的产物本身,取表不取 list)

前两样是材料,此样是产物。一条规格必须写成 S3 能直接拿来测的形状。反例:「判据应当考虑跨空间情形」——S3 无从下手。正例:「若判据的陈述里出现 $\mathbb{E}_p$ 与 $\mathbb{E}_{\kappa\tau p}$ 相比较,则它预设两面同空间,故在 AR 上无定义」——S3 拿候选判据一比即出是否。

六列:**编号 / 规格陈述 / 来源(哪一行或哪份判决) / S3 怎么测 / 强度(硬约束或偏好) / 来源倒了则本条连带作废**。

末列为要紧项:规格由事实推出,事实被推翻则规格须跟着撤。这是「数字要么删要么钉死」这条既定规矩用在规格上;缺此列则数轮之后会剩下一批无人记得来源的「要求」。

### 两个杀伤目标(已有具体候选,不需先探索)

**杀伤一:杀「纤维对训练目标可见 ⟺ 提交代价被训练」这条等价。** 现状六比零无反例,但那是从已填的六个条目读出来的,不是证出来的。候选反例是 REINFORCE / score-function 那一类离散采样:纤维对解码器不可见,而提交经 score function 估计量进入梯度,即被训练。若该候选成立,这条等价当场倒;若不成立,须说清它为何不构成反例(而非仅记「没找到」)。

**杀伤二:杀「AR 是唯一跨空间安放」这条唯一性。** 找出第二个换算前后不在同一空间的安放方式,或证明 AR 其实同空间。此条一倒,则「一个结构上的异类被当成了典型」这句连带失效,而那是 S1 全表最危险的一句。

### 门

每一行进表之前,必须先写明它可能杀掉哪一条。写不出来的行不进表。杀成了记杀成,杀不动记杀不动并说明理由——两种都是产出,只有「扫了但没结论」不是。

此门的作用是给「扩充信息」装上停止条件。以扩充为目标的工作没有终点,扫得越多越像有进展而永远扫不完;以杀伤清单为驱动则清单清空即停。

### 停止条件

杀伤清单清空(每条要么被杀,要么被判定杀不动且给出理由)。
